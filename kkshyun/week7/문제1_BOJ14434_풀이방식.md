## BOJ 14434 문제 요약

- N명의 아이와 M개의 놀이기구가 있다.
- 각 놀이기구 k는 키 제한을 가진다.
- (i, j, k) 쿼리는 아이 i와 아이 j가 놀이기구 k를 매일 타려고 시도한다는 뜻이다.
- K일 동안 매일 한 아이의 키가 1씩 자란다.
- 매일, 키가 먼저 자라고 나서 조건

  아이 i 키 + 아이 j 키 ≥ 놀이기구 k의 키 제한

  을 만족하면 그 날 그 쿼리는 1번 놀이기구를 탄다.

- 1일부터 K일까지, 각 날마다 놀이기구를 총 몇 번 탔는지 구하는 문제이다.

---

## 아이디어

1. 아이별 성장 날짜 저장
    - K일 동안 매일 키가 자라는 아이 번호가 주어지므로 growDays[i] 리스트에 아이 i가 자란 날짜(day)를 오름차순으로 넣어둔다.
    - t일에 아이 i의 키는 growDays[i]에서 t 이하인 원소 개수(upperBound로 계산)와 같다.
2. 쿼리마다 처음 탈 수 있는 날을 날짜 기준 이분 탐색
    - 쿼리 (kid1, kid2, rideIdx)에 대해 limit = rides[rideIdx]를 키제한으로 둔다.
    - t일에 두 아이 키 합은 upperBound(growDays[kid1], t) + upperBound(growDays[kid2], t) 이다.
    - t가 커질수록 키는 증가만 하므로 두 아이 키 합이 limit 이상이 되는 최소 날짜 t를 [1, K] 구간에서 이분 탐색으로 찾는다.
    - 이 날짜를 actDay로 두고, actDay일부터 K일까지 매일 이 쿼리는 1번 놀이기구를 탄다.
    - 두 아이의 최종 키 합이 limit보다 작으면 끝까지 못 타므로 건너뛴다.
3. 차분 배열로 날짜별 탑승 횟수 계산
    - 각 쿼리에서 구한 actDay에 대해 diff[actDay] += 1을 해 준다.
    - 이후 1일부터 K일까지 diff를 누적합으로 더해서 그 날까지 시작된 쿼리 수를 구하면, 그 값이 곧 그 날의 총 탑승 횟수가 된다.

---

## 알고리즘 단계

1. N, M, K, Q 입력
2. 놀이기구 키 제한을 rides[1..M]에 저장
3. growDays[1..N] 초기화 후, K일 동안 성장 정보를 읽어 day를 1부터 K까지 증가시키며 growDays[아이].add(day)
4. diff[1..K]를 0으로 초기화
5. Q개의 쿼리에 대해
- (kid1, kid2, rideIdx) 입력, limit = rides[rideIdx]
- 두 아이 최종 키 합이 limit 미만이면 continue
- [1, K]에서 이분 탐색으로 upperBound(growDays[kid1], mid) + upperBound(growDays[kid2], mid) ≥ limit 를 처음 만족하는 최소 mid를 actDay로 찾는다
- actDay ≤ K이면 diff[actDay] += 1
1. day = 1..K에 대해 누적합 cur += diff[day]를 계산하고 cur를 출력

---

## 코드

```java
import java.io.*;
import java.util.ArrayList;
import java.util.List;

public class Main {

    static List<Integer>[] growDays;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int M = Integer.parseInt(s[1]);
        int K = Integer.parseInt(s[2]);
        int Q = Integer.parseInt(s[3]);

        // 놀이기구 키 제한
        int[] rides = new int[M + 1];
        s = br.readLine().split(" ");
        for (int i = 1; i <= M; i++) {
            rides[i] = Integer.parseInt(s[i - 1]);
        }

        // 아이가 자란 날짜 리스트
        // 아이 키는 리스트에서 해당 날짜보다 작거나 같은 원소 개수로 알 수 있음
        growDays = new ArrayList[N + 1];
        for (int i = 1; i <= N; i++) {
            growDays[i] = new ArrayList<>();
        }
        s = br.readLine().split(" ");
        for (int day = 1; day <= K; day++) {
            int kid = Integer.parseInt(s[day - 1]);
            growDays[kid].add(day);
        }

        long[] diff = new long[K + 2];

        for (int qi = 0; qi < Q; qi++) {
            s = br.readLine().split(" ");
            int kid1 = Integer.parseInt(s[0]);
            int kid2 = Integer.parseInt(s[1]);
            int rideIdx = Integer.parseInt(s[2]);
            int limit = rides[rideIdx];

            List<Integer> l1 = growDays[kid1];
            List<Integer> l2 = growDays[kid2];

            int actDay = K + 1;

            int totalGrow = l1.size() + l2.size();
            if (totalGrow >= limit) {
                int low = 1;
                int high = K;
                int ans = K + 1;

                while (low <= high) {
                    int mid = low + (high - low) / 2;
                    int cnt = upperBound(l1, mid) + upperBound(l2, mid);
                    if (cnt >= limit) {
                        ans = mid;
                        high = mid - 1;
                    } else {
                        low = mid + 1;
                    }
                }
                actDay = ans;
            }

            if (actDay <= K) {
                diff[actDay] += 1;
            }
        }

        // 차분 → 누적합으로 각 날마다 총 탑승 횟수 계산
        StringBuilder sb = new StringBuilder();
        long cur = 0;
        for (int day = 1; day <= K; day++) {
            cur += diff[day];
            sb.append(cur).append('\n');
        }

        bw.write(sb.toString());
        bw.flush();
        bw.close();
        br.close();
    }

    // list에서 value 이하인 원소 개수 = upper_bound 역할
    private static int upperBound(List<Integer> list, int value) {
        int low = 0;
        int high = list.size();
        while (low < high) {
            int mid = low + (high - low) / 2;
            if (list.get(mid) <= value) {
                low = mid + 1;
            } else {
                high = mid;
            }
        }
        return low;
    }
}
```
