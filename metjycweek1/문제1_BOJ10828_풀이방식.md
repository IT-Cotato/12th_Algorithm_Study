# 📚 BOJ 10828 - 스택

## 📝 문제 설명

정수를 저장하는 스택을 구현하고, 입력으로 주어지는 명령을 처리하는 문제이다.  
스택은 **후입선출 (LIFO)** 구조이다.

---

## 🧾 명령어 목록

- `push X`: 정수 X를 스택에 넣는다.
- `pop`: 스택에서 가장 위의 정수를 제거하고 출력. 없으면 `-1`.
- `size`: 스택에 있는 정수 개수 출력.
- `empty`: 스택이 비어있으면 `1`, 아니면 `0`.
- `top`: 스택의 가장 위 정수 출력. 없으면 `-1`.

---

## 🧾 코드 설명

### 📥 입력 처리

```js
const fs = require("fs");
const input = fs.readFileSync("/dev/stdin").toString().trim().split("\n");
```

- 백준에서는 `/dev/stdin`을 통해 입력을 받기 때문에 `readFileSync`를 사용해 한 번에 읽고 줄 기준으로 split한다.

### 📦 명령 분리 및 스택 초기화

```js
const n = Number(input[0]);
const commands = input.slice(1);
const stack = [];
const output = [];
```

- 첫 줄은 명령 수 `n`
- `commands`는 각 명령 문자열 배열
- `stack`은 실제 데이터를 담는 배열
- `output`은 나중에 출력할 결과 모음

### 🔁 명령 처리

```js
for (let cmd of commands) {
  if (cmd.startsWith("push")) {
    const [, num] = cmd.split(" ");
    stack.push(Number(num));
  } else if (cmd === "pop") {
    output.push(stack.length ? stack.pop() : -1);
  } else if (cmd === "size") {
    output.push(stack.length);
  } else if (cmd === "empty") {
    output.push(stack.length === 0 ? 1 : 0);
  } else if (cmd === "top") {
    output.push(stack.length ? stack[stack.length - 1] : -1);
  }
}
```

- `push`: `split(" ")`으로 숫자 추출 후 `stack.push()`로 삽입
- `pop`: 비었으면 -1, 아니면 `stack.pop()`으로 제거 후 출력
- `size`: 현재 스택의 길이 출력
- `empty`: `length === 0`이면 1, 아니면 0 출력
- `top`: `stack[stack.length - 1]`로 맨 위 값 출력, 없으면 -1

---

## 💡 풀이 전략 요약

1. `stack` 배열을 활용해 직접 스택 구현
2. 명령어마다 `if` 또는 `switch` 문으로 처리
3. `push` 명령은 `split(" ")`으로 숫자 분리
4. `output` 배열에 결과 누적 후 한 번에 출력

---

## ✅ 주요 코드

```js
const fs = require("fs");
const input = fs.readFileSync("/dev/stdin").toString().trim().split("\n");

const n = Number(input[0]);
const commands = input.slice(1);

const stack = [];
const output = [];

for (let cmd of commands) {
  if (cmd.startsWith("push")) {
    const [, num] = cmd.split(" ");
    stack.push(Number(num));
  } else if (cmd === "pop") {
    output.push(stack.length ? stack.pop() : -1);
  } else if (cmd === "size") {
    output.push(stack.length);
  } else if (cmd === "empty") {
    output.push(stack.length === 0 ? 1 : 0);
  } else if (cmd === "top") {
    output.push(stack.length ? stack[stack.length - 1] : -1);
  }
}

console.log(output.join("\n"));
```

- JavaScript 문자열 처리와 배열 메서드 응용
- 백준에서 `fs.readFileSync("/dev/stdin")` 사용법 익힘
