# 📘 분할 정복 핵심 개념 정리 — BOJ 1780 & BOJ 1074

두 문제 모두 **분할 정복(Divide & Conquer)** 기반 문제이지만  
각자의 목적과 구현 방식이 다릅니다.

이 README에서는 다음 두 문제에 필요한 **핵심 개념을 통합 정리**합니다.

- **BOJ 1780 — 종이의 개수**
- **BOJ 1074 — Z 탐색(Z-order)**

---

# 🔥 공통 핵심 개념: 분할 정복 (Divide & Conquer)

두 문제는 모두 다음 과정을 기반으로 동작합니다.

1. **현재 공간을 분할한다.**
2. **조건을 검사한다.**
3. **필요하면 더 작은 단위로 재귀(call).**
4. **기준 조건(단일 값 or 크기 1)이 되면 값을 반환한다.**

즉, 큰 문제를 동일한 구조의 작은 문제로 쪼개 해결하는 방식이다.

---

# 📌 BOJ 1780 — 종이의 개수

## 📝 문제 요약

`N × N` 크기의 종이를 다음과 같이 검사한다:

- 종이 전체가 **같은 숫자(−1, 0, 1)** 로만 이루어져 있으면  
  → 그대로 카운트 1 증가
- 아니라면 종이를 **9등분(3×3)** 하여 각각 다시 검사한다.

## 🔑 핵심 개념

### ✔ 1. 균일성 검사 (all same check)

현재 구간이 같은 숫자로 이루어져 있는지 반드시 검사해야 한다.

```txt
모든 값이 같으면 → 한 개의 종이로 인정
하나라도 다르면 → 9등분해서 재귀
```

### ✔ 2. 3-way 분할 (N/3)

```
┌───┬───┬───┐
│ 1 │ 2 │ 3 │
├───┼───┼───┤
│ 4 │ 5 │ 6 │
├───┼───┼───┤
│ 7 │ 8 │ 9 │
└───┴───┴───┘
```

### ✔ 3. 시간복잡도

```
O(N^2)
```

# 📌 BOJ 1074 — Z 탐색 (Z-order)

## 📝 문제 요약

`2^N × 2^N` 배열을 Z 모양 순서로 방문한다고 할 때,  
특정 좌표 `(r, c)`가 몇 번째 방문인지 계산하는 문제.

## 🔑 핵심 개념

### ✔ 1. 2×2 사분면 분할

```
┌─────┬─────┐
│  0  │  1  │
├─────┼─────┤
│  2  │  3  │
└─────┴─────┘
```

### ✔ 2. 사분면 판정

```
half = 2^(n-1)
```

### ✔ 3. 사분면별 건너뛰는 칸 수

```
area = half * half
```

### ✔ 4. 시간복잡도

```
O(N)
```

# ⚔ 두 문제의 차이점 정리

| 항목        | BOJ 1780 종이의 개수     | BOJ 1074 Z 탐색            |
| ----------- | ------------------------ | -------------------------- |
| 목표        | 각 숫자의 종이 개수 세기 | 특정 좌표의 방문 순서 찾기 |
| 분할 크기   | 3등분(9조각)             | 2등분(4조각)               |
| 동일성 검사 | 필요                     | 필요 없음                  |
| 종료 조건   | 모든 값 동일             | n = 0                      |
| 시간복잡도  | O(N²)                    | O(N)                       |

# 🧩 예시 코드 구조

## ✔ BOJ 1780 — 종이의 개수

```js
function solve(x, y, size) {
  if (checkSame(x, y, size)) {
    count[value]++;
    return;
  }
  const newSize = size / 3;
  for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
      solve(x + i * newSize, y + j * newSize, newSize);
    }
  }
}
```

## ✔ BOJ 1074 — Z 탐색

```js
function z(n, r, c) {
  if (n === 0) return 0;

  const half = 1 << (n - 1);
  const area = half * half;

  if (r < half && c < half) return z(n - 1, r, c);
  if (r < half && c >= half) return area + z(n - 1, r, c - half);
  if (r >= half && c < half) return area * 2 + z(n - 1, r - half, c);
  return area * 3 + z(n - 1, r - half, c - half);
}
```

# 📌 최종 요약

- **1780(종이의 개수)** → 3등분, 모든 값 동일 여부 검사
- **1074(Z 탐색)** → 2등분, 사분면 index 계산
- 둘 다 **분할 정복** 기반이지만 목적과 로직이 다름
- 시간복잡도는 1780이 더 큼(N²), 1074는 더 작음(N)
