# 백준 2812번 풀이

## 핵심 아이디어

* 왼쪽에서부터 숫자를 하나씩 보면서, **앞자리(왼쪽 숫자)** 가 현재 숫자보다 작으면 제거한다
* 즉, "지금 보는 숫자가 더 크다면 이전에 쌓은 숫자들은 필요 없다"는 그리디 전략
* 단, **K개까지만 제거** 가능하며, **숫자의 순서는 유지해야 한다.**

이 논리를 효율적으로 처리하기 위해 **스택(Deque)** 을 사용한다.

---

## 알고리즘 로직

1. **입력 숫자를 왼쪽부터 하나씩 순회**
2. 현재 숫자 `c`가 스택의 top(마지막 숫자)보다 크면:

    * 스택에서 pop (`pollLast()`)
    * `k--`
    * 단, 스택이 비어있으면 멈춤 (`!stack.isEmpty()` 조건)
3. 모든 숫자에 대해 반복 후, **아직 k > 0이면 뒤에서부터 제거**
4. 스택의 모든 문자를 이어서 출력

---

## 코드 구현

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());
        String number = br.readLine();

        Deque<Character> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            char c = number.charAt(i);

            // 스택의 마지막 숫자가 현재 숫자보다 작으면 pop
            while (!stack.isEmpty() && k > 0 && stack.peekLast() < c) {
                stack.pollLast();
                k--;
            }
            stack.addLast(c); // 현재 숫자를 스택에 추가
        }

        // 아직 제거할 개수가 남았다면 뒤에서 제거
        while (k > 0) {
            stack.pollLast();
            k--;
        }

        StringBuilder sb = new StringBuilder();
        for (char c : stack) sb.append(c);

        System.out.println(sb.toString());
    }
}
```

---

## 스택 방향 

이 코드는 **Deque**를 스택처럼 사용하지만, 스택의 **위(top)** 를 `Last`로 둔다.

| 메서드          | 역할     | 설명              |
| ------------ | ------ | --------------- |
| `peekLast()` | top 확인 | 현재 스택의 마지막 값 확인 |
| `pollLast()` | top 제거 | 마지막(가장 최근) 값 제거 |
| `addLast()`  | push   | 현재 숫자를 스택 끝에 추가 |

> 즉, 스택의 "끝쪽(Last)"이 실제로 **왼쪽 숫자들의 최신 상태**를 의미한다
