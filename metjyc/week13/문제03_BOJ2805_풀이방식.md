# 🌲 BOJ 2805 — 나무 자르기 (이분 탐색)

## 1. 문제 요약

- N개의 나무가 있고, 각 나무의 높이가 주어진다.
- 절단기 높이 `H`를 정해 모든 나무를 자른다.
- 잘린 나무 중 **`H`보다 높은 부분만** 가져갈 수 있다.
- 가져간 나무 길이의 합이 **최소 M 이상**이 되도록 하면서  
  **절단기 높이 `H`의 최댓값**을 구하는 문제.

---

## 2. 핵심 관찰 (왜 이분 탐색인가?)

절단 높이 `H`에 따라 얻는 나무 길이 `sum(H)`는 다음 성질을 가진다.

- `H`가 **커질수록** → 잘리는 나무 길이 `sum(H)`는 **작아진다**
- `H`가 **작아질수록** → `sum(H)`는 **커진다**

즉, `sum(H)`는 **단조 감소 함수**이다.

👉 이런 문제는 **이분 탐색(Binary Search)** 이 정답.

---

## 3. 접근 전략

### ① 판별 함수 정의

> “이 높이 `H`로 잘랐을 때 나무를 M 이상 얻을 수 있는가?”

```js
canGet(H) = true / false
```

- `true` → 더 높게 잘라도 될 가능성 있음
- `false` → 너무 높게 잘랐으므로 낮춰야 함

---

### ② 탐색 범위 설정

- 최소 높이: `0`
- 최대 높이: `나무 중 가장 높은 값`

```js
left = 0;
right = maxHeight;
```

---

### ③ 이분 탐색 규칙

| 조건                    | 행동                          |
| ----------------------- | ----------------------------- |
| `canGet(mid) === true`  | `ans = mid`, `left = mid + 1` |
| `canGet(mid) === false` | `right = mid - 1`             |

→ **가능한 높이 중 최댓값**을 찾기 위해 `true`일 때 오른쪽 탐색

---

## 4. 전체 코드 (Node.js)

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const [N, M] = input[0].split(" ").map(Number);
const trees = input[1].split(" ").map(Number);

// 가장 높은 나무 찾기
let maxH = 0;
for (let i = 0; i < trees.length; i++) {
  if (trees[i] > maxH) maxH = trees[i];
}

// 절단 높이 h로 잘랐을 때 M 이상 얻을 수 있는지
function canGet(h) {
  let sum = 0;
  for (let i = 0; i < trees.length; i++) {
    if (trees[i] > h) {
      sum += trees[i] - h;
    }
  }
  return sum >= M;
}

let left = 0;
let right = maxH;
let ans = 0;

while (left <= right) {
  const mid = Math.floor((left + right) / 2);

  if (canGet(mid)) {
    ans = mid;
    left = mid + 1;
  } else {
    right = mid - 1;
  }
}

console.log(ans);
```

---

## 5. 자주 하는 실수

- `mid++`, `mid--` 사용 ❌ → 반드시 `left`, `right` 이동
- 높이를 1씩 탐색 ❌ → 시간 초과
- 판별 함수에서 중간에 높이 변경 ❌

---

## 6. 시간 복잡도

- 판별 함수: `O(N)`
- 이분 탐색: `O(log H)`
- 전체: **`O(N log H)`**
