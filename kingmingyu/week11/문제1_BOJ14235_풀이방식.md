# 문제
산타가 아이들에게 가치가 큰 선물을 순서대로 나눠주는 프로그램을 작성하기

## 자료구조
- 선물이 없는 경우에는 -1을 출력
- 선물이 있는 경우 가치가 큰 선물먼저 아이들에게 나눠주는 구조 -> 우선 순위 큐 이용
```java
// 큰 정수가 앞으로 오도록 저장
PriorityQueue<Integer> gifts = new PriorityQueue<>(Collections.reverseOrder());
```

## 알고리즘 순서
1. 만약 입력받은 정수가 0이라면 선물을 줘야하는 타이밍이다.
   1. 우선 순위 큐에 선물이 존재하는 경우 `poll()`을 통해 선물을 준다
   2. 선물이 없는 경우 -1을 출력한다.
   
2. 입력받은 정수가 0이 아닌 경우
    1. 선물을 우선순위 큐에 저장한다.
```java
for(int i = 0; i < n; i++){
    StringTokenizer st = new StringTokenizer(br.readLine());
    int k = Integer.parseInt(st.nextToken());
    // 1. 0인 경우
    if(k == 0){
        // ii. 선물이 존재하지 않는 경우
        if(gifts.isEmpty()) System.out.println("-1");
        // i. 선물이 존재하는 경우
        else System.out.println(gifts.poll());
    }
    // 2. 0이 아닌 경우
    else{
        // i. 선물을 모두 저장
        for(int j = 0; j < k; j++){
            gifts.add(Integer.parseInt(st.nextToken()));
        }
    }
}
```

## 전체 코드
```java
package kingmingyu.week11;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Collections;
import java.util.PriorityQueue;
import java.util.StringTokenizer;

public class 문제1_BOJ14235_풀이 {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PriorityQueue<Integer> gifts = new PriorityQueue<>(Collections.reverseOrder());

        int n = Integer.parseInt(br.readLine());
        for(int i = 0; i < n; i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            int k = Integer.parseInt(st.nextToken());
            if(k == 0){
                if(gifts.isEmpty()) System.out.println("-1");
                else System.out.println(gifts.poll());
            }
            else{
                for(int j = 0; j < k; j++){
                    gifts.add(Integer.parseInt(st.nextToken()));
                }
            }
        }
    }
}

```
