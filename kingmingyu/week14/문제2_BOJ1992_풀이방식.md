# 문제
n x n 배열이 주어졌을 때 정사각형 크기 내에 모두 같은 숫자가 존재한다면 요약해서 출력하기
> 예시 출력
> 
> ((110(0101))(0010)1(0001))

## 풀이
주어진 좌표에서 절반씩 나누어 같은 값으로 존재하는지 확인해야 하므로 Divide and Conquer 이용

### 1. 주어진 입력값 받기
```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
sb = new StringBuilder();

n = Integer.parseInt(br.readLine());
map = new int[n][n];

for(int i = 0; i < n; i++){
    String mapInf = br.readLine();
    for(int j = 0; j < n; j++){
        map[i][j] = mapInf.charAt(j) - '0';
    }
}
```
### 2. dnc 수행하기
```java
dnc(0, n, 0, n);


public static void dnc(int sx, int ex, int sy, int ey){

    int start = map[sx][sy];
    for(int i = sx; i < ex; i++){
        for(int j = sy; j < ey; j++){
            if(start != map[i][j]){
                int mx = (sx + ex) / 2;
                int my = (sy + ey) / 2;
                sb.append("(");
                dnc(sx, mx, sy, my); // 왼쪽 위
                dnc(sx, mx, my, ey); // 오른쪽 위
                dnc(mx, ex, sy, my); // 왼쪽 아래
                dnc(mx, ex, my, ey); // 오른쪽 아래
                sb.append(")");
                return;
            }
        }
    }
    sb.append(start);
    return;
}
```
1. 초기값을 start에 저장
2. 만약 start와 같지 않은 값이 존재한다면 그 부분은 다시 4등분으로 나누어 dnc 호출 
   - 순서 중요(반드시 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 순서)
3. 앞 뒤로 sb.append()를 통해 괄호를 열고 닫아주기(문제의 출력 조건)
4. 만약 반복문이 끝났는데도 모두 같다면 sb.append로 초기 값 저장
### 3. 결과 출력하기
```java
System.out.println(sb);
```
- sb에 저장된 값 출력
### 전체 코드
```java
package kingmingyu.week14;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class 문제2_BOJ1992_풀이 {
    static int n;
    static int[][] map;
    static StringBuilder sb;

    public static void main(String[] args) throws IOException {

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        sb = new StringBuilder();

        n = Integer.parseInt(br.readLine());
        map = new int[n][n];

        for(int i = 0; i < n; i++){
            String mapInf = br.readLine();
            for(int j = 0; j < n; j++){
                map[i][j] = mapInf.charAt(j) - '0';
            }
        }

        dnc(0, n, 0, n);
        System.out.println(sb);
    }

    public static void dnc(int sx, int ex, int sy, int ey){
//        if(sx >= ex || sy >= ey){
//            sb.append(map[sx]).append(")");
//        }
        int start = map[sx][sy];
        for(int i = sx; i < ex; i++){
            for(int j = sy; j < ey; j++){
                if(start != map[i][j]){
                    int mx = (sx + ex) / 2;
                    int my = (sy + ey) / 2;
                    sb.append("(");
                    dnc(sx, mx, sy, my); // 왼쪽 위
                    dnc(sx, mx, my, ey); // 오른쪽 위
                    dnc(mx, ex, sy, my); // 왼쪽 아래
                    dnc(mx, ex, my, ey); // 오른쪽 아래
                    sb.append(")");
                    return;
                }
            }
        }
        sb.append(start);
        return;
    }
}
```
