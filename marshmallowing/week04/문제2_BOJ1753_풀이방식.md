#  BOJ 1753 — 최단경로 (Dijkstra)

##  문제 개요
하나의 시작 정점에서 다른 모든 정점까지의 최단거리 구하기.  
모든 가중치는 양수 → **다익스트라 알고리즘** 사용.

---

##  핵심 아이디어
- `dist[v]`: start→v의 현재까지 알려진 최소거리
- **우선순위 큐(PriorityQueue)** 사용  
- 우선순위 큐에서 가장 가깝게 확정된 정점을 꺼내고, 그 정점의 간선을 릴랙스
- 방문 시점에서 최단거리 확정됨
- 이미 더 짧은 값으로 방문된 정점이 큐에서 다시 나올 수 있으므로,
  lazy deletion: pop했을 때 if (curDist > dist[cur]) continue

## 구현 요약
- 인접리스트 생성
- dist[*] = INF, dist[start] = 0
- PQ에 (start,0) push
- 꺼내며 이웃 갱신
- 출력 시 INF면 문자열 "INF"

- 모든 간선 가중치가 비음수일 때, PQ에서 꺼낼 때의 u는 그 순간 start→u의 최단거리가 확정.
- 그 이후 u를 경유하는 경로들이 다른 정점들의 상한을 낮추며 수렴.

## 시간복잡도
- O(E log V) — E는 간선 수, PQ 기반이라 빠름.

---

## 주요 코드
```java
PriorityQueue<Node> pq = new PriorityQueue<>();
dist[start] = 0;
pq.offer(new Node(start, 0));

while (!pq.isEmpty()) {
    Node cur = pq.poll();
    if (cur.weight > dist[cur.vertex]) continue; // 이미 처리된 노드

    for (Node next : graph[cur.vertex]) {
        if (dist[next.vertex] > dist[cur.vertex] + next.weight) {
            dist[next.vertex] = dist[cur.vertex] + next.weight;
            pq.offer(new Node(next.vertex, dist[next.vertex]));
        }
    }
}
```
