# 백준 12865

## 문제 요약
각 물건은
- 무게 W
- 가치 V
를 가진다.

배낭이 버틸 수 있는 최대 무게 K 안에서
가치의 합이 최대가 되도록 물건을 선택한다.

각 물건은 한 번만 선택 가능하다.

---

## 풀이 접근 방식

이 문제의 핵심은 **현재 물건을 넣을지 말지를 결정하는 선택 문제**이다.

### 1. 상태 정의
- `dp[i][w]` : i번째 물건까지 고려했을 때 무게 w 이하로 담을 수 있는 최대 가치

### 2. 점화식 도출
i번째 물건의 무게를 weight, 가치를 value라고 할 때

1. 물건을 넣지 않는 경우
   `dp[i][w] = dp[i-1][w]`

2. 물건을 넣는 경우 (w ≥ weight)
   `dp[i][w] = dp[i-1][w - weight] + value`

> 둘 중 더 큰 값을 선택
```
dp[i][w] = max(
dp[i-1][w],
dp[i-1][w - weight] + value
)
```
---
### 초기값
- `dp[0][*] = 0` (아무 물건도 고려하지 않았을 때 가치는 0)

## 핵심 포인트
- 물건 인덱스는 1부터 시작 
- dp 테이블 크기: (N+1) × (K+1)
- 이전 행(i-1)만 참조 → 순서 중요

---

## Java 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        int[][] dp = new int[N + 1][K + 1];

        for (int i = 1; i <= N; i++) {
            st = new StringTokenizer(br.readLine());
            int weight = Integer.parseInt(st.nextToken());
            int value = Integer.parseInt(st.nextToken());

            for (int w = 0; w <= K; w++) {
                dp[i][w] = dp[i - 1][w]; // 안 넣는 경우

                if (w >= weight) {
                    dp[i][w] = Math.max(
                        dp[i][w],
                        dp[i - 1][w - weight] + value
                    );
                }
            }
        }

        System.out.println(dp[N][K]);
    }
}
```
- 시간·공간 복잡도 
  - 시간 복잡도: O(N × K)
  - 공간 복잡도: O(N × K)
