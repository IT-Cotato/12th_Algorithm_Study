## BOJ 1987 문제 요약

- R×C 보드 위에서 (0,0)에서 시작
- 상하좌우로 이동할 수 있으며, 같은 알파벳은 한 번만 밟을 수 있음
- 만들 수 있는 최대 경로 길이를 구하는 문제

---

## 아이디어

- DFS + 백트래킹 사용
- 방문 경로의 알파벳을 Set<Character>로 관리
    - 알파벳 중복만 막으면 되므로 방문 체크는 Set으로 충분하여 visited 배열은 생략하였음
- 새 알파벳을 만나면 추가 → 재귀 탐색 → 탐색 후 제거

---

## 알고리즘 단계

1. 입력을 받아 보드를 char[][]에 저장
2. 시작 위치 (0,0)의 알파벳을 집합에 추가
3. DFS 탐색 시작
    - 현재 깊이 depth로 최대값 갱신
    - 상하좌우 이동
    - 이동한 칸의 알파벳이 아직 사용되지 않았다면 → 집합에 추가 후 재귀 호출
    - 탐색이 끝나면 다시 제거(백트래킹)
4. 모든 탐색이 끝난 후 최댓값 출력

---

## 코드

```java
import java.io.*;
import java.util.HashSet;
import java.util.Set;

public class Main {
    static int[] dr = {-1,1,0,0};
    static int[] dc = {0,0,-1,1};
    static int R, C, max = 0;
    static Set<Character> set;
    static char[][] board;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        R = Integer.parseInt(s[0]);
        C = Integer.parseInt(s[1]);
        board = new char[R][C];
        for (int i = 0; i < R; i++) {
            board[i] = br.readLine().toCharArray();
        }
        set = new HashSet<Character>();
        set.add(board[0][0]);
        dfs(0,0, 1);
        bw.write(max+"\n");
        bw.flush();
        bw.close();
    }
    static void dfs(int row, int col, int depth) {
        max = Math.max(max, depth);

        for(int i = 0; i < 4; i++) {
            int nextRow = row + dr[i];
            int nextCol = col + dc[i];
            if(nextRow>=0 && nextRow<R && nextCol>=0 && nextCol<C) {
                if(!set.contains(board[nextRow][nextCol])) {
                    set.add(board[nextRow][nextCol]);
                    dfs(nextRow, nextCol,depth + 1);
                    set.remove(board[nextRow][nextCol]);
                }
            }
        }
    }
}
```
