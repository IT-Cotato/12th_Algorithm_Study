# 📦 BOJ 1719 - 택배 (Special Judge)

## 🔍 문제 요약

- 집하장 `N`개, 경로 `M`개가 주어진다.
- 각 경로는 **양방향**이며 이동 시간이 존재한다.
- 모든 집하장 쌍 `(i, j)`에 대해  
  **i에서 j로 최단 경로로 갈 때 처음 이동해야 할 집하장**을 구한다.
- 이를 `N × N` **경로표** 형태로 출력한다.

---

## 🧠 핵심 개념 정리

### 1) 플로이드-워셜 (Floyd–Warshall)

- 모든 정점 쌍 최단 경로를 구하는 알고리즘
- 시간 복잡도: `O(N³)` (N ≤ 200이면 가능)
- 이 문제는 최단거리(`dist`)뿐 아니라, **첫 이동 지점(`next`)**도 같이 관리해야 한다.

### 2) dist 배열

- `dist[i][j]` : i → j 최단 이동 시간
- 초기화
  - `dist[i][i] = 0`
  - `dist[i][j] = INF (i != j)`
- 간선 입력 `(a, b, w)` 처리 (양방향)
  - 더 짧은 간선이면 `dist[a][b] = w`, `dist[b][a] = w`

### 3) next 배열 (경로표의 핵심)

- `next[i][j]` : i에서 j로 갈 때 **가장 먼저** 가야 하는 집하장 번호(= 첫 hop)
- 경로 전체를 저장하지 않고, **첫 이동만** 저장한다.
- 간선 입력 시(직접 연결)
  - `next[a][b] = b`
  - `next[b][a] = a`

---

## 🔄 플로이드 갱신 규칙

### 갱신 조건

`dist[i][k] + dist[k][j] < dist[i][j]`

### 갱신 내용

- `dist[i][j] = dist[i][k] + dist[k][j]`
- `next[i][j] = next[i][k]`

---

## ✅ 구현 (Node.js)

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

const [N, M] = input[0].split(" ").map(Number);
const INF = 1e15;

const dist = Array.from({ length: N + 1 }, () => Array(N + 1).fill(INF));
const next = Array.from({ length: N + 1 }, () => Array(N + 1).fill(0));

// dist 초기화
for (let i = 1; i <= N; i++) dist[i][i] = 0;

// 간선 입력
for (let idx = 1; idx <= M; idx++) {
  const [a, b, w] = input[idx].split(" ").map(Number);

  // 중복 간선이 있을 수 있으니 더 짧은 것만 반영
  if (w < dist[a][b]) {
    dist[a][b] = w;
    dist[b][a] = w;

    // 직접 연결이면 첫 hop은 상대 정점
    next[a][b] = b;
    next[b][a] = a;
  }
}

// 플로이드-워셜 + next 갱신
for (let k = 1; k <= N; k++) {
  for (let i = 1; i <= N; i++) {
    for (let j = 1; j <= N; j++) {
      if (dist[i][k] + dist[k][j] < dist[i][j]) {
        dist[i][j] = dist[i][k] + dist[k][j];
        next[i][j] = next[i][k];
      }
    }
  }
}

// 출력
const out = [];
for (let i = 1; i <= N; i++) {
  const row = [];
  for (let j = 1; j <= N; j++) {
    if (i === j) row.push("-");
    else row.push(String(next[i][j]));
  }
  out.push(row.join(" "));
}
console.log(out.join("\n"));
```
