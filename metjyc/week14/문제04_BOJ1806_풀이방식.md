# 부분합 - 최소 길이 연속 부분수열 (슬라이딩 윈도우)

## 📌 문제 요약

- 길이 `N`인 자연수 수열이 주어진다.
- 연속된 부분수열 중 **합이 S 이상**이 되는 것들 중
- **길이가 가장 짧은 부분수열의 길이**를 구한다.
- 조건을 만족하는 부분수열이 없다면 `0`을 출력한다.

---

## 🔑 핵심 조건

- 수열의 모든 원소는 **자연수(양수)**  
  → 이 조건 덕분에 **슬라이딩 윈도우(투 포인터)** 사용 가능

---

## 💡 사용 알고리즘: 슬라이딩 윈도우 (Two Pointer)

### 왜 슬라이딩 윈도우인가?

- 모든 수가 양수이기 때문에
  - 오른쪽 포인터를 늘리면 합이 **증가**
  - 왼쪽 포인터를 줄이면 합이 **감소**
- 이 성질로 불필요한 탐색 없이 **O(N)** 에 해결 가능

---

## 🧠 알고리즘 아이디어

1. `left`, `right` 두 포인터로 연속 구간을 표현
2. `right`를 증가시키며 합(`sum`)에 더한다
3. `sum >= S`가 되면:
   - 현재 구간 길이를 답 후보로 갱신
   - `left`를 이동시키며 가능한 한 구간을 줄인다
4. 끝까지 반복
5. 조건을 만족한 적 없으면 `0` 출력

---

## ⏱️ 시간 복잡도

- `right` 포인터: 최대 N번 이동
- `left` 포인터: 최대 N번 이동  
  ➡️ 전체 시간 복잡도 **O(N)**

---

## 🧾 예제 설명

입력:

10 15
5 1 3 5 10 7 4 9 2 8

- 부분수열 `[5, 10]`의 합이 15
- 길이 = 2 (가장 짧음)

출력: 2

---

## 🧑‍💻 Node.js 풀이 코드

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

const [N, S] = input[0].split(" ").map(Number);
const arr = input[1].split(" ").map(Number);

let left = 0;
let sum = 0;
let ans = Infinity;

for (let right = 0; right < N; right++) {
  sum += arr[right];

  while (sum >= S) {
    ans = Math.min(ans, right - left + 1);
    sum -= arr[left];
    left++;
  }
}

console.log(ans === Infinity ? 0 : ans);


⸻

⚠️ 주의할 점
	•	수열에 0이나 음수가 있으면 이 방식 불가능
	•	ans를 Infinity로 초기화한 이유:
	•	조건을 만족한 구간이 있는지 판단하기 위함
```
