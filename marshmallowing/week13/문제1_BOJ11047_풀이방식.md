## 백준 11047

### 문제 요약
여러 종류의 동전이 주어질 때,  
주어진 금액 `K`를 만들기 위해 필요한 **동전의 최소 개수**를 구하는 문제이다.

동전의 종류는 오름차순으로 주어지며,  
각 동전은 **항상 바로 이전 동전의 배수**라는 특징을 가진다.

### 핵심 아이디어

이 문제는 **그리디(Greedy) 알고리즘**을 이용해 해결할 수 있다.

> 가장 큰 동전부터 최대한 많이 사용하는 전략이  
> 항상 최적의 해를 보장한다.

### 접근 방법
1. 동전 배열을 입력받는다.
2. 가장 큰 동전부터 역순으로 순회한다.
3. 현재 동전으로 만들 수 있는 최대 개수 `k / coin`을 계산한다.
4. 사용한 동전 개수를 누적하고, 남은 금액으로 `k`를 갱신한다.
5. 모든 동전을 확인하면 최소 동전 개수가 완성된다.

### 시간 복잡도
- 동전 종류 수를 N이라 할 때 **O(N)**

---

### 구현 코드

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.util.StringTokenizer;

public class Main {
	public static void main(String[] args) throws Exception {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
		StringTokenizer st = new StringTokenizer(br.readLine());

		int n = Integer.parseInt(st.nextToken()); // 동전 종류
		int k = Integer.parseInt(st.nextToken()); // 총 합
		int count = 0;

		int[] arr = new int[n];

		for (int i = 0; i < n; i++) {
			st = new StringTokenizer(br.readLine());
			arr[i] = Integer.parseInt(st.nextToken());
		}
		
		/*
		 * - 항상 가장 큰 동전부터 사용한다.
		 * - 현재 금액 k에서 해당 동전을 최대 몇 개 쓸 수 있는지 계산
		 * - 사용한 만큼 k를 줄이고 다음 동전으로 이동
		 */

        // 가장 큰 동전부터 거꾸로 순회
		for (int i = n - 1; i >= 0; i--) {
		
			if (k >= arr[i]) {
			    // 현재 동전을 사용할 수 있는 최대 개수
				int c = k / arr[i];
				
				// 사용한 동전 개수 누적
				count += c;
				
				// 사용한 금액만큼 k 감소
				k -= c * arr[i];
			}
		}

		bw.write(String.valueOf(count));
		bw.flush();
		bw.close();
	}
}
