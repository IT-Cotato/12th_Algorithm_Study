🟦🟥 색종이 만들기 (분할 정복)

📌 문제 요약
• N×N 크기의 종이가 주어진다. (N = 2^k)
• 각 칸은 흰색(0) 또는 파란색(1)이다.
• 어떤 정사각형 영역이 모두 같은 색이면 더 이상 자르지 않고 색종이 1장으로 센다.
• 섞여 있다면 가로·세로로 반씩 잘라 4등분하고 같은 과정을 반복한다.
• 최종적으로 만들어진 흰색 색종이 개수와 파란색 색종이 개수를 구한다.

⸻

🧠 핵심 아이디어

이 문제는 분할 정복(Divide & Conquer) 문제이다. 1. 현재 정사각형 영역이 한 색으로만 이루어졌는지 검사 2. 한 색이면 → 해당 색 카운트 +1 3. 아니라면 → 영역을 4개로 나눠서 재귀적으로 처리

⸻

🔍 영역 검사 로직
• (x, y)를 시작점으로 size × size 영역을 확인
• 기준 색(map[x][y])과 다른 값이 하나라도 있으면 섞인 영역

function check(x, y, size) {
const base = map[x][y];

for (let i = x; i < x + size; i++) {
for (let j = y; j < y + size; j++) {
if (map[i][j] !== base) return false;
}
}
return true;
}

⸻

✂️ 분할 정복(재귀) 처리
• check 결과가 true → 색에 따라 카운트 증가
• false → size를 반으로 나눠 4개 영역으로 분할

4등분 좌표

(x, y) (x, y + half)
(x + half, y) (x + half, y + half)

function mapping(x, y, size) {
if (check(x, y, size)) {
if (map[x][y] === 0) white++;
else blue++;
return;
}

const half = size / 2;
mapping(x, y, half);
mapping(x, y + half, half);
mapping(x + half, y, half);
mapping(x + half, y + half, half);
}

⸻

▶️ 실행 흐름 1. 전체 종이에 대해 mapping(0, 0, N) 호출 2. 재귀적으로 분할하며 색종이 개수 누적 3. 최종 결과 출력

mapping(0, 0, N);
console.log(white);
console.log(blue);

⸻

⏱ 시간 복잡도
• 최악의 경우 모든 칸을 여러 번 검사
• O(N²)
(N ≤ 128 이므로 충분히 통과)

⸻

❗ 주의할 점
• 배열을 실제로 slice해서 자르지 말고 좌표 + size로 접근할 것
• mapping(0,0,N) 호출과 출력은 함수 밖에서 한 번만
• 섞임이 확인되면 즉시 분할 (불필요한 검사 X)
