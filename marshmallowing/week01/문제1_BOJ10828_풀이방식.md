# BOJ 10828 - 스택

## 문제
정수를 저장하는 스택을 구현한 다음, 입력으로 주어지는 명령을 처리하는 프로그램 작성.

### 명령어 종류
- `push X`: 정수 X를 스택에 넣는다.
- `pop`: 스택에서 가장 위의 정수를 빼고 출력. 없으면 -1 출력.
- `size`: 스택에 들어있는 정수의 개수 출력.
- `empty`: 스택이 비어있으면 1, 아니면 0 출력.
- `top`: 스택의 가장 위 정수 출력. 없으면 -1 출력.

---

## 풀이 아이디어
- Java에서 `Stack` 클래스는 오래된 구현체라 `Deque<Integer>`를 사용.
- `addLast` → push, `pollLast` → pop, `peekLast` → top 과 동일하게 동작.
- 입력이 많으므로 `BufferedReader`와 `BufferedWriter` 사용해 빠른 입출력 처리.

---

## 핵심 코드
```java
Deque<Integer> stack = new ArrayDeque<>();

if (command.equals("push")) {
    stack.addLast(x);
} else if (command.equals("pop")) {
    Integer pop = stack.pollLast();
    bw.write((pop == null ? -1 : pop) + "\n");
} else if (command.equals("top")) {
    Integer top = stack.peekLast();
    bw.write((top == null ? -1 : top) + "\n");
}
