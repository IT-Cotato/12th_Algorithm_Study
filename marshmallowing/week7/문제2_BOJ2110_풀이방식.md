# 백준 2110 풀이 정리 — 이분 탐색(Binary Search) 

## 1. 문제 요약

N개의 집이 1차원 직선 상에 있고, 집의 위치가 주어진다.  
C개의 공유기를 설치하려고 할 때,

- **서로 가장 가까운 두 공유기의 거리(=최소 거리)** 를
- **최대한 크게** 하려고 한다.

즉, 공유기 간 **최소 간격의 최대값**을 구하는 문제.

---

# 2. 핵심 코드

이 문제는 대표적인 **결정 문제(Decision Problem)** 형태: "최소 거리 D로 공유기 C개를 설치할 수 있는가?"

→ YES/NO 로 판단 가능하다.

이러한 문제는 **이분 탐색(Parametric Search)** 로 풀 수 있다.

---

# 3. 이분 탐색 진행 방식

- **가능하면(dist ≥ mid 로 공유기 설치 가능)** → 더 큰 거리로 도전  
  → `left = mid + 1`
- **불가능하면(dist < mid)** → 거리 줄여야 함  
  → `right = mid - 1`

마지막으로 가능한 최대 거리 right 값을 출력한다.

---

# 4. 시간 복잡도

- 정렬: O(N log N)
- 이분 탐색: O(log 1e9 ≈ 31)
- 결정 함수: O(N)

총 시간: **O(N log N)** → N ≤ 200,000 충분히 통과.

---

# 최종 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N, C;
    static int[] house;

    public static boolean canInstall(int mid) {
        int count = 1; 
        int last = house[0];

        for (int i = 1; i < N; i++) {
            if (house[i] - last >= mid) {
                count++;
                last = house[i];
            }
        }
        return count >= C;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        N = Integer.parseInt(st.nextToken());
        C = Integer.parseInt(st.nextToken());

        house = new int[N];

        for (int i = 0; i < N; i++) {
            house[i] = Integer.parseInt(br.readLine());
        }

        Arrays.sort(house);

        int left = 1;
        int right = house[N - 1] - house[0];
        int answer = 0;

        while (left <= right) {
            int mid = (left + right) / 2;

            if (canInstall(mid)) {
                answer = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        System.out.println(answer);
    }
}
