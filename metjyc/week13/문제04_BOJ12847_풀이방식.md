# 📌 슬라이딩 윈도우 (연속 구간 최대 합)

## 🧩 문제 요약

- n일 동안의 일급 정보가 주어진다.
- 일을 시작하면 **연속으로만** 일할 수 있다.
- 최대 **m일까지만** 일할 수 있다.
- 하루 일급은 모두 **양의 정수**이다.
- 벌 수 있는 **최대 이익**을 구하는 문제.

---

## 💡 핵심 포인트 정리

### 1️⃣ 연속 조건

- 일을 시작하면 중간에 쉬는 날이 있으면 안 된다.
- 즉, 선택 가능한 날들은 **연속된 구간**이어야 한다.

### 2️⃣ 최대 m일

- 일급이 모두 양수이므로  
  👉 **가능하다면 m일을 전부 채워서 일하는 것이 항상 이득**이다.

### 3️⃣ 문제 변환

> 길이가 m인 **연속 부분 배열** 중  
> **합이 가장 큰 값**을 구하면 된다.

---

## 🚀 해결 전략: 슬라이딩 윈도우

슬라이딩 윈도우는  
**연속된 구간의 합을 효율적으로 구하는 기법**이다.

### 왜 필요한가?

- 모든 구간을 매번 처음부터 더하면 → `O(n × m)` (느림 ❌)
- 이전 합을 재사용하면 → `O(n)` (빠름 ✅)

---

## 🔄 슬라이딩 윈도우 동작 방식

1. 처음 `m`일의 합을 구한다.
2. 하루씩 오른쪽으로 이동하면서:
   - **새로 들어오는 값은 더하고**
   - **빠지는 값은 뺀다**
3. 매번 최대값을 갱신한다.

---

## 🧪 예시

입력: n = 5, m = 3
일급 = [10, 20, 30, 20, 10]

연속 3일 합:

- 10 + 20 + 30 = 60
- 20 + 30 + 20 = 70 ✅
- 30 + 20 + 10 = 60

출력: 70

---

## 🧑‍💻 JavaScript 구현 코드

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const [n, m] = input[0].split(" ").map(Number);
const T = input[1].split(" ").map(Number);

// 첫 m일의 합 계산
let windowSum = 0;
for (let i = 0; i < m; i++) {
  windowSum += T[i];
}

let best = windowSum;

// 슬라이딩 윈도우 이동
for (let i = m; i < n; i++) {
  windowSum += T[i];       // 새로 들어온 날
  windowSum -= T[i - m];   // 빠진 날
  if (windowSum > best) best = windowSum;
}

console.log(best);

⏱ 시간 복잡도
	•	O(n)
	•	n ≤ 100,000 이므로 충분히 빠르게 통과 가능
```
