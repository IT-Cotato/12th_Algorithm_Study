# BOJ 14502 연구소 (벽 3개 + 바이러스 확산) 정리

## 문제 핵심
- 격자(`N x M`, `3 ≤ N,M ≤ 8`)에서
  - `0`: 빈 칸
  - `1`: 벽
  - `2`: 바이러스
- **반드시 벽 3개를 새로 세운 뒤**, 바이러스가 상하좌우로 퍼진 다음에도 `0`으로 남는 칸(안전 영역)의 **최댓값**을 구한다.

---

## 풀이 아이디어 (브루트포스 + BFS)
이 문제는 크게 두 단계의 조합이다.

1. **벽 3개 세우기 (조합/백트래킹)**
   - 빈 칸 좌표들을 `empties[]`에 모아둔다.
   - 그 중 3개를 **중복 없이** 고르는 모든 경우를 탐색한다.
   - 중복 방지 핵심: 재귀에서 `start` 인덱스를 사용하고 다음 호출에 `i + 1`을 넘긴다.

2. **바이러스 확산 시뮬레이션 (BFS)**
   - 현재 벽 배치가 반영된 `lab`를 `tmp`로 복사한다.
   - 모든 바이러스 좌표를 큐에 넣고 시작해 상하좌우로 퍼뜨린다.
   - 퍼뜨릴 때 조건은 딱 하나:
     - 다음 칸이 `0`(빈 칸)일 때만 `2`로 바꾸고 큐에 넣는다.
   - 확산 후 `tmp`에서 `0`의 개수를 세면 안전 영역 크기.

---

## 왜 시간 안 터짐?
- 최악의 빈 칸이 64개라 해도 벽 3개 조합 수는 `C(64,3)=41664` 정도.
- 각 케이스마다 BFS는 최대 64칸을 훑는다.
- 대략 `4만 * 64` 수준이라 제한 내에서 충분히 통과한다.

---

## 구현 포인트

### 1) 방향 배열(dx, dy)
상하좌우 탐색을 반복문으로 처리하기 위해 사용한다.

```js
const dx = [1, -1, 0, 0];
const dy = [0, 0, 1, -1];
```

### 2) 범위 체크
배열 인덱스는 `0 ~ N-1`, `0 ~ M-1` 범위만 유효하다.

```js
if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
```

### 3) visited 배열이 없어도 되는 이유
- 방문한 빈 칸은 `tmp[nx][ny] = 2`로 바꾸므로,
- 다시 방문하려고 해도 `tmp[nx][ny] === 0` 조건에서 걸러진다.
- 즉 **상태 변경 자체가 visited 역할**을 한다.

### 4) 가장 흔한 실수 TOP 4
1. `ny`를 `dy`로 잘못 선언해서 방향 배열과 충돌  
2. 범위 체크를 `>`로 써서 경계에서 터짐 (`>=` 사용)  
3. BFS 함수가 안전영역 숫자가 아니라 `tmp` 배열을 리턴  
4. `buildWalls(0,0)` 호출 / `console.log(answer)` 누락

## 코드 (Node.js, 최소 구성)

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

const [N, M] = input[0].split(" ").map(Number);
const lab = input.slice(1).map(line => line.split(" ").map(Number));

const empties = [];
const viruses = [];

for (let i = 0; i < N; i++) {
  for (let j = 0; j < M; j++) {
    if (lab[i][j] === 0) empties.push([i, j]); //0인 수 실험실에 푸시
    else if (lab[i][j] === 2) viruses.push([i, j]); // 2인 경우 바이러스 배열에 푸시
  }
}

// 좌우 탐색
const dx = [1, -1, 0, 0]; 
const dy = [0, 0, 1, -1];

let answer = 0;

function spreadAndCountSafe() {
  const tmp = lab.map(row => row.slice());

  const q = [];
  let head = 0;
  for (const [x, y] of viruses) q.push([x, y]);

  while (head < q.length) {
    const [x, y] = q[head++];

    for (let dir = 0; dir < 4; dir++) { //방향탐색
      const nx = x + dx[dir];
      const ny = y + dy[dir];

      if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;

      if (tmp[nx][ny] === 0) {
        tmp[nx][ny] = 2;
        q.push([nx, ny]);
      }
    }
  }

  let safe = 0;
  for (let i = 0; i < N; i++) {
    for (let j = 0; j < M; j++) {
      if (tmp[i][j] === 0) safe++;
    }
  }
  return safe;
}

function buildWalls(start, count) {
  if (count === 3) {
    const safe = spreadAndCountSafe();
    if (safe > answer) answer = safe;
    return;
  }

  for (let i = start; i < empties.length; i++) {
    const [x, y] = empties[i];

    lab[x][y] = 1;                // 벽 세우기
    buildWalls(i + 1, count + 1);  // 조합(중복 방지)
    lab[x][y] = 0;                // 원상복구(백트래킹)
  }
}

buildWalls(0, 0);
console.log(answer);
```

---

## 요약
- **벽 3개 선택(조합/백트래킹)** + **바이러스 확산(BFS)** 시뮬레이션
- 벽 배치는 `lab`에 적용하고, BFS는 `tmp` 복사본에서 수행
- 확산 후 `0` 개수를 세어 최댓값 갱신
