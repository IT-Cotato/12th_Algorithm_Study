# 슬라이딩 윈도우

> 슬라이딩 윈도우(Sliding Window)는 배열/문자열처럼 연속된 구간을 효율적으로 탐색하기 위한 알고리즘 패턴이다.

매번 처음부터 다시 계산하는 대신, 윈도우를 한 칸씩 이동시키면서 **새로 들어오는 값 추가 + 빠져나가는 값 제거** 방식으로 처리한다.

---

## 1. 슬라이딩 윈도우란?

연속된 구간을 다뤄야 하는 문제에서 기존 방식은 O(N*K)이 걸렸다면,  
슬라이딩 윈도우는 **한 번씩만 방문 → O(N)** 으로 처리 가능하다.

윈도우 = 구간 `[left, right]`  
윈도우 이동 =
- `right` 증가 → 요소 추가
- `left` 증가 → 요소 제거

---

## 2. 언제 사용하는가?

연속된 문제라면 대부분 가능:

- 길이가 **정해진 K** 구간의 합/평균/최대/최소
- 특정 조건을 만족하는 **부분 배열의 최소/최대 길이**
- 문자열 내 **중복 없는 가장 긴 부분 문자열**
- 합이 특정 조건 이상이 되는 **최단 연속 부분 배열**
- 투 포인터와 결합한 조건 탐색

---

## 3. 슬라이딩 윈도우 종류

### 1. 고정 길이(Fixed-size Window)
윈도우 크기 **K 고정**  
→ 항상 `right - left + 1 == K`

예: “길이 K의 부분 배열 중 최대합”

### 2. 가변 길이(Variable Window)
조건을 만족할 때까지 `right` 증가,  
조건이 깨지면 `left` 증가

예: “중복 없는 가장 긴 부분 문자열”

---

## 4. 자주 쓰는 패턴

### - 고정 길이
```java
for (right = 0; right < n; right++) {
    window += nums[right];
	if (right >= k) {
        window -= nums[right - k];
	}
}
```

### - 가변 길이 기본 형태
```java
while (right < n) {
    // 확장
    window 추가

    while (조건 불만족) {
        // 축소
        window 제거
        left++;
	}

    결과 갱신
    right++;
}
```
