# BOJ 21921 풀이 정리

## 문제 요약
- N일간 방문자 수가 주어진다.
- X일 동안의 **연속 방문자 수 합의 최대값**을 구하고,
- 그 **최대값이 나타나는 횟수**도 구한다.
- 만약 모든 X일 합이 0이면 `"SAD"` 출력.

---

# 핵심 아이디어 — 슬라이딩 윈도우 (Fixed-size Window)

X일이라는 **고정 길이의 연속 구간**이 필요하기 때문에  
슬라이딩 윈도우를 사용하면 시간복잡도를 O(N)으로 해결할 수 있다.

### - 윈도우 구조
- 오른쪽으로 이동하면서 값 1개 추가
- 윈도우 크기가 X가 되면 최대값 비교
- 왼쪽 값 제거하며 윈도우 유지

합(`sum`)은 윈도우 이동 시 계속 갱신되므로  
매번 X개를 다시 더할 필요 없음 → O(N)

---

# 알고리즘 흐름

1) X 크기 윈도우가 찰 때까지 방문자 수 추가
2) 윈도우가 X가 되면
    - 현재 합이 최대인지 비교
    - 최대면 갱신, 같으면 count++
3) 왼쪽 값 제거 (슬라이딩)
4) 끝까지 반복
5) 최대합이 0이면 "SAD" 출력

---

# 코드 

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringTokenizer st;

        st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int x = Integer.parseInt(st.nextToken());

        Deque<Integer> queue = new ArrayDeque<>();

        int sum = 0;
        int maxSum = 0;
        int maxDays = 0;

        st = new StringTokenizer(br.readLine());
        
        for (int i = 1; i <= n; i++) {
            int k = Integer.parseInt(st.nextToken());

            // 새로운 값 들어옴
            queue.addLast(k);
            sum += k;

            // 윈도우 크기 X 도달
            if (queue.size() == x) {
                if (sum > maxSum) {
                    maxSum = sum;
                    maxDays = 1;
                } else if (sum == maxSum) {
                    maxDays++;
                }
                
                // 왼쪽 값 제거 → 슬라이딩
                sum -= queue.removeFirst();
            }
        }

        if (maxSum == 0) {
            bw.write("SAD");
        } else {
            bw.write(maxSum + "\n");
            bw.write(String.valueOf(maxDays));
        }

        bw.flush();
    }
}
```
