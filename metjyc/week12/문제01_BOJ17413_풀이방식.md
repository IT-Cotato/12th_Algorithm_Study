# 📘 BOJ 17413 - 단어 뒤집기 2

## 🧩 문제 요약

문자열 `S`가 주어질 때,

- `< >` 로 감싸진 **태그 내부 문자열은 그대로 출력**
- 태그 **밖에 있는 단어만 뒤집어서 출력**
- 단어는 공백으로 구분
- 공백과 태그 구조는 원래 형태를 유지해야 한다

---

## 🧠 핵심 아이디어

이 문제는 알고리즘 계산 문제가 아니라  
**문자열을 한 글자씩 해석하는 파싱 문제**다.

핵심은 현재 위치가

- **태그 안인지**
- **태그 밖인지**

를 구분하는 것이다.

---

## 🛠 사용 개념

- 문자열 파싱 (Character Parsing)
- 스택 (LIFO → 문자열 뒤집기)
- 상태 플래그 (`inTag`)

---

## 🔄 처리 전략

### 상태 변수

- `inTag` : 현재 `< >` 태그 내부인지 여부
- `stack` : 태그 밖에서 단어를 뒤집기 위한 스택
- `out` : 최종 출력 결과를 저장하는 배열

---

### 문자 처리 규칙

1. `<`를 만나면

   - 스택에 쌓인 단어를 먼저 뒤집어 출력
   - 태그 시작 → `inTag = true`
   - `<`는 그대로 출력

2. 태그 안(`inTag === true`)

   - 모든 문자를 그대로 출력
   - `>`를 만나면 태그 종료 → `inTag = false`

3. 태그 밖에서 공백을 만나면

   - 현재 단어를 뒤집어 출력
   - 공백 출력

4. 태그 밖에서 문자/숫자를 만나면

   - 스택에 push

5. 문자열 순회가 끝난 후
   - 스택에 남아 있는 단어를 뒤집어 출력

---

## 💻 Node.js 코드

```js
const fs = require("fs");
const S = fs.readFileSync(0, "utf8").trimEnd();

let inTag = false;
let stack = [];
let out = [];

for (let i = 0; i < S.length; i++) {
  const ch = S[i];

  if (ch === "<") {
    while (stack.length) out.push(stack.pop());
    inTag = true;
    out.push(ch);
    continue;
  }

  if (inTag) {
    out.push(ch);
    if (ch === ">") inTag = false;
    continue;
  }

  if (ch === " ") {
    while (stack.length) out.push(stack.pop());
    out.push(" ");
  } else {
    stack.push(ch);
  }
}

while (stack.length) out.push(stack.pop());

console.log(out.join(""));
```
