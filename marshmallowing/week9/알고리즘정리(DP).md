# Dynamic Programming

## 1. DP란 무엇인가?

**동적 계획법(Dynamic Programming)** 은  
- **큰 문제를 작은 부분 문제로 나누어 해결**하고  
-  **이미 계산한 결과를 저장하여 재사용**함으로써  
- **중복 계산을 제거**하는 알고리즘 기법이다.

주로 **최적화 문제(최댓값/최솟값)** 에 사용된다.

---

## 2. DP가 적용되는 조건

### 1. 최적 부분 구조
- 큰 문제의 최적해가 **작은 문제들의 최적해**로 구성됨

### 2. 중복 부분 문제
- 같은 부분 문제가 **여러 번 반복**해서 등장함

---

## 3. DP 구현 방식

### 1. Top-Down (재귀 + 메모이제이션)

- 큰 문제에서 시작하여 작은 문제로 재귀적으로 호출하며 내려가는 방식
- 한 번 계산한 결과를 배열(또는 Map)에 저장해 두었다가, 같은 작은 문제가 다시 호출되면 저장된 결과를 즉시 반환(Memoization)

```java
// Java 예시: 피보나치 수열 (Top-Down, Memoization)
// memo 배열: 계산 결과를 저장하는 DP 테이블 (0으로 초기화)
private static long[] memo = new long[100];

public static long fibonacci_topdown(int n) {
	// Base Case
	if (n <= 1) return n;

	// Memoization: 이미 계산된 값이 있다면 바로 반환
	if (memo[n] > 0) {
		return memo[n];
	}

	// 재귀 호출 및 결과 저장
	memo[n] = fibonacci_topdown(n - 1) + fibonacci_topdown(n - 2);
	return memo[n];
}
```
- 특징 
  - 필요한 부분 문제만 계산
  - 문제의 점화식을 그대로 코드로 옮기기 쉬워 직관적
  - 재귀 호출이 많아 스택 오버플로우(Stack Overflow) 위험

### 2. Bottom-Up (반복문)

- 가장 작은 문제부터 시작하여(바닥부터), 반복문을 통해 점진적으로 큰 문제의 해를 구하면서 결과를 테이블(배열)에 채워나가는 방식
- 재귀 호출 없이 반복문으로 구현되므로, 일반적으로 스택 오버플로우 위험이 없고 성능 면에서 더 효율적일 수 있음

```java
// Java 예시: 피보나치 수열 (Bottom-Up, Tabulation)
public static long fibonacci_bottomup(int n) {
	if (n <= 1) return n;

	// DP 테이블 정의 및 초기값 설정
	long[] dp = new long[n + 1];
	dp[0] = 0;
	dp[1] = 1;

	// 반복문을 사용하여 테이블을 바닥(작은 문제)부터 채움
	for (int i = 2; i <= n; i++) {
		// 점화식: DP[i] = DP[i-1] + DP[i-2]
		dp[i] = dp[i - 1] + dp[i - 2];
	}

	return dp[n];
}
```
- 특징 
  - 재귀 호출이 없어 스택 오버플로우 위험이 없으며, 반복문 기반이라 실행 속도가 일반적으로 더 빠름
  - 문제 전체를 해결하기 위해 필요하지 않은 부분 문제까지 모두 계산할 수도 있음
  - 실전에서는 Bottom-Up을 더 많이 사용
---
## 4. DP 알고리즘 설계의 4단계
1. 점화식 정의: 문제의 해답을 작은 문제의 해답을 이용하여 표현하는 수학적 관계식 (점화식)을 세운다. 
    - (예: DP[i] = DP[i-1] + DP[i-2])
2. DP 테이블 정의: 정의한 점화식의 값을 저장할 배열 또는 테이블의 크기와 형태를 결정
3. 초기값 설정: 테이블의 가장 작은 값(Base Case, 예: DP[0], DP[1])을 설정
4. 반복/재귀 구현: 설정된 점화식과 초기값을 사용하여 나머지 DP 테이블을 채움

| 구분   | 특징             |
| ---- | -------------- |
| DP   | 중복 문제 + 저장     |
| 그리디  | 매 순간 최적 선택     |
| 분할정복 | 문제 분할, 결과 저장 X |
