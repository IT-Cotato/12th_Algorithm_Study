## 최단 경로 알고리즘

- 그래프 상에서 노드 간의 탐색 비용을 최소화하는 알고리즘

## 다익스트라

### 01. “다익스트라” 란?

- 다익스트라 알고리즘은 음의 가중치(음의 간선, 음의 값)가 없는 그래프의 한 노드에서 각 모든 노드까지의 최단거리를 구하는 알고리즘
- 간선들의 가중치가 같다면 bfs 를 사용해서 최단거리를 구할 수 있지만 다르다면 다익스트라 알고리즘을 사용해야 함
- 기본적으로 그리디 알고리즘 + 다이나믹 프로그래밍 기법을 사용한 알고리즘

  (1) 방문하지 않은 노드 중에서 가장 비용이 적은 노드를 선택한다(그리디 알고리즘)

  (2) 해당 노드로부터 갈 수 있는 노드들의 비용을 갱신한다(다이나믹 프로그래밍)

- 가장 가까운 정점을 하나씩 확정하면서, 그 정점에서 이어지는 간선들을 이용해 인접 정점의 거리를 갱신하고, 값이 줄어든 정점들을 우선순위 큐에 넣는 알고리즘
- 우선순위 큐를 사용하여 개선된 다익스트라를 만들 수 있음

    ```java
    PriorityQueue<Node> q = new PriorityQueue<Node>((o1, o2) 
    	-> Integer.compare(o1.cost, o2.cost)); 
    ```


### 02. 구현 방법

1. Node 클래스 생성 (인덱스, 가중치)
2. dist 배열 (최단거리 저장), INF(=Integer.MAX_VALUE)로 초기화
3. dist[start] = 0, 우선순위 큐에 삽입
4. 큐에서 최소 비용 노드를 꺼내고, 인접 노드 거리 갱신
5. 큐가 빌 때까지 반복

```java
static class Node {
    int index, cost;
    Node(int index, int cost) {
        this.index = index;
        this.cost = cost;
    }
}

PriorityQueue<Node> pq = new PriorityQueue<>((a,b) -> a.cost - b.cost);
boolean[] visited = new boolean[N + 1];
dist[start] = 0;
pq.add(new Node(start, 0));

while(!pq.isEmpty()) {
    Node now = pq.poll();
    if (visited[next.index]) continue; // 확정된 곳은 안 봐도 됨
		visited[now.index] = true;
		
    for(Node next : graph[now.index]) {
        if(dist[next.index] > dist[now.index] + next.cost) {
            dist[next.index] = dist[now.index] + next.cost;
            pq.add(new Node(next.index, dist[next.index]));
        }
    }
}
```

## 벨만 포드

### 01. “벨만 포드” 란?

- 그래프에서 음수 가중치를 가진 간선이 있을 때 최단거리를 구하는 알고리즘
- 한 노드에서 다른 모든 노드까지의 최단거리를 구하는 알고리즘 + 음수 사이클 존재 여부를 알 수 있음
- 다익스트라 알고리즘과의 비교
    - 공통점 : 특정 노드에서 다른 모든 노드까지의 최단 거리를 탐색
    - 차이점 : 벨만 포드 알고리즘은 다익스트라 알고리즘과 다르게 음수 간선이 포함되어 있어도 최단 경로를 구할 수 있음
- 음수 사이클 존재 여부도 판별 가능
    - (N-1번 반복해 갱신 후, N번째에서도 갱신되면 음수 사이클 존재)

### 02. 구현 방법

1. Edge 클래스 생성 (시작, 끝, 가중치)
2. dist 배열을 INF로 초기화
3. 최단 거리 갱신 과정을 모든 간선에 대해 N-1번 반복
4. N번째에 갱신되면 음수 사이클 존재

```java
static class Edge {
    int start, end;
    long cost;
    Edge(int start, int end, long cost) {
        this.start = start; this.end = end; this.cost = cost;
    }
}

for (int i = 1; i < N; i++) {
    for (Edge e : edges) {
        if(dist[e.start] == INF) continue;
        if(dist[e.end] > dist[e.start] + e.cost) {
            dist[e.end] = dist[e.start] + e.cost;
        }
    }
}

// 음수 사이클 판별
boolean hasCycle = false;
for (Edge e : edges) {
    if(dist[e.start] != INF && dist[e.end] > dist[e.start] + e.cost) {
        hasCycle = true;
        break;
    }
}
```

## 플로이드-워셜

### 01. “플로이드-워셜” 이란?

- 시작점을 정하지 않고 모든 노드에서 모든 노드까지의 최단 경로를 구하는 알고리즘
- 음수 간선 허용 (단, 음수 사이클은 허용 X)
- 다이나믹 프로그래밍 기법을 사용한 알고리즘
- 시간복잡도 : O(V^3) (V:노드의 수)로 시간복잡도가 큼

### 02. 구현 방법

1. dist 배열을 이차원 배열로 구현
2. 삼중 for문을 돌면서 모든 노드 쌍 (i, j)에 대해 중간 노드 k를 거쳤을 때 더 짧은 경로가 있으면 갱신

```java
for(int k=1; k<=N; k++) {       // 중간점
    for(int i=1; i<=N; i++) {   // 시작점
        for(int j=1; j<=N; j++) { // 도착점
            if(dist[i][k] == INF || dist[k][j] == INF) continue;
            dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
        }
    }
}
```
