# 2×n 타일 채우기 (BOJ 11726) - DP 정리

## 문제 요약

- 크기 `2×n` 직사각형을 다음 타일로 채운다.
  - `1×2` (가로)
  - `2×1` (세로)
- 채우는 **방법의 수**를 구하고, 결과를 `10007`로 나눈 나머지를 출력한다.
- 입력 범위: `1 ≤ n ≤ 1000`

---

## 핵심 아이디어 (Dynamic Programming)

큰 문제 `2×n`을 **오른쪽 끝(마지막 부분)** 을 기준으로 작은 문제로 쪼개면, 같은 형태의 문제가 반복된다.

---

## DP 상태 정의 (State)

`dp[i] = 2×i 직사각형을 채우는 방법의 수 (mod 10007)`

---

## 점화식 (Transition)

`2×i`의 **맨 오른쪽을 어떻게 채우는지**로 경우를 나눈다.

### 1) 마지막 열을 세로 타일(2×1) 1개로 채우는 경우

- 오른쪽 끝 1열을 세로 타일로 채우면
- 남는 영역은 `2×(i-1)`
- 경우의 수: `dp[i-1]`

### 2) 마지막 2열을 가로 타일(1×2) 2개로 채우는 경우

- 위 칸/아래 칸에 가로 타일 2개를 놓으면
- 남는 영역은 `2×(i-2)`
- 경우의 수: `dp[i-2]`

✅ 따라서:

```
dp[i] = dp[i-1] + dp[i-2]
dp[i] = (dp[i-1] + dp[i-2]) % 10007
```

---

## 초기값 (Base Case)

- `dp[1] = 1`
  - `2×1`은 세로 타일 1개만 가능
- `dp[2] = 2`
  - `2×2`는
    - 세로 2개
    - 가로 2개
  - 총 2가지

---

## 계산 순서 (Bottom-up)

`dp[1]`, `dp[2]`를 먼저 채우고, `dp[3]`부터 `dp[n]`까지 순서대로 계산한다.

---

## 예시 (n = 5)

- `dp[1] = 1`
- `dp[2] = 2`
- `dp[3] = 2 + 1 = 3`
- `dp[4] = 3 + 2 = 5`
- `dp[5] = 5 + 3 = 8`

---

## 시간/공간 복잡도

- 시간 복잡도: `O(n)` (1부터 n까지 한 번씩 계산)
- 공간 복잡도: `O(n)` (dp 배열 저장)

---

## Node.js 풀이 템플릿 (Bottom-up)

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim();
const n = Number(input);

const MOD = 10007;
const dp = Array(n + 1).fill(0);

dp[1] = 1;
if (n >= 2) dp[2] = 2;

for (let i = 3; i <= n; i++) {
  dp[i] = (dp[i - 1] + dp[i - 2]) % MOD;
}

console.log(dp[n]);
```

---

## 한 줄 요약

> `2×n` 타일 채우기는 오른쪽 끝 기준으로  
> `세로 1개 → dp[n-1]`, `가로 2개 → dp[n-2]`  
> 그래서 `dp[n] = dp[n-1] + dp[n-2]` 이다.
