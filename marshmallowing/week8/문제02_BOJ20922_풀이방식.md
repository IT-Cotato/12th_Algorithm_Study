# BOJ 20922 풀이 정리

## 문제 요약
- 길이 N의 수열에서  
  **같은 정수가 K번 이하로만 등장하는 가장 긴 연속 부분 수열의 길이**를 구하는 문제.

- 즉, 연속 부분 수열에서  
  `count[x] ≤ K` 조건을 만족하는 최대 길이를 찾는 문제.

---

# 핵심 아이디어 — 가변 길이 슬라이딩 윈도우

이 문제는 **정해진 최대 빈도(K)를 넘지 않는 가장 긴 연속 구간**을 찾는 문제이므로  
가변 길이 슬라이딩 윈도우를 사용한다.

윈도우 `[left, right]`를 확장하면서:

1. `right`를 증가시키며 값 추가
2. 추가한 값의 등장 횟수가 `K`를 초과하면  
   → `left`를 증가시키며 초과한 값을 제거
3. 조건을 만족하는 동안 최대 길이를 갱신

---

# 사용한 자료구조

- `arr[x]` : 값 x가 현재 윈도우 안에서 몇 번 등장하는지
- `deleteArr[i]` : 각 인덱스의 원래 값 저장
- `deletePosition` : 슬라이딩 윈도우의 left 역할

---

# 알고리즘 흐름 

1. 값 하나씩 읽으면서 등장 횟수 증가
2. 만약 등장 횟수가 K 이하라면
    - 윈도우 안에 들어갈 수 있음 → 길이 증가
3. 등장 횟수가 K 초과되면
    - 현재 길이를 maxLength와 비교
    - 왼쪽(deletePosition)을 이동시키며  
      등장 횟수를 줄여 **K 이하가 될 때까지 반복**
4. 종료 후 마지막 length도 비교

---

# 코드 

```java
import java.io.*;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringTokenizer st;

        st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        int[] arr = new int[100001];  // 등장 횟수 카운팅
        int[] deleteArr = new int[n]; // 입력값 저장용

        int length = 0;      // 현재 윈도우 길이
        int maxLength = 0;   // 최대 길이
        int deletePosition = 0; // left 포인터

        st = new StringTokenizer(br.readLine());

        for (int i = 0; i < n; i++) {
            int x = Integer.parseInt(st.nextToken());
            deleteArr[i] = x;

            arr[x]++;  // 등장 횟수 증가

            if (arr[x] <= k) {
                // 조건 만족 → 윈도우 확장
                length++;
            } else {
                // 조건 위반 → 윈도우 축소
                maxLength = Math.max(maxLength, length);

                // left 포인터를 옮기며 등장 횟수 줄이기
                for (int j = deletePosition; j <= i; j++) {
                    arr[deleteArr[j]]--;  // 윈도우에서 제거
                    if (deleteArr[j] == x) {
                        deletePosition = j + 1; // left 위치 업데이트
                        break;
                    }
                    length--; // 조건 만족할 때까지 길이 감소
                }
            }
        }

        maxLength = Math.max(maxLength, length);

        bw.write(String.valueOf(maxLength));
        bw.flush();
    }
}
```
