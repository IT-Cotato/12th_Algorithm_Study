## 그리디 알고리즘 (탐욕 알고리즘)

### 01. “그리디 알고리즘” 이란?

- 동적 프로그래밍 사용 시 지나치게 많은 일을 한다는 것에서 착안하여 고안된 알고리즘으로 현재 상황에서 가장 최적이라고 생각되는 것을 선택해 나가는 방식으로 최종 해답에 도달하는 알고리즘
- 각 단계의 최적 선택이 모여 최종적으로 전체 문제의 최적해를 만들 것이라고 가정
- 각 단계에서 가장 좋은 선택을 하지만 전체 문제의 최적해를 항상 보장하지는 않는다는 특징이 있음
    - 현재의 최적 선택이 미래의 더 나은 결과를 망칠 수 있기 때문에 항상 최적의 해를 보장하지는 못 함

### 02. 그리디 알고리즘을 보장하는 조건

- 탐욕적 선택 속성
    - 각 단계에서 최선의 선택을 했을 때 전체 문제에 대한 최적해 구할 수 있는 경우
    - 매 단계에서의 국소적으로 최선의 선택을 먼저 해도, 그 선택을 포함하는 전역 최적해가 존재한다는 성질
- 최적 분해 구조
    - 전체 문제의 최적해가 부분 문제의 최적해로 구성될 수 있는 경우
    - 전체 문제를 작은 부분 문제로 나누어 각각의 부분 문제에서 최적의 해를 구한 후 이를 조합하여 전체 문제의 최적해를 구하는 것을 말함

### 03. 그리디 알고리즘 단계 (ex. 거스름돈 문제)

1. 선택 절차 : 문제의 구조에 맞게 선택 절차를 정의함

   ex) 거스름돈 문제에서 가장 가치가 큰 동전부터 선택

2. 적절성 검사 : 선택된 해가 문제의 조건을 만족하는지 검사함

   ex) 만약 선택된 동전의 가치가 거스름돈보다 크다면 다음으로 작은 동전을 선택

3. 해답 검사 : 모든 선택이 완료되면 해답을 검사함

   ex) 합이 일치하면 거스름돈 문제 해결
