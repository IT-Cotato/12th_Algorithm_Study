# 📘 이분 탐색 (Binary Search)

## 📖 개념 정리

이분 탐색(Binary Search)은 **정렬된 배열**에서 원하는 값을 빠르게 찾기
위한 탐색 알고리즘이다.\
탐색 범위를 절반씩 줄여 나가기 때문에, **O(log N)**의 시간 복잡도로 매우
효율적이다.

즉, 중간값(`mid`)을 기준으로 **찾고자 하는 값(target)**이 왼쪽에 있는지,
오른쪽에 있는지를 판단하며 탐색 범위를 좁혀나간다.

---

## ⚙️ 동작 과정

1.  **배열의 시작점(`low`)과 끝점(`high`)을 설정한다.**

2.  **중간 인덱스(`mid`)를 계산한다.**

    ```js
    mid = Math.floor((low + high) / 2);
    ```

3.  **`mid` 위치의 값과 `target`을 비교한다.**

    - `arr[mid] === target` → 탐색 성공 (값 반환)
    - `arr[mid] < target` → 오른쪽 구간 탐색 (`low = mid + 1`)
    - `arr[mid] > target` → 왼쪽 구간 탐색 (`high = mid - 1`)

4.  `low`가 `high`보다 커질 때까지 반복한다. (탐색 실패 시 종료)

---

## 💻 예제 코드 (JavaScript)

### 🔹 기본 구현 (오름차순 배열 기준)

```js
function binarySearch(arr, target) {
  let low = 0;
  let high = arr.length - 1;

  while (low <= high) {
    const mid = Math.floor((low + high) / 2);

    if (arr[mid] === target) {
      return mid; // 찾은 경우 인덱스 반환
    } else if (arr[mid] < target) {
      low = mid + 1; // 오른쪽 탐색
    } else {
      high = mid - 1; // 왼쪽 탐색
    }
  }

  return -1; // 찾지 못한 경우
}

const arr = [1, 3, 5, 7, 9, 11];
console.log(binarySearch(arr, 7)); // ✅ 출력: 3
```

## 📊 시간 복잡도

---

구분 복잡도 설명

---

최선의 경우 `O(1)` 중간값이 바로
`target`일 때

평균/최악의 경우 `O(log N)` 매 단계마다 탐색
범위를 절반으로 줄임

---

> 👉 선형 탐색(`O(N)`)보다 훨씬 빠르며, **정렬된 데이터**에서만 적용
> 가능하다.

---

## 🧠 주의할 점

---

주의 항목 설명

---

🔸 **정렬 필수** 배열이 정렬되어 있지 않으면 올바른
결과를 보장할 수 없음

🔸 **중간 인덱스 계산** `(low + high) / 2` 대신
`Math.floor((low + high) / 2)`로
정수화해야 함

🔸 **무한 루프 주의** 조건문(`low <= high`)과 인덱스
갱신(`+1`, `-1`)을 정확히 해야 함

---

## 🧾 요약 정리

항목 내용

---

**이름** 이분 탐색 (Binary Search)
**전제 조건** 데이터가 정렬되어 있어야 함
**핵심 아이디어** 중간값을 기준으로 탐색 범위를 반씩 줄여나감
**시간 복잡도** `O(log N)`
**공간 복잡도** `O(1)`
**활용 분야** 탐색, 최적화, 매개변수 탐색 등

---

📚 **Tip:**\
이분 탐색은 단순 탐색보다 "답이 존재하는 범위"를 기준으로 탐색 범위를
좁혀가는 **사고방식 자체**를 익히는 것이 핵심이다.
