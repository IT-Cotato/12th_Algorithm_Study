📌 BOJ 20922 — 겹치는 건 싫어

🔍 문제 요약
• 길이 N인 수열이 주어진다.
• 같은 정수가 최대 K개 이하로만 포함되도록 하는
• 가장 긴 연속 부분 수열의 길이를 구하는 문제.

⸻

📥 입력 조건
• 1 ≤ N ≤ 200,000
• 1 ≤ K ≤ 100
• 1 ≤ a_i ≤ 100,000

⸻

📤 출력
• 조건을 만족하는 최장 연속 부분 수열의 길이

⸻

💡 핵심 아이디어

✅ 슬라이딩 윈도우 (Two Pointer)
• 연속 부분 수열이므로 정렬 ❌
• 모든 경우를 탐색하면 O(N²) → 시간 초과
• 두 포인터(left, right) 를 사용해 O(N)으로 해결

⸻

🧠 접근 방법 1. right 포인터를 오른쪽으로 이동하며 숫자를 추가 2. 각 숫자의 등장 횟수를 count 배열로 관리 3. 어떤 숫자가 K개를 초과하면
• left 포인터를 이동하며 조건을 다시 만족할 때까지 줄이기 4. 매 순간 right - left + 1로 최대 길이 갱신

⸻

🧩 알고리즘 흐름

left = 0
for right = 0 → N-1
count[arr[right]]++

while count[arr[right]] > K
count[arr[left]]--
left++

answer = max(answer, right - left + 1)

⸻

⏱️ 시간 & 공간 복잡도

구분 복잡도
시간 O(N)
공간 O(100000) (숫자 등장 횟수 배열)

⸻

// BOJ 20922 - 겹치는 건 싫어

const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split(/\s+/).map(Number);

let idx = 0;
const N = input[idx++];
const K = input[idx++];

const arr = input.slice(idx, idx + N);

// 각 숫자의 등장 횟수 (ai ≤ 100000)
const cnt = new Array(100001).fill(0);

let left = 0;
let answer = 0;

for (let right = 0; right < N; right++) {
const x = arr[right];
cnt[x]++;

// 같은 숫자가 K개 초과하면 왼쪽 포인터 이동
while (cnt[x] > K) {
cnt[arr[left]]--;
left++;
}

// 현재 윈도우 길이 갱신
answer = Math.max(answer, right - left + 1);
}

console.log(answer.toString());
