## BOJ 17413 문제 요약

- 한 줄 문자열이 주어진다.
- 문자열에는 일반 단어, 공백, 태그가 섞여 있다.
- 태그는 < 로 시작해서 > 로 끝나는 구간이며, 태그 안의 문자열은 뒤집지 않는다.
- 태그 밖의 단어들은 공백 기준으로 나뉘며, 각 단어를 뒤집어서 출력한다.
- 최종 변환된 문자열을 출력하는 문제

---

## 아이디어

- 태그 밖 단어는 뒤집어야 하므로, 문자를 스택(Deque)에 쌓았다가 한 번에 꺼내며 출력한다.
- 태그 안은 원본 그대로 출력해야 하므로, 현재 태그 안인지 여부를 boolean(check)로 관리한다.
- 중요한 전환 지점
    - < 를 만나면: 지금까지 쌓인 단어를 먼저 뒤집어 출력하고, 태그 모드로 들어간다.
    - > 를 만나면: 해당 문자까지 그대로 출력하고, 태그 모드를 끝낸다.
    - 공백을 만나면: 지금까지 쌓인 단어를 뒤집어 출력하고, 공백 출력 후 다음 단어를 새로 시작한다.
- 문자열을 끝까지 처리한 뒤에도 스택에 남아있는 문자가 있을 수 있으므로 마지막에 한 번 더 비운다.

---

## 알고리즘 단계

1. 문자열 str을 입력받는다.
2. 뒤집기용 스택 역할로 ArrayDeque<Character> stack을 준비한다.
3. 현재 태그 안인지 나타내는 check 변수를 false로 둔다.
4. str을 왼쪽부터 끝까지 순회한다.
5. 각 문자 처리
    - check가 true(태그 안)인 경우
        - 문자를 그대로 출력한다.
        - 만약 문자가 > 이면 check를 false로 바꿔 태그 밖으로 나간다.
    - check가 false(태그 밖)인 경우
        - 문자가 < 이면
            1. stack에 쌓인 단어를 모두 뒤집어 출력한다.
            2. check를 true로 바꾸고 < 를 출력한다.
        - 문자가 공백이면
            1. stack에 쌓인 단어를 모두 뒤집어 출력한다.
            2. 공백을 출력한다.
        - 그 외 일반 문자면
            - stack에 문자를 추가한다. (나중에 뒤집어서 출력하기 위함)
6. 문자열 순회가 끝나면 stack에 남아있는 문자(마지막 단어)를 모두 뒤집어 출력한다.
7. 출력 버퍼를 flush하고 종료한다.

---

## 코드

```java
import java.io.*;
import java.util.ArrayDeque;
import java.util.Deque;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String str = br.readLine();
        ArrayDeque<Character> stack = new ArrayDeque<>();
        boolean check = false;
        for (int i = 0; i < str.length(); i++) {
            if(check) { // 괄호 안의 문자인 경우에는 그대로 출력
                if(str.charAt(i) == '>')
                    check = false;
                bw.write(str.charAt(i));
            }
            else if(str.charAt(i) == '<') { // 괄호 시작의 경우(기존에 있던 stack 내용 모두 꺼냄)
                while(!stack.isEmpty()) {
                    bw.write(stack.pollLast());
                }
                check = true;
                bw.write(str.charAt(i));
            }
            else if(str.charAt(i) == ' ') { // 괄호 안에 있는 띄어쓰기가 아닌 경우(stack에 있는 내용 모두 꺼내고 새로운 stack을 시작해야함)
                while(!stack.isEmpty()) {
                    bw.write(stack.pollLast());
                }
                bw.write(str.charAt(i));
            }
            else stack.add(str.charAt(i)); // 모두 아닌 경우 거꾸로 출력하기 위해 stack 에 넣음
        }
        while(!stack.isEmpty()) { // 출력되지 않은 stack에 있는 문자들 모두 출력
            bw.write(stack.pollLast());
        }
        bw.flush();
        bw.close();
    }
}
```
