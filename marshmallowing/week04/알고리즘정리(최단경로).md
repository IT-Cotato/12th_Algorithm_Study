# 최단경로 알고리즘 정리

## 다익스트라 (Dijkstra)
- 시작점 하나에서 모든 정점으로의 최단거리
- 가중치가 모두 양수일 때 사용
- 방문하지 않은 정점 중 가장 가까운 정점을 우선 선택해 확정

### 작동 방식
1. `dist[start] = 0`, 나머지는 INF
2. PQ에 `(정점, 거리)` 저장
3. 현재 최소 거리의 정점을 꺼내서 인접 정점을 릴랙스(relax):
4. 이미 더 짧은 거리로 방문된 정점은 무시 (lazy deletion)

### 핵심 코드
```java
PriorityQueue<Node> pq = new PriorityQueue<>();
dist[start] = 0;
pq.offer(new Node(start, 0));

while (!pq.isEmpty()) {
 Node cur = pq.poll();
 if (cur.w > dist[cur.v]) continue;

 for (Node next : graph[cur.v]) {
     if (dist[next.v] > dist[cur.v] + next.w) {
         dist[next.v] = dist[cur.v] + next.w;
         pq.offer(new Node(next.v, dist[next.v]));
     }
 }
}
```

## 벨만-포드 (Bellman–Ford)
- 용도: 단일 시작점, 음수 간선 포함 가능
- 시간복잡도: O(VE)
- 핵심: 모든 간선 릴랙스 V-1번 반복
- 추가: V번째에도 갱신 있으면 음수 사이클 존재

### 작동 방식
1. 모든 정점의 거리를 INF로 초기화, 시작점은 0 
2. V-1번 반복: 모든 간선(u, v, w)에 대해
3. V번째 반복에서도 갱신이 일어나면 → 음수 사이클 존재

### 핵심 코드
```java
for (int i = 1; i < V; i++) {
for (Edge e : edges) {
if (dist[e.u] != INF && dist[e.v] > dist[e.u] + e.w)
dist[e.v] = dist[e.u] + e.w;
}
}

// 음수 사이클 검출
for (Edge e : edges) {
if (dist[e.u] != INF && dist[e.v] > dist[e.u] + e.w)
System.out.println("Negative Cycle Detected");
}
```

## 플로이드-워셜 (Floyd–Warshall)
- 용도: 모든 쌍 최단경로
- 시간복잡도: O(N³)
- 핵심: k를 경유지로 두고 3중 for문으로 최소값 갱신
- 장점: 구현 단순, 음의 간선 가능
- 단점: 느림, N 커지면 비효율

### 핵심 코드
```java
for (int k = 1; k <= n; k++) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (dist[i][k] + dist[k][j] < dist[i][j])
                dist[i][j] = dist[i][k] + dist[k][j];
        }
    }
}
```
---

| 알고리즘 | 용도 | 음수 간선 | 시간복잡도 | 특징 |
|-----------|--------|------------|-------------|--------|
| Dijkstra | 단일 출발점 | X | O(E log V) | 빠르고 실용적 |
| Bellman-Ford | 단일 출발점 | O | O(VE) | 음수 간선, 사이클 탐지 |
| Floyd–Warshall | 모든 쌍 | O | O(V³) | 단순, N작을 때 유리 |
