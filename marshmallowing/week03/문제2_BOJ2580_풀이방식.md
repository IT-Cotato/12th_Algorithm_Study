### **핵심 아이디어: 순차 탐색과 가지치기**

1. **탐색 순서:** 백트래킹 함수 `solve(r, c)`는 보드를 **왼쪽 상단(0, 0)부터 오른쪽 하단(8, 8)까지** 순서대로(행 우선) 탐색합니다.
    - `solve(r, c)`는 현재 **(r, c)** 칸에 숫자를 채우는 역할을 합니다.
2. **빈 칸 처리:** `board[r][c]`가 0인 빈 칸을 만나면, 1부터 9까지 숫자를 반복적으로 시도합니다.
3. **전망성 검사 (`isPossible`):** 숫자를 시도할 때마다 **`isPossible(r, c, num)`** 함수를 호출하여 현재 숫자가 다음 세 가지 규칙을 위반하는지 검사합니다.
    - 같은 **행(가로)**에 중복이 있는지.
    - 같은 **열(세로)**에 중복이 있는지.
    - 속해 있는 **3×3 박스**에 중복이 있는지.
4. **가지치기 (Pruning):** `isPossible` 검사에서 `false`가 나오면, 해당 숫자는 더 이상 탐색하지 않고 다음 숫자를 시도합니다.
5. **되돌리기 (Backtrack):** 유효한 숫자 `num`을 채우고 다음 칸으로 넘어갔다가 (재귀 호출), 만약 그 이후의 탐색에서 해답을 찾지 못하고 돌아왔다면, **`board[r][c] = 0`으로 되돌려 놓아 다른 숫자를 시도할 수 있도록 상태를 복원합니다.
6. **탐색 중단:** 이 문제는 해답 **하나만** 찾으면 되므로, 해답을 찾았을 때 `found`와 같은 전역 변수를 이용해 모든 재귀 호출을 즉시 종료하는 최적화가 중요합니다.

```java
// 전역 변수 설정
static int[][] board = new int[9][9];
static boolean found = false;

// 3. 전망성 검사 (isPossible) 함수
boolean isPossible(int r, int c, int num) {
    // 3-1. 행(가로) 검사
    for (int i = 0; i < 9; i++) {
        if (board[r][i] == num) return false;
    }
    // 3-2. 열(세로) 검사
    for (int i = 0; i < 9; i++) {
        if (board[i][c] == num) return false;
    }
    // 3-3. 3x3 박스 검사
    int startRow = (r / 3) * 3;
    int startCol = (c / 3) * 3;
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            if (board[startRow + i][startCol + j] == num) return false;
        }
    }
    return true;
}

// 1. 백트래킹 solve 함수
void solve(int r, int c) {
    
    // 6. 탐색 중단: 이미 해답을 찾았다면 즉시 복귀
    if (found) return;

    // 종료 조건: 마지막 행까지 탐색 완료 (r==9)
    if (r == 9) {
        found = true;
        // 해답 board 출력 로직 추가
        return; 
    }

    // 1-1. 다음 칸 계산
    int nextR = r, nextC = c + 1;
    if (nextC == 9) { 
        nextR = r + 1;
        nextC = 0;
    }

    // 2. 빈 칸이 아닌 경우: 다음 칸으로 이동
    if (board[r][c] != 0) {
        solve(nextR, nextC);
        return;
    }

    // 2. 빈 칸 처리: 1부터 9까지 숫자 시도
    for (int num = 1; num <= 9; num++) {
        if (isPossible(r, c, num)) {
            // 전진
            board[r][c] = num;
            solve(nextR, nextC);
            
            if (found) return; // 해답 찾았으면 복귀
            
            // 5. 되돌리기 (Backtrack)
            board[r][c] = 0;
        }
    }
}
```
