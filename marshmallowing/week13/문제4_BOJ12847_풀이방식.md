## 백준 12847

### 해결 방법

이 문제는 **슬라이딩 윈도우(Sliding Window)** 기법을 사용하여 해결할 수 있다.

### 핵심 아이디어
- 연속된 `m`일의 합을 구해야 한다.
- 매 구간마다 합을 다시 계산하면 시간 초과가 발생한다.
- 이전 구간의 합을 재사용하여 효율적으로 계산한다.

---

### 알고리즘 흐름

1. 처음 `m`일 동안의 일급 합을 계산한다.
2. 해당 값을 최대 수익(`max`)으로 초기화한다.
3. 이후 하루씩 구간을 오른쪽으로 이동하며:
    - 새로 포함되는 일급을 더하고
    - 더 이상 포함되지 않는 일급을 뺀다.
4. 매 이동마다 최대값을 갱신한다.
5. 모든 구간을 확인한 후 최대 수익을 출력한다.

---

### 슬라이딩 윈도우 동작 설명

윈도우 크기는 항상 `m`으로 고정되어 있다.

```text
초기 상태:
[ 0 ... m-1 ]

한 칸 이동:
[ 1 ... m ]

다시 이동:
[ 2 ... m+1 ]
```
> 새로운 합 = 이전 합 - 빠진 값 + 새로 들어온 값

---
### 구현 코드

```java
import java.io.*;
import java.util.StringTokenizer;

public class Main {
public static void main(String[] args) throws Exception {
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        int[] arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        long sum = 0;

        // 초기 윈도우 합 (0 ~ m-1)
        for (int i = 0; i < m; i++) {
            sum += arr[i];
        }

        long max = sum;

        // 윈도우 이동
        for (int i = m; i < n; i++) {
            sum += arr[i];
            sum -= arr[i - m];
            if (sum > max) {
                max = sum;
            }
        }

        bw.write(String.valueOf(max));
        bw.flush();
        bw.close();
    }
}
```
