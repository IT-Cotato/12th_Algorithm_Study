# 문제
주어진 정수 삼각형에서 인접한 아래로 내려가면서 출력할 수 있는 가장 큰 값을 출력하는 프로그램 작성하기

### 1. 문제 입력받기
```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

int n = Integer.parseInt(br.readLine());

int[][] tri = new int[n][n];
for(int i = 0; i < n; i++){
    StringTokenizer st = new StringTokenizer(br.readLine());
    for(int j = 0; j < n; j++){
        if(st.hasMoreTokens()){
            tri[i][j] = Integer.parseInt(st.nextToken());
        }
        else{
            tri[i][j] = 0;
        }
    }
}
```
1. 정수 삼각형의 각 내부 위치를 저장하기 위해 2차원 배열에 저장
2. st에 다음 토큰이 없는 경우는 0으로 저장
### 2. dp 이용
```java
int[][] dp = new int[n][n];
dp[0][0] = tri[0][0];
// 두 번째 줄(i=1)부터 탐색
for (int i = 1; i < n; i++) {
    for (int j = 0; j <= i; j++) {
        if (j == 0) {
            // 맨 왼쪽 칸: 바로 위(오른쪽 대각선 위)에서만 내려옴
            dp[i][j] = dp[i - 1][j] + tri[i][j];
        } else if (j == i) {
            // 맨 오른쪽 칸: 왼쪽 위에서만 내려옴
            dp[i][j] = dp[i - 1][j - 1] + tri[i][j];
        } else {
            // 가운데 칸: 위쪽 두 칸 중 큰 값을 선택
            dp[i][j] = Math.max(dp[i - 1][j - 1], dp[i - 1][j]) + tri[i][j];
        }
    }
}
```
1. 맨 꼭대기의 경우 1개의 값 밖에 없으므로 dp에 저장
2. 삼각형 위의 값들은 j - 1(왼쪽 위)이나 j(오른쪽 위)에서 내려오므로 그 중에서 큰 값을 선택
    - 이 때 맨 왼쪽 칸과 맨 오른쪽 칸은 한 쪽에서만 내려오므로 따로 처리(인덱스 에러 발생)
### 3. 출력하기
```java
int max = 0;
for(int i = 0; i < n; i++){
    max = Math.max(dp[n-1][i], max);
}

System.out.println(max);
```
- 가장 아래로 내려왔을 때 가장 큰 값을 max에 저장 후 출력
### 전체 코드
```java
package kingmingyu.week15;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class 문제4_BOJ1932_풀이 {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[][] tri = new int[n][n];
        for(int i = 0; i < n; i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            for(int j = 0; j < n; j++){
                if(st.hasMoreTokens()){
                    tri[i][j] = Integer.parseInt(st.nextToken());
                }
                else{
                    tri[i][j] = 0;
                }
            }
        }

        int[][] dp = new int[n][n];
        dp[0][0] = tri[0][0];
        // 두 번째 줄(i=1)부터 탐색
        for (int i = 1; i < n; i++) {
            for (int j = 0; j <= i; j++) {
                if (j == 0) {
                    // 맨 왼쪽 칸: 바로 위(오른쪽 대각선 위)에서만 내려옴
                    dp[i][j] = dp[i - 1][j] + tri[i][j];
                } else if (j == i) {
                    // 맨 오른쪽 칸: 왼쪽 위에서만 내려옴
                    dp[i][j] = dp[i - 1][j - 1] + tri[i][j];
                } else {
                    // 가운데 칸: 위쪽 두 칸 중 큰 값을 선택
                    dp[i][j] = Math.max(dp[i - 1][j - 1], dp[i - 1][j]) + tri[i][j];
                }
            }
        }

        int max = 0;
        for(int i = 0; i < n; i++){
            max = Math.max(dp[n-1][i], max);
        }

        System.out.println(max);

    }
}

```
