# 🎢 놀이기구 1 (Parallel Binary Search 풀이)

## 📖 문제 설명

N명의 아이들과 M개의 놀이기구가 있다.  
아이 i와 j가 놀이기구 k를 타려면 `(height[i] + height[j]) ≥ limit[k]` 가 되어야 한다.  
모든 아이들의 처음 키는 0cm이며, 하루에 한 명씩 키가 1씩 자란다.

- 기간: K일
- 매일 자라는 아이의 번호가 주어진다.
- Q개의 `(i, j, k)` 쌍이 주어지며, 매일 이 아이들이 놀이기구를 시도한다.
- 단, **키가 자라는 것이 먼저**, 그 후에 놀이기구 시도가 이루어진다.

각 날짜마다 **성공한 시도의 총 개수**를 구하는 프로그램을 작성하라.

---

## 🧩 입력

```
N M K Q
limit[1..M]
grow[1..K]
(i1 j1 k1)
(i2 j2 k2)
...
(iQ jQ kQ)
```

---

## 📤 출력

```
각 날짜(1..K)마다 성공한 시도 개수
```

---

## 🧠 접근 아이디어

### ❌ 단순 접근 (시간초과)

매일 키 성장 → Q개의 질의 전수 검사  
→ 시간복잡도: **O(K × Q)**  
(최대 200,000 × 200,000 = 4×10¹⁰ 연산, 절대 불가능)

---

### ✅ 효율적 접근 (병렬 이분 탐색)

핵심은 각 질의 `(i, j, k)`가 **처음으로 조건을 만족하는 날**만 찾으면 된다는 점이다.

| 질의    | 최초로 가능한 날 | 그 이후        |
| ------- | ---------------- | -------------- |
| (1,2,2) | 4일차            | 이후 매일 가능 |
| (3,5,3) | 3일차            | 이후 매일 가능 |

이 “최초 성공일”을 모든 질의에 대해 찾은 후,  
그날부터는 매일 +1씩 누적해가면 된다.

---

## ⚙️ 알고리즘 개요

| 단계 | 설명                                                                     |
| ---- | ------------------------------------------------------------------------ |
| 1️⃣   | 각 질의 q에 대해 `L[q]=1`, `R[q]=K+1` 로 초기화 (탐색 구간 설정)         |
| 2️⃣   | 각 라운드마다 mid = (L+R)/2를 계산하고, mid별 질의를 버킷(bucket)에 저장 |
| 3️⃣   | 1일부터 K일까지 성장 시뮬레이션하면서, 오늘을 mid로 가진 질의들을 판정   |
| 4️⃣   | 조건 만족 → `R[q]=t`, 불만족 → `L[q]=t+1` 로 갱신                        |
| 5️⃣   | 더 이상 L < R인 질의가 없을 때까지 반복                                  |
| 6️⃣   | `R[q]` = 최초 성공일(d) 로 확정, `diff[d]++` 후 누적합으로 날짜별 출력   |

---

## 📈 단조성과 이분 탐색의 원리

- 날짜가 증가할수록 키 합(`height[i]+height[j]`)은 절대 줄지 않는다.
- 즉, **불가능 → 가능**으로 한 번만 바뀌는 단조성을 가진다.
- 따라서 “최초로 가능해지는 날”을 **이분 탐색**으로 찾을 수 있다.

---

## 🧮 시간 복잡도 분석

| 구분      | 복잡도                     |
| --------- | -------------------------- |
| 매 라운드 | O(N + K + Q)               |
| 라운드 수 | O(log K)                   |
| **총합**  | **O((N + K + Q) × log K)** |

---

## ✅ 정답 코드

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

let line = 0;
const [N, M, K, Q] = input[line++].trim().split(" ").map(Number);
const p = input[line++].trim().split(" ").map(Number); // 키 제한
const cIdx = input[line++]
  .trim()
  .split(" ")
  .map((v) => Number(v) - 1); // 성장 배열

const qwerty = new Array(Q);
for (let q = 0; q < Q; q++) {
  qwerty[q] = input[line++].trim().split(" ").map(Number);
}

const L = new Array(Q).fill(1);
const R = new Array(Q).fill(K + 1);

const hasActive = () => {
  for (let q = 0; q < Q; q++) if (L[q] < R[q]) return true;
  return false;
};

while (hasActive()) {
  const bucket = Array.from({ length: K + 2 }, () => []);
  for (let q = 0; q < Q; q++) {
    if (L[q] < R[q]) {
      const mid = (L[q] + R[q]) >> 1;
      bucket[mid].push(q);
    }
  }

  const cnt = new Array(N).fill(0);

  for (let t = 1; t <= K; t++) {
    cnt[cIdx[t - 1]]++;
    const list = bucket[t];
    for (let idx = 0; idx < list.length; idx++) {
      const q = list[idx];
      const [ii, jj, kk] = qwerty[q];
      const need = p[kk - 1];
      const have = cnt[ii - 1] + cnt[jj - 1];
      if (have >= need) R[q] = t;
      else L[q] = t + 1;
    }
  }

  const tail = bucket[K + 1];
  if (tail.length) {
    for (let idx = 0; idx < tail.length; idx++) {
      const q = tail[idx];
      const [ii, jj, kk] = qwerty[q];
      const need = p[kk - 1];
      const have = cnt[ii - 1] + cnt[jj - 1];
      if (have >= need) R[q] = K;
      else L[q] = K + 1;
    }
  }
}

const diff = new Array(K + 2).fill(0);
for (let q = 0; q < Q; q++) {
  const d = R[q];
  if (d <= K) diff[d] += 1;
}

let running = 0;
let out = [];
for (let t = 1; t <= K; t++) {
  running += diff[t];
  out.push(String(running));
}
console.log(out.join("\n"));
```

## 🧭 정리

| 키워드        | 설명                                                 |
| ------------- | ---------------------------------------------------- |
| **단조성**    | 날짜가 증가할수록 키 합은 줄지 않는다.               |
| **이분 탐색** | "최초로 가능해지는 날"을 효율적으로 찾는다.          |
| **병렬 탐색** | 모든 질의를 동시에 mid별로 묶어서 검사한다.          |
| **diff 배열** | 최초 가능일 이후 매일 탑승 → 누적합으로 날짜별 출력. |

---

## ✨ 배운 점

- "매일 검사" 대신 “최초로 참이 되는 시점”을 찾는 접근법
- **단조성 → 이분 탐색**, **여러 질의 → 병렬 처리**의 조합
- `diff` 배열을 이용하면 “그 이후 매일 반영”을 효율적으로 구현 가능

---

📘 **요약:**  
이 문제는 병렬 이분 탐색(Parallel Binary Search)을 통해  
각 질의의 “최초 성공일”만 찾아내고,  
그 이후는 누적합(diff)으로 계산하는 고급 이분 탐색 응용 문제다.
