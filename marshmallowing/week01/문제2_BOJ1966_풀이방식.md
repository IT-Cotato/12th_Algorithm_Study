# BOJ 1966 - 프린터 큐

## 문제
문서들이 프린터 큐에 들어있고 각 문서는 **우선순위(priority)**를 갖는다.

큐 맨 앞 문서를 확인:
- 다른 문서 중 현재 문서보다 높은 우선순위가 있으면 뒤로 보낸다.
- 그렇지 않으면 출력한다.

목표 문서가 몇 번째로 출력되는지 구하는 문제.

### 입력
- 첫 줄: 테스트 케이스 수 `N`
- 각 테스트 케이스:
    - 문서 개수 `a`와 목표 문서 위치 `b`
    - 다음 줄: `a`개의 문서 우선순위

### 출력
- 각 테스트 케이스마다 목표 문서의 출력 순서

---

## 풀이 아이디어
- **Deque<int[]>** 사용
    - `[우선순위, 원래 인덱스]` 형태로 저장
    - 목표 문서를 추적하기 위함
- 큐 맨 앞 문서를 확인하고, 더 높은 우선순위 문서가 있으면 뒤로 이동
- 아니면 출력하고 출력 순서를 증가
- 목표 문서를 출력할 때 순서를 기록

---

## Deque 메서드 설명
- `peekFirst()` : 큐 맨 앞 요소를 확인만 하고 제거하지 않음
  - 덱의 앞쪽 엘리먼트 하나를 제거하지 않은채 리턴한다. 덱이 비어있으면 null이 리턴된다.
- `pollFirst()` : 큐 맨 앞 요소를 제거하고 반환
  - 덱의 앞쪽에서 엘리먼트 하나를 뽑아서 제거한 다음 해당 엘리먼트를 리턴한다. 덱이 비어있으면 null 이 리턴된다.
- `addLast(E e)` : 큐 맨 뒤에 요소를 추가
  - 덱의 마지막 쪽에 엘리먼트를 삽입한다. 용량 제한이 있는 덱의 경우, 용량 초과시 예외가 발생한다
- 위 세 메서드를 조합해서 **프린터 큐 시뮬레이션** 가능
    - 우선순위가 높으면 뒤로 보내기 → `addLast(pollFirst())`
    - 출력하기 → `pollFirst()`

---

## 핵심 코드
```java
Deque<int[]> queue = new ArrayDeque<>();

// 문서 저장
for (int j = 0; j < a; j++) {
    int priority = Integer.parseInt(st.nextToken());
    queue.addLast(new int[] {priority, j}); // [우선순위, 원래 인덱스]
}

int count = 0;

while (!queue.isEmpty()) {
    int[] cur = queue.peekFirst();
    boolean hasHigher = false;

    // 현재 문서보다 높은 우선순위 확인
    for (int[] doc : queue) {
        if (doc[0] > cur[0]) {
            hasHigher = true;
            break;
        }
    }

    if (hasHigher) {
        queue.addLast(queue.pollFirst()); // 뒤로 이동
    } else {
        queue.pollFirst(); // 출력
        count++;
        if (cur[1] == b) {
            bw.write(count + "\n"); // 목표 문서 출력 순서
            break;
        }
    }
}
