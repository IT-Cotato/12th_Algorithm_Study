# BOJ 1780 — 종이의 개수

## 문제 개요

N×N 크기의 종이가 있고, 각 칸에는 **-1, 0, 1** 중 하나의 값이 들어있다.  
이 종이를 다음 규칙에 따라 잘라가며 같은 숫자로만 채워진 종이의 개수를 구하는 문제이다.

---

## 규칙 요약

1. 전체 종이를 검사한다.
2. 종이가 모두 같은 수로 되어 있으면 → “종이 1장”으로 센다.
3. 같지 않으면, 종이를 **3×3으로 9등분**해서 각 부분에 대해 위 과정을 반복한다.
4. 마지막으로
    - -1로만 채워진 종이 개수
    - 0으로만 채워진 종이 개수
    - 1로만 채워진 종이 개수  
      를 차례대로 출력한다.

---

## 분할 정복(Divide and Conquer) 접근

> 같으면 세고, 다르면 9개로 쪼갠다

### 알고리즘 단계
1. **Divide (분할)**
    - 현재 영역을 9개의 작은 종이로 나눈다.
2. **Conquer (정복)**
    - 각 작은 종이에 대해 재귀적으로 동일한 검사 수행.
3. **Combine (통합)**
    - 모든 결과를 합쳐 최종 카운트 계산.

---

## 코드

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.util.StringTokenizer;

public class Main {
    static int N;
    static int[][] paper;
    static int[] count = new int[3]; // -1, 0, 1 각각의 개수 저장

    public static void main(String[] args) throws Exception {
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        N = Integer.parseInt(br.readLine());
        paper = new int[N][N];

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 0; j < N; j++) {
                paper[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        divide(0, 0, N);

        // 순서대로 -1, 0, 1 출력
        bw.write(count[0] + "\n");
        bw.write(count[1] + "\n");
        bw.write(String.valueOf(count[2]));
        bw.flush();
        bw.close();
    }

    // (x, y)를 시작으로 하는 size×size 영역 검사
    private static void divide(int x, int y, int size) {
        if (isSame(x, y, size)) {
            int value = paper[x][y];
            count[value + 1]++; // -1→0, 0→1, 1→2 인덱스 보정
            return;
        }

        int newSize = size / 3;
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                divide(x + i * newSize, y + j * newSize, newSize);
            }
        }
    }

    // 현재 영역이 전부 같은 숫자인지 확인
    private static boolean isSame(int x, int y, int size) {
        int first = paper[x][y];
        for (int i = x; i < x + size; i++) {
            for (int j = y; j < y + size; j++) {
                if (paper[i][j] != first) {
                    return false;
                }
            }
        }
        return true;
    }
}
```

| 함수 / 변수              | 역할                                             |
| -------------------- | ---------------------------------------------- |
| `paper[][]`          | 입력된 종이 상태 저장 (-1, 0, 1)                        |
| `count[3]`           | 각각 -1, 0, 1 종이의 개수 저장                          |
| `divide(x, y, size)` | `(x, y)`부터 `size×size` 영역을 검사하고, 필요시 9등분 재귀 호출 |
| `isSame(x, y, size)` | 해당 영역이 전부 같은 숫자인지 확인                           |

- 주요 로직 
  - isSame()이 true면 → 바로 count 증가 
  - isSame()이 false면 → 3×3 영역으로 재귀 분할 
  - 인덱스 보정: count[value + 1]
    - -1 → index 0 
    - 0 → index 1 
    - 1 → index 2
