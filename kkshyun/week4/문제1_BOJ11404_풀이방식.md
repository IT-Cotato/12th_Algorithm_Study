## BOJ 11404 문제 요약

- n개의 도시, m개의 버스 비용이 주어짐
- 모든 도시 쌍의 최단 비용을 구해 출력
- 갈 수 없으면 0을 출력

---

## 아이디어

- 모든 도시 쌍의 최단경로를 찾아야하고 도시가 많지 않기 때문에 플로이드 워셜 사용함
- 시작 도시와 도착 도시를 연결하는 노선이 여러개 있을 수 있으므로 더 작은 비용만 저장 (dist[a][b] = min(dist[a][b], c))
- INF는 Long.MAX_VALUE로 두고, 더할 때 오버플로/의미 없는 덧셈 방지를 위해 dist[j][i] == INF 또는 dist[i][k] == INF면 건너뜀

---

## 알고리즘 단계

- 입력으로 n, m 받고 dist[n+1][n+1]을 INF로, 대각선은 0으로 초기화
- 각 간선 (a,b,c)를 읽어 dist[a][b] = min(dist[a][b], c) 반영
- 플로이드 워셜 3중 루프 수행
    - if dist[i][k] != INF && dist[k][j] != INF
        - dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
- 최종 dist 출력 (INF는 0으로 출력)

---

## 코드

```java
import java.io.*;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        int n = Integer.parseInt(br.readLine());
        int m = Integer.parseInt(br.readLine());

        long[][] dist = new long[n+1][n+1];
        // 2차원 배열 Long.MAX_VALUE로 초기화
        for (long[] ints : dist) {
            Arrays.fill(ints, Long.MAX_VALUE);
        }

        for (int i = 0; i <= n; i++) {
            dist[i][i] = 0;
        }

        for (int i = 0; i < m; i++) {
            String[] s = br.readLine().split(" ");
            int a = Integer.parseInt(s[0]);
            int b = Integer.parseInt(s[1]);
            int c = Integer.parseInt(s[2]);
            dist[a][b] = Math.min(dist[a][b], c);
        }

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                for (int k = 1; k <= n; k++) {
                    if(dist[j][i] == Long.MAX_VALUE || dist[i][k] == Long.MAX_VALUE)
                        continue;
                    if(dist[j][k] > dist[j][i] + dist[i][k])
                        dist[j][k] = dist[j][i] + dist[i][k];
                }
            }
        }
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                if(dist[i][j] == Long.MAX_VALUE)
                    bw.write(0 +" ");
                else
                    bw.write(dist[i][j] +" ");
            }
            bw.write("\n");
        }
        bw.flush();
        bw.close();
    }
}
```
