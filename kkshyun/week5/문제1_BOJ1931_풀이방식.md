## BOJ 1931 문제 요약

- 회의 N개가 주어짐 (각 회의: 시작시간, 종료시간)
- 한 회의가 끝나는 동시에 다음 회의 시작 가능
- 하나의 회의실에서 진행할 수 있는 최대 회의 수를 구하는 문제

---

## 아이디어

- 가장 빨리 끝나는 회의부터 고르면, 뒤에 더 많은 회의를 배치할 수 있음 → 그리디
- 종료 시간이 같으면 시작 시간이 더 빠른 회의를 먼저 두면 선택 가능성이 넓어짐
    - ex. (1, 2) (2, 2) (2, 3) 인데 시작 시간을 고려하지 않으면 틀릴 수 있음
- 회의를 (끝나는 시간, 시작 시간) 기준으로 정렬한 뒤,
    - 현재 시각 time 이하에서 시작하는 회의는 스킵
    - time ≤ 시작시간이면 채택하고 time = 종료시간으로 갱신

---

## 알고리즘 단계

- 입력으로 N을 받고 (시작, 종료) 쌍을 모두 수집
- 회의를 종료시간 오름차순, 종료시간 같으면 시작시간 오름차순으로 정렬
- time = 0, count = 0으로 시작해 정렬된 순서대로 순회
    - if (time ≤ 시작시간) → count++, time = 종료시간
- 최종 count 출력

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.PriorityQueue;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());
        // 가장 먼저 끝나는 것들 중 시작 시간이 가장 빠른 것부터 선택
        // 그 중에 그 전 회의 끝나는 시간 <= 현재 선택할 회의 시작할 시간
        PriorityQueue<int[]> queue = new PriorityQueue<>((o1,o2) -> {
            if (o1[1] == o2[1]) return o1[0] - o2[0];
            else return o1[1] - o2[1];
        });
        for (int i = 0; i < N; i++) {
            String[] s = br.readLine().split(" ");
            int startTime = Integer.parseInt(s[0]);
            int endTime = Integer.parseInt(s[1]);
            queue.add(new int[]{startTime, endTime});
        }
        int count = 0;
        int time = 0;
        while (!queue.isEmpty()) {
            int[] poll = queue.poll();
            int meetingStartTime = poll[0];
            int meetingEndTime = poll[1];
            if(time > meetingStartTime)
                continue;
            count++;
            time = meetingEndTime;
        }
        System.out.println(count);
    }
}
```
