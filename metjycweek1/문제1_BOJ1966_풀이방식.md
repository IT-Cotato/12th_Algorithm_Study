# 📄 큐(Queue) 문제 풀이 - 프린터 큐 문제

## ✅ 문제 설명

프린터는 일반적으로 **먼저 요청한 문서부터 출력**하는 방식(FIFO, First-In-First-Out)을 따른다. 그러나 이번 문제에서는 **중요도가 더 높은 문서가 있으면 현재 문서를 뒤로 푸시함.**

주어진 문서들의 중요도에 따라, 특정 문서가 **몇 번째로 출력되는지**를 구하는 것이 목표이다.

---

## 🧠 큐(Queue) 자료구조란?

- 선입선출(FIFO, First-In-First-Out) 구조의 선형 자료구조
- `push()` → 데이터를 뒤에 추가
- `shift()` → 맨 앞의 데이터를 꺼냄
- 활용 예시: 프린터 큐, 캐시, BFS 등

---

## 🔍 풀이 흐름

```js
const [n, m] = input[j].split(" ").map(Number);
const priorities = input[j + 1].split(" ").map(Number);
```

- 각 테스트 케이스마다 문서의 개수 `n`, 궁금한 문서의 위치 `m`, 중요도 배열 `priorities`를 추출한다.

```js
const queue = priorities.map((priority, index) => [priority, index]);
```

- 중요도와 원래 인덱스를 함께 저장하여 나중에 추적할 수 있도록 큐를 초기화한다.

```js
const cur = queue.shift();
const hasHigherPriority = queue.some(([priority]) => priority > cur[0]);
```

- 현재 큐의 맨 앞 문서를 꺼낸다.
- **중요도가 더 높은 문서가 남아있는지** 확인.

```js
if (hasHigherPriority) {
  queue.push(cur); // 중요도가 더 높은 문서가 있다면 현재 문서를 뒤로 보냄
} else {
  count++;         // 그렇지 않으면 출력(count 증가)
  if (cur[1] === m) {
    console.log(count); // 찾는 문서가 출력되었으면 count 출력
    break;
  }
}
```

---

## ✅ 정리

- `some()` 메서드를 사용하여 현재 문서보다 높은 우선순위가 있는지를 확인
- 출력될 때마다 count를 증가시켜 추적
- 궁금한 문서가 출력될 때 카운트를 출력하고 break

## 🧾 코드 전체

```js
const fs = require("fs");

const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const testCaseCount = Number(input[0]);
let j = 1;

for (let i = 0; i < testCaseCount; i++) {
  const [n, m] = input[j].split(" ").map(Number);
  const priorities = input[j + 1].split(" ").map(Number);

  const queue = priorities.map((priority, index) => [priority, index]);
  let count = 0;

  while (queue.length) {
    const cur = queue.shift();
    const hasHigherPriority = queue.some(([priority]) => priority > cur[0]);

    if (hasHigherPriority) {
      queue.push(cur);
    } else {
      count++;
      if (cur[1] === m) {
        console.log(count);
        break;
      }
    }
  }

  j += 2;
}
```

## 📌 배운 점

- Queue의 작동 방식(FIFO): 먼저 들어온 문서를 먼저 처리하는 큐의 특성과, 중요도에 따라 조건부로 순서를 재조정하는 문제의 특수한 큐 활용 방식을 이해했다.

- 배열을 큐처럼 다루기 위해 shift()와 push()를 활용했다. shift()는 맨 앞 요소를 제거하고 반환하며, push()는 맨 뒤에 요소를 추가하는 데 사용된다.

- queue.some()을 통해 현재 문서보다 높은 중요도의 문서가 존재하는지 검사하는 방법을 배웠다. 이 방식은 효율적으로 조건 확인을 가능하게 했다.
