## BOJ 11726 문제 요약

- 2×N 크기의 직사각형을 1×2, 2×1 타일로 채우는 경우의 수를 구하는 문제
- 정답은 10007로 나눈 나머지를 출력

---

## 아이디어

- DP
- dp[i]를 2×i 직사각형을 채우는 경우의 수라고 두면
    - 마지막 타일 배치 기준으로 경우가 2가지로 나뉨
        1. 세로 타일(2×1) 1개를 마지막에 세우는 경우

           → 앞은 2×(i-1) 이므로 dp[i-1]

        2. 가로 타일(1×2) 2개를 마지막에 눕혀서 채우는 경우

           → 앞은 2×(i-2) 이므로 dp[i-2]

- 따라서 점화식
    - dp[i] = dp[i-1] + dp[i-2]
- 값이 커지므로 매 단계에서 모듈러 연산 적용
    - (A+B)%C = ((A%C) + (B%C))%C 형태로 안전하게 처리 가능
- dp[1]은 따로 분기해서 처리
    - dp 배열에서 dp[1] 접근을 위해 기본값을 먼저 채우고, n이 1일 때는 반복을 돌지 않도록 분기

---

## 알고리즘 단계

1. 입력으로 N을 읽는다
2. dp 배열을 n+1 크기로 만든다
3. 초기값을 설정한다
    - dp[0] = 1
    - dp[1] = 1
4. n이 1이 아닌 경우에만
    - dp[2] = 2 설정
    - i = 3부터 n까지 반복하면서
        - dp[i] = (dp[i-1] + dp[i-2]) % 10007
5. dp[n]을 출력한다

---

## 코드

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        int n = Integer.parseInt(br.readLine());
        int[] dp = new int[n+1];
        dp[0] = 1;
        dp[1] = 1;
        if(n!= 1) {
            dp[2] = 2;
            for (int i = 3; i < n + 1; i++) {
                dp[i] = (dp[i - 1] + dp[i - 2]) % 10007;
            }
        }
        bw.write(dp[n]+"\n");
        bw.flush();
        bw.close();
    }
}
```
