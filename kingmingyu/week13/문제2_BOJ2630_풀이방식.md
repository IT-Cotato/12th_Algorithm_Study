# 문제
전체 색종이에서 색이 다른 부분이 몇개인지 출력하는 문제

## dnc 이용
색이 같은지 반씩 나눠서 문제를 해결하므로 dnc를 이용

### 1. degenerate case 설정
```java
if(sx >= ex){
    if(paper[sx][sy] == 0) paper0++;
    else paper1++;
    return;
}
```
### 2. 현재 탐색하는 색종이가 모두 같은색인지 확인
```java
int init = paper[sx][sy];
for(int i = sx; i < ex; i++){
    for(int j = sy; j < ey; j++){
        if(paper[i][j] != init){ //처음 종이 색과 같지 않음!
            int mx = (sx + ex) / 2;
            int my = (sy + ey) / 2;
            dnc(sx, mx, sy, my);
            dnc(mx, ex, sy, my);
            dnc(sx, mx, my, ey);
            dnc(mx, ex, my, ey);
            return;
        }
    }
}
```
### 3. 같지 않다면 구역을 나눠서 다시 dnc
```java
if(paper[i][j] != init){
    int mx = (sx + ex) / 2;
    int my = (sy + ey) / 2;
    dnc(sx, mx, sy, my); // 1사분면
    dnc(mx, ex, sy, my); // 3사분면
    dnc(sx, mx, my, ey); // 2사분면
    dnc(mx, ex, my, ey); // 4사분면
    return;
}
```

### 4. 만약 모두 같은 색종이라면 색종이 개수 추가
- for문이 모두 끝났는데도 이쪽으로 온다면 모두 같은 색의 색종이라는 의미이므로 종이 개수 추가
```java
if(init == 0) paper0++;
else paper1++;
```

### 전체 코드
```java
package kingmingyu.week13;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class 문제2_BOJ2630_풀이 {
    static int[][] paper;
    static int paper0, paper1;
    public static void main(String[] args) throws IOException {

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());

        paper = new int[n][n];

        for(int i = 0; i < n; i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            for(int j = 0; j < n; j++){
                paper[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        dnc(0, n, 0, n);
        System.out.println(paper0);
        System.out.println(paper1);
    }
    public static void dnc(int sx, int ex, int sy, int ey){
        if(sx >= ex){
            if(paper[sx][sy] == 0) paper0++;
            else paper1++;
            return;
        }

        int init = paper[sx][sy];
        for(int i = sx; i < ex; i++){
            for(int j = sy; j < ey; j++){
                if(paper[i][j] != init){
                    int mx = (sx + ex) / 2;
                    int my = (sy + ey) / 2;
                    dnc(sx, mx, sy, my);
                    dnc(mx, ex, sy, my);
                    dnc(sx, mx, my, ey);
                    dnc(mx, ex, my, ey);
                    return;
                }
            }
        }
        if(init == 0) paper0++;
        else paper1++;
        return;
    }
}

```
