# 🐔 치킨 배달 (BOJ 15686)

## 📌 문제 요약

- N×N 도시에서 **집(1)** 과 **치킨집(2)** 이 존재
- 각 집은 가장 가까운 치킨집까지의 거리 = **치킨 거리**
- 도시의 치킨 거리 = 모든 집의 치킨 거리 합
- 치킨집 중 **최대 M개만 남길 수 있음**
- 도시 치킨 거리의 **최솟값**을 구하는 문제

거리 공식:
|r1 - r2| + |c1 - c2|

---

## 🧠 핵심 아이디어

이 문제의 본질은 다음 두 가지다.

1. **치킨집 중 M개를 고르는 모든 조합 탐색**
2. **각 조합에 대해 도시 치킨 거리 계산**

치킨집 개수 ≤ 13 이므로  
👉 **조합(백트래킹)** 으로 충분히 해결 가능

---

## 🧩 풀이 단계

### 1️⃣ 입력 처리 & 좌표 분리

- 도시 전체를 들고 있을 필요 없음
- 집 / 치킨집 좌표만 따로 저장

```js
houses = [];
chickens = [];
```

---

### 2️⃣ 거리 미리 계산 (dist 배열)

- 집 H개, 치킨집 C개
- `dist[h][c]` = h번째 집 ↔ c번째 치킨집 거리

```js
dist[h][c] = |hr - cr| + |hc - cc|
```

➡️ 이후 조합이 바뀌어도 거리 계산을 다시 안 해도 됨

---

### 3️⃣ 도시 치킨 거리 계산 함수

선택된 치킨집 조합(pick)에 대해:

- 각 집마다
  - 선택된 치킨집 중 **최소 거리** 선택
- 모든 집의 최소 거리 합 = 도시 치킨 거리

```js
function calc(pick) {
  for (각 집 h) {
    best = INF;
    for (선택된 치킨집 c) {
      best = min(best, dist[h][c]);
    }
    sum += best;
  }
}
```

---

### 4️⃣ 치킨집 조합 생성 (DFS / 백트래킹)

- 치킨집 인덱스를 기준으로 조합 생성
- 중복 없이 M개 선택

```js
dfs(start, picked);
```

- `picked === M` → 거리 계산
- 아니면 다음 인덱스부터 계속 선택

---

## 💡 실수 포인트 정리

- `answer` 초기값을 `0`으로 두면 ❌ → 반드시 `INF`
- `dfs(0,0)` 호출은 **함수 밖에서**
- 치킨집 자체가 아니라 **인덱스**를 pick에 저장해야 편함

---

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const [N, M] = input[0].split(" ").map(Number);
const area = input.slice(1).map((line) => line.trim().split(" ").map(Number));

const houses = [];
const chickens = [];

for (let i = 0; i < N; i++) {
  for (let j = 0; j < N; j++) {
    if (area[i][j] === 1) houses.push([i, j]);
    else if (area[i][j] === 2) chickens.push([i, j]);
  }
}

const H = houses.length;
const C = chickens.length;

const dist = Array.from({ length: H }, () => Array(C).fill(0));

for (let h = 0; h < H; h++) {
  const [hr, hc] = houses[h];

  for (let c = 0; c < C; c++) {
    const [cr, cc] = chickens[c];
    dist[h][c] = Math.abs(hr - cr) + Math.abs(hc - cc);
  }
}

const INF = 1e9;

function calc(pick) {
  let sum = 0;

  for (let h = 0; h < H; h++) {
    let best = INF;
    for (let k = 0; k < pick.length; k++) {
      const c = pick[k];
      best = Math.min(best, dist[h][c]);
    }
    sum += best;
  }
  return sum;
}

let answer = INF;
const pick = [];

function dfs(start, picked) {
  if (picked === M) {
    answer = Math.min(answer, calc(pick));
    return;
  }

  for (let i = start; i < C; i++) {
    pick.push(i);
    dfs(i + 1, picked + 1);
    pick.pop();
  }
}

dfs(0, 0);
console.log(answer);
```
