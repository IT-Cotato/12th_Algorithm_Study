# BOJ 1806

## 문제 요약
- 길이가 N인 수열이 주어진다.
- 연속된 부분 수열의 합이 **S 이상**이 되는 것 중
  **가장 짧은 길이**를 구하는 문제이다.
- 조건을 만족하는 부분 수열이 없다면 0을 출력한다.

---

## 핵심 아이디어 (투 포인터 / 슬라이딩 윈도우)

이 문제는 **연속된 부분 수열**을 다루기 때문에  
투 포인터(슬라이딩 윈도우) 기법을 사용할 수 있다.

- 오른쪽 포인터를 이동시키며 합을 키운다.
- 합이 S 이상이 되면, 왼쪽 포인터를 이동시키며
  **길이를 최소화**한다.

각 원소는 최대 한 번씩만 더해지고, 한 번씩만 빠지므로  
전체 시간 복잡도는 **O(N)** 이다.

---

## 접근 방법

1. 수열을 저장할 배열을 선언한다.
2. 현재 부분 수열의 합을 저장할 변수 `sum`을 선언한다.
3. 부분 수열의 시작 인덱스를 가리키는 `start` 포인터를 선언한다.
4. 오른쪽 포인터 `i`를 0부터 N-1까지 이동시킨다.
5. 현재 값을 `sum`에 더한다.
6. `sum >= S` 인 동안:
    - 현재 부분 수열 길이 `(i - start + 1)`로 최소 길이를 갱신한다.
    - 왼쪽 값을 빼고 `start`를 증가시킨다.
7. 모든 탐색이 끝난 후 최소 길이를 출력한다.

---

## 코드 흐름 설명

```java
int sum = 0;
int minLen = Integer.MAX_VALUE;
int start = 0;

for (int i = 0; i < n; i++) {
    sum += arr[i];                 // 오른쪽 포인터 확장

    while (sum >= s) {             // 조건 만족 시
        minLen = Math.min(minLen, i - start + 1);
        sum -= arr[start];         // 왼쪽 포인터 축소
        start++;
    }
}
```
- i는 오른쪽 포인터 역할
- start는 왼쪽 포인터 역할
- sum은 [start ~ i] 구간의 합을 의미
- 조건을 만족하는 동안 윈도우를 줄여 최소 길이를 찾는다

---

## 시간 복잡도
- 각 포인터가 배열을 한 번씩만 이동 O(N)

## 공간 복잡도
- 입력 배열 저장에 O(N)
