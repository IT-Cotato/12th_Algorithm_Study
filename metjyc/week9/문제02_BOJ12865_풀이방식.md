# 평범한 배낭 (0/1 Knapsack) - DP 정리 (BOJ 12865)

## 문제 요약

- 물건 `N`개가 있고, 각 물건은 `(무게 W, 가치 V)`를 가진다.
- 배낭은 최대 무게 `K`까지 담을 수 있다.
- 각 물건은 **넣거나 / 안 넣거나** (한 번만 사용 가능) → **0/1 배낭**
- 목표: **가치 합의 최댓값** 출력

---

## 핵심 아이디어

무게 제한 `K`가 있을 때, 특정 무게까지 담을 수 있는 상황에서의 **최대 가치**를 DP로 저장하며 갱신한다.

---

## DP 상태 정의 (1차원 최적화)

`dp[w] = 무게 한도 w일 때 얻을 수 있는 최대 가치`

- 최종 답: `dp[K]`

---

## 점화식 (Transition)

현재 물건이 `(W, V)`일 때,

- **안 넣는 경우**: `dp[w]` 유지
- **넣는 경우**: `dp[w - W] + V`

따라서:

```
dp[w] = max(dp[w], dp[w - W] + V)
```

---

## ⭐ 가장 중요한 포인트: w를 “뒤에서 앞으로” 순회

0/1 배낭에서는 같은 물건을 여러 번 쓰면 안 된다.

그래서 현재 물건을 반영할 때는:

```
for (w = K; w >= W; w--)
```

처럼 **w를 감소시키며** 갱신해야 한다.

### 왜 뒤에서 앞으로?

- `dp[w - W]`가 “이번 물건을 넣기 전”의 값이어야,
- 같은 물건을 한 라운드에서 여러 번 사용하는 실수를 막을 수 있다.

> 만약 `for (w = W; w <= K; w++)`처럼 앞으로 가면  
> 방금 갱신된 dp를 또 사용하게 되어 “무한히 넣을 수 있는 배낭(무한 배낭)”처럼 동작할 수 있음.

---

## 시간/공간 복잡도

- 시간: `O(N * K)` (물건마다 0..K 범위 갱신)
- 공간: `O(K)` (dp 배열 1개)

---

## Node.js 풀이 템플릿 (1차원 DP)

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

const [N, K] = input[0].split(" ").map(Number);

const items = [];
for (let i = 1; i <= N; i++) {
  const [W, V] = input[i].split(" ").map(Number);
  items.push([W, V]);
}

const dp = Array(K + 1).fill(0);

for (let i = 0; i < N; i++) {
  const [W, V] = items[i];

  // 0/1 배낭: 뒤에서 앞으로!
  for (let w = K; w >= W; w--) {
    dp[w] = Math.max(dp[w], dp[w - W] + V);
  }
}

console.log(dp[K]);
```
