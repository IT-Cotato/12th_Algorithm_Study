# 📊 블로그 방문자 수 분석 (슬라이딩 윈도우)

## 🧩 문제 요약

찬솔이는 블로그를 시작한 지 `N`일이 되었고,  
각 날짜별 방문자 수가 주어진다.

연속된 `X`일 동안의 방문자 수 합 중 **최댓값**과  
그 최댓값이 **몇 번 등장하는지**를 구하는 문제이다.

- 단, 최대 방문자 수가 `0`이라면 `SAD`를 출력한다.

---

## ⚠️ 단순 풀이의 문제점

모든 구간을 매번 직접 합산하면:

- 시간 복잡도: **O(N × X)**
- `N`이 큰 경우 **시간 초과 발생**

따라서 **한 번 계산한 값을 재사용하는 방식**이 필요하다.

---

## 💡 핵심 개념: 슬라이딩 윈도우 (Sliding Window)

### ✔ 아이디어

- 길이가 `X`인 연속 구간을 **윈도우**로 생각한다.
- 첫 `X`일의 합을 한 번 계산
- 이후에는:
  - 왼쪽 끝 값 제거
  - 오른쪽 새 값 추가
- 매 이동마다 합을 **O(1)** 에 갱신

### ✔ 시간 복잡도

- 전체 순회 1번 → **O(N)**
- 공간 복잡도 → **O(1)**

---

## 🛠 구현 절차

1. 첫 `X`일 방문자 수 합 계산
2. `maxSum`에 현재 최대값 저장
3. 윈도우를 하루씩 이동하며:
   - 합 갱신
   - 최대값 갱신 시 `count = 1`
   - 동일한 최대값이면 `count++`
4. 최종 출력

---

## 💻 Node.js 코드

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const [N, X] = input[0].split(" ").map(Number);
const visitors = input[1].split(" ").map(Number);

// 1. 첫 X일 합
let sum = 0;
for (let i = 0; i < X; i++) {
  sum += visitors[i];
}

let maxSum = sum;
let count = 1;

// 2. 슬라이딩 윈도우
for (let i = X; i < N; i++) {
  sum += visitors[i];
  sum -= visitors[i - X];

  if (sum > maxSum) {
    maxSum = sum;
    count = 1;
  } else if (sum === maxSum) {
    count++;
  }
}

// 3. 출력
if (maxSum === 0) {
  console.log("SAD");
} else {
  console.log(maxSum);
  console.log(count);
}
```
