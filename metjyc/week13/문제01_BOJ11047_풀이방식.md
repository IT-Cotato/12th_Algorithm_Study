# 💰 동전 0 (BOJ 11047) 풀이 정리

## 📌 문제 요약

- N종류의 동전이 주어진다.
- 각 동전은 **무한히** 사용할 수 있다.
- 동전 가치의 합으로 정확히 K원을 만들 때,
  **필요한 동전 개수의 최솟값**을 구한다.

### 입력 조건의 핵심

- 동전 가치 `A1 = 1`
- `Ai`는 항상 `Ai-1`의 **배수**
- 동전은 **오름차순**으로 주어짐

---

## ❌ DFS / DP가 아닌 이유

- K의 최대값은 **100,000,000**
- DFS / DP로 경우를 탐색하면 시간 초과
- 하지만 **동전이 배수 관계**이기 때문에
  → **그리디(탐욕법)** 이 항상 최적해를 보장한다

---

## ✅ 해결 전략 (그리디)

### 핵심 아이디어

> **가장 큰 동전부터 가능한 한 많이 사용한다**

이 전략이 가능한 이유:

- 큰 동전 1개는 항상
  작은 동전 여러 개보다 **동전 개수가 적다**
- 배수 관계이기 때문에
  큰 동전을 쓰는 선택이 절대 손해가 아니다

---

## 🔍 왜 `cnt = K / coin` 인가?

### 의미

```js
cnt = Math.floor(K / coin);
```
