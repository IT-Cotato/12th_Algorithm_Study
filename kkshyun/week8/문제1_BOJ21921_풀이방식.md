## BOJ 21921 문제 요약

- N일 동안의 블로그 방문자 수가 주어질 때,
- 연속된 X일 동안의 방문자 수 합 중 최댓값과,
- 그 최댓값이 나오는 기간의 개수를 구하는 문제
- 단, 최댓값이 0이라면 방문자가 없었다고 보고 `"SAD"`를 출력

---

## 아이디어

- 슬라이딩 윈도우(투 포인터 느낌)
   - 먼저 첫 X일의 합을 구해 `max`와 `temp`에 저장.
   - 그 다음부터는
      - 새로 포함되는 오른쪽 값 `+ visit[i + X]`
      - 빠지는 왼쪽 값 `visit[i]`

        를 이용해 한 번의 덧셈/뺄셈만으로 다음 구간 합을 갱신.

   - 매번 `temp`와 현재까지의 최댓값 `max`를 비교해서
      - `temp > max` 이면 `max` 갱신하고, 횟수(`maxCount`)는 1로 초기화
      - `temp == max` 이면 같은 최댓값이므로 `maxCount++`
      - `temp < max` 이면 아무 변화 없음
- 마지막에 `max == 0`이면 모든 구간 합이 0이라는 뜻이므로 `"SAD"` 출력,

  아니면 `max`와 `maxCount`를 출력.


---

## 알고리즘 단계

1. 입력으로 N(전체 일수), X(연속 일수)를 읽는다.
2. N개의 방문자 수 배열 `visitNumberArray`를 입력받는다.
3. 초기 윈도우(0 ~ X-1)의 합을 구해 `max`와 `temp`에 저장하고, 이때 최댓값을 만든 구간 개수 `maxCount = 1`로 설정한다.
4. i를 0부터 `N - X - 1`까지 순회하면서,
   - 다음 구간의 합을

     `temp = temp + visit[i + X] - visit[i]` 로 갱신한다.

   - `temp`와 `max` 비교:
      - `temp > max` → `max = temp`, `maxCount = 1`
      - `temp == max` → `maxCount++`
      - `temp < max` → 그대로 유지
5. 반복이 끝난 후,
   - `max == 0`이면 `"SAD"` 출력
   - 그렇지 않으면 `max`와 `maxCount`를 순서대로 출력

## 코드

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int X = Integer.parseInt(s[1]);
        int[] visitNumberArray = new int[N];
        int max = 0;
        int maxCount = 1;
        s = br.readLine().split(" ");
        for (int i = 0; i < N; i++) {
            visitNumberArray[i] = Integer.parseInt(s[i]);
        }
        for (int i = 0; i < X; i++) {
            max += visitNumberArray[i];
        }
        int temp = max;
        for (int i = 0; i < N-X; i++) {
            temp += visitNumberArray[i + X] - visitNumberArray[i];
            if(max == temp) {
                maxCount++;
            } else if(max < temp) {
                max = temp;
                maxCount = 1;
            }
            // max > temp 면 변화 없음
        }
        if(max == 0)
            bw.write("SAD\n");
        else
            bw.write(max+"\n"+maxCount);
        bw.flush();
        bw.close();
    }
}
```
