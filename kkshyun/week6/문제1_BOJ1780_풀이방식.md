## BOJ 1780 문제 요약

- 크기가 N×N(N=3^k)인 종이가 있고, 각 칸에는 -1, 0, 1 중 하나의 값이 들어 있음
- 어떤 정사각형 구역의 모든 값이 같다면 해당 값의 종이 1장을 얻은 것으로 간주
- 그렇지 않다면 그 구역을 3×3, 즉 같은 크기의 아홉 개 정사각형으로 분할하여 각각에 대해 같은 과정을 재귀적으로 반복
- 최종적으로 값이 -1인 종이 수, 0인 종이 수, 1인 종이 수를 차례로 출력

---

## 아이디어

- 분할 정복
    - 현재 구간이 전부 같은 값인지 한 번 훑어 확인. 같다면 해당 값 카운트를 1 증가시키고 종료
    - 모두 같지 않다면 가로와 세로를 각각 3등분하여 3×3 = 9개의 부분 구간으로 나누고, 각 구간에 대해 재귀 호출
    - 기저 조건은 구간 크기가 1×1일 때로 두고, 그 칸의 값을 카운트
    - 최종 해답은 각 재귀 호출에서 얻은 카운트의 합

---

## 알고리즘 단계

- 입력을 N×N 배열 `graph[col][row]` 에 저장
- 함수 `checkPaperCount(c1, c2, r1, r2)`를 재귀 호출
    1. 입력받은 구간의 값들이 모두 같은지 확인
    2. 동일하면 카운트 증가 후 리턴
    3. 아니면 `size/3`으로 9등분 후 각각 재귀
- 마지막에 `count[-1], count[0], count[1]` 순으로 출력 (`count[0], count[1], count[2]`)

## 코드

```java
import java.io.*;

public class Main {
    public static int[] count;
    public static int[][] graph;
    public static int N;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        N = Integer.parseInt(br.readLine());
        graph = new int[N][N];
        count = new int[3]; // count[0] : -1인 종이 수, count[1] : 0인 종이 수, count[2] : 1인 종이 수
        String[] s;
        for (int i = 0; i < N; i++) {
            s = br.readLine().split(" ");
            for (int j = 0; j < s.length; j++) {
                graph[i][j] = Integer.parseInt(s[j]);
            }
        }

        checkPaperCount(0, N-1, 0, N-1);
        for (int i = 0; i < 3; i++) {
            bw.write(count[i]+"\n");
        }
        bw.flush();
        bw.close();
    }

    public static void checkPaperCount(int col1, int col2, int row1, int row2) {
        if(col2-col1==0 || row2-row1==0) {
            count[graph[col1][row1]+1]++;
            return;
        }
        int num = graph[col1][row1];
        for (int i = col1; i <= col2; i++) {
            for (int j = row1; j <= row2; j++) {
                if(num != graph[i][j]) {
                    int width = (col2-col1+1)/3;
                    int height = (row2-row1+1)/3;
                    for (int k = col1; k <= col2; k+=width) {
                        for (int l = row1; l <= row2; l+=height) {
                            checkPaperCount(k,k+height-1,l,l+width-1);
                        }
                    }
                    return;
                }
            }
        }
        count[num+1]++;
    }
}
```
