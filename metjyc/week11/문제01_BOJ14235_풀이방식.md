BOJ 14235 크리스마스 선물

문제 요약

산타가 방문하는 곳은 두 종류다.
	•	거점지 (a > 0): 선물 a개를 충전한다. (각 선물은 “가치” 값)
	•	아이 (a = 0): 산타가 가진 선물 중 가장 가치가 큰 선물 1개를 준다.
	•	줄 선물이 없으면 -1 출력

즉, 입력을 위에서 아래로 처리하면서
	•	선물은 계속 “추가”되고
	•	아이를 만나면 매번 “현재까지의 최댓값 1개”를 꺼내야 한다.

⸻

핵심 아이디어

아이(0)를 만날 때마다 “가장 큰 값 1개”를 빠르게 꺼내야 한다.
	•	배열에 계속 넣고 정렬을 반복하면(특히 sort, shift) 시간/메모리가 크게 증가할 수 있음.
	•	그래서 “최댓값 꺼내기”에 최적화된 자료구조인 최대 힙(Max Heap) 을 사용한다.

⸻

Max Heap 이란?

규칙 (Max Heap)
	•	부모 값 ≥ 자식 값을 항상 만족한다.
	•	그래서 항상 루트(배열 0번) 가 최댓값이다.

배열로 힙을 구현하는 이유

트리를 직접 만들지 않고, 배열 인덱스 규칙으로 트리를 “흉내”낸다.

인덱스 규칙:
	•	부모 인덱스: Math.floor((i - 1) / 2) (또는 (i - 1) >> 1)
	•	왼쪽 자식: i * 2 + 1
	•	오른쪽 자식: i * 2 + 2

⸻

this.h는 무슨 의미?

this.h는 힙(선물 주머니)에 실제로 저장되는 배열이다.

class MaxHeap {
  constructor() {
    this.h = []; // 선물 가치들이 들어가는 저장소
  }
}

	•	MaxHeap 객체마다 자기만의 배열을 가진다.
	•	외부에서는 push, pop 같은 메서드로만 힙을 사용한다.

⸻

push(x)의 역할

문제에서 의미
	•	거점지에서 선물 x를 산타가 가진 선물 목록에 추가하는 동작

구현에서 하는 일 (sift-up: 위로 올리기)
	1.	배열 마지막에 x를 추가
	2.	부모보다 크면 부모랑 바꾼다
	3.	더 이상 부모보다 크지 않을 때까지 반복

왜 부모를 알아야 하나?
	•	새로 들어온 값이 부모보다 크면 “부모 ≥ 자식” 규칙이 깨지기 때문
	•	그래서 부모와 비교하며 올려서 규칙을 복구한다.

⸻

pop()의 역할

문제에서 의미
	•	아이를 만나면 가장 큰 가치 선물 1개를 꺼내서 지급하는 동작

구현에서 하는 일 (sift-down: 아래로 내리기)
	1.	최댓값은 항상 h[0] → top = h[0] 저장
	2.	배열 마지막 값을 꺼냄 → last = h.pop()
	3.	힙이 아직 남아있다면 h[0] = last로 루트를 대체
	4.	규칙이 깨졌을 수 있으니 아래로 내려가며 정리
	•	자식 둘 중 더 큰 자식과 비교
	•	내가 더 작으면 swap
	•	더 이상 작지 않으면 종료
	5.	top 반환

⸻

last = h.pop() 이 줄이 의미하는 것

여기서 h.pop()은 배열의 pop(맨 뒤 제거) 이다.

const last = h.pop();

의미:
	•	힙 배열의 맨 마지막 값을 꺼내서 last에 저장한다.

왜 마지막 값을 꺼내나?
	•	힙은 “완전 이진 트리” 형태를 유지해야 해서,
루트(h[0])를 그냥 지우면 구조가 깨진다.
	•	그래서:
	•	루트 값(top)을 따로 저장하고
	•	마지막 값을 루트로 올려 자리를 메운 뒤
	•	아래로 내려가며 규칙을 복구한다.

⸻

비트 연산자 >> 1을 쓰는 이유

const p = (i - 1) >> 1;

	•	x >> 1은 Math.floor(x / 2)와 동일한 “정수 나눗셈”이다.
	•	힙에서는 부모 인덱스를 구할 때 Math.floor((i - 1) / 2)가 필요하고,
이를 짧게 쓴 표현이 (i - 1) >> 1이다.
	•	꼭 비트를 써야 하는 건 아님. 아래도 동일하게 동작한다:

const p = Math.floor((i - 1) / 2);


⸻

시간복잡도
	•	push: O(log N)
	•	pop: O(log N)
	•	전체 입력은 최대 약 5000줄, 한 줄에 최대 100개 선물 추가 가능 → 힙이면 충분히 통과

⸻

Node.js 정답 코드 (MaxHeap 구현)

const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

class MaxHeap {
  constructor() {
    this.h = [];
  }

  size() {
    return this.h.length;
  }

  push(x) {
    const h = this.h;
    h.push(x);
    let i = h.length - 1;

    while (i > 0) {
      const p = (i - 1) >> 1; // 부모 인덱스
      if (h[p] >= h[i]) break;
      [h[p], h[i]] = [h[i], h[p]];
      i = p;
    }
  }

  pop() {
    const h = this.h;
    if (h.length === 0) return null;

    const top = h[0];
    const last = h.pop();

    if (h.length > 0) {
      h[0] = last;
      let i = 0;

      while (true) {
        const l = i * 2 + 1;
        const r = i * 2 + 2;
        let best = i;

        if (l < h.length && h[l] > h[best]) best = l;
        if (r < h.length && h[r] > h[best]) best = r;

        if (best === i) break;

        [h[i], h[best]] = [h[best], h[i]];
        i = best;
      }
    }

    return top;
  }
}

const n = Number(input[0]);
const heap = new MaxHeap();
let out = [];

for (let i = 1; i <= n; i++) {
  const arr = input[i].split(" ").map(Number);
  const a = arr[0];

  if (a === 0) {
    const val = heap.pop();
    out.push(val === null ? "-1" : String(val));
  } else {
    for (let j = 1; j <= a; j++) heap.push(arr[j]);
  }
}

console.log(out.join("\n"));

헷갈릴 때 한 줄 요약
	•	push: “선물 넣고, 큰 값은 위로 올려서 h[0]이 최댓값이 되게”
	•	pop: “h[0] 꺼내고, 마지막 값을 루트로 올린 뒤 아래로 내려가며 정리”
