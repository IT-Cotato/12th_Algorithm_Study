# 백준 1987번 - 알파벳

## 📌 문제 설명

세로 `R`칸, 가로 `C`칸의 보드가 주어지고, 각 칸에는 대문자 알파벳이 하나씩 적혀 있다.  
좌측 상단 `(1행 1열)`에서 말이 시작하며, 말은 상하좌우로 인접한 칸으로 이동할 수 있다.  
단, **지금까지 지나온 칸에 적힌 알파벳과 같은 알파벳이 있는 칸은 이동할 수 없다.**

좌측 상단에서 시작하여 말이 **최대로 이동할 수 있는 칸의 수**를 구하는 문제이다.  
(시작 칸도 포함한다)

---

## 🧩 입력

- 첫 줄: `R C` (1 ≤ R,C ≤ 20)
- 다음 `R`줄: 보드의 알파벳 정보

## 🧩 출력

- 말이 지날 수 있는 최대 칸 수

---

## 💡 핵심 개념

1. **DFS (깊이 우선 탐색)**

   - 모든 가능한 경로를 탐색해야 하므로 DFS 사용.
   - 한 경로 끝까지 탐색 → 돌아와서 다른 경로도 탐색해야 하므로 **백트래킹** 필요.

2. **백트래킹**

   - 특정 알파벳을 방문한 상태로 탐색을 진행하고, 탐색이 끝나면 다시 방문 해제.
   - 이를 통해 다른 경로에서도 해당 알파벳을 사용할 수 있게 함.

3. **방문 처리 방법**

   - `Set` 자료구조 사용 → 현재까지 방문한 알파벳을 기록.
   - 새로운 칸의 알파벳이 `Set`에 없으면 추가 후 이동.
   - DFS 종료 시 `Set.delete()`로 원상복구.

4. **탐색 종료 조건**
   - 더 이상 갈 수 있는 방향이 없을 때 탐색 종료.
   - 이때까지 방문한 칸 수(`visited.size`)를 최대값으로 갱신.

---

## 🛠 풀이 방법 (접근 과정)

1. 입력을 받아 `R x C` 보드를 2차원 배열로 저장.
2. 시작 위치 `(0,0)`의 알파벳을 `visited` 집합에 추가.
3. DFS를 사용해 4방향(상하좌우)으로 이동:
   - 보드 범위 안에 있고
   - 아직 방문하지 않은 알파벳이라면
     - `visited`에 추가 → DFS 재귀 호출 → 탐색 종료 후 다시 `delete` (백트래킹).
4. 탐색하면서 `maxCount = Math.max(maxCount, visited.size)`로 최대 경로 길이를 갱신.
5. 최종적으로 `maxCount` 출력.
