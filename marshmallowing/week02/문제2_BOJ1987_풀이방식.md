# BOJ 1987 - 알파벳

## 문제
- R×C 보드에 대문자 알파벳이 적혀 있다.
- (0,0) 위치에서 시작해 상하좌우로 이동 가능.
- 단, **지나온 칸의 알파벳은 다시 방문 불가**.
- 만들 수 있는 경로의 최대 길이를 구하라.

---

## 풀이 아이디어
- DFS + 백트래킹 사용.
- `visited[26]` 배열을 이용해 알파벳 방문 여부 체크.
- 이동할 때마다 방문 처리 → 재귀 탐색 → 복귀 시 방문 해제.
- 최대 깊이를 전역 변수로 갱신.

---

## 핵심 코드
```java
int R, C, answer = 0;
char[][] board;
boolean[] visited = new boolean[26];

void dfs(int x, int y, int depth) {
    answer = Math.max(answer, depth);

    int[] dx = {-1, 1, 0, 0};
    int[] dy = {0, 0, -1, 1};

    for (int i = 0; i < 4; i++) {
        int nx = x + dx[i];
        int ny = y + dy[i];

        if (nx >= 0 && ny >= 0 && nx < R && ny < C) {
            int idx = board[nx][ny] - 'A';
            if (!visited[idx]) {
                visited[idx] = true;
                dfs(nx, ny, depth + 1);
                visited[idx] = false; // 백트래킹
            }
        }
    }
}
