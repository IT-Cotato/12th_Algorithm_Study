#  BOJ 11404 — 플로이드 (Floyd–Warshall)

##  문제 개요
N개의 도시와 M개의 버스 노선이 주어질 때,  
각 도시에서 다른 모든 도시로 가는 **최소 비용**을 구하는 문제.  
도시 수가 100 이하이므로 모든 쌍 최단경로 알고리즘인 **Floyd–Warshall** 사용이 적합하다.

---

##  핵심 아이디어
- `dist[i][j]`: i → j로 가는 최소비용
- **k를 경유지로 하는 경우를 점진적으로 허용**하며 갱신
- 자기 자신은 0, 연결되지 않은 곳은 INF로 초기화
- 같은 경로가 여러 번 주어질 수 있으므로 최소값만 저장

---
## 구현 요약
- INF 초기화 (1e9 이상)
- 자기자신 0으로
- 모든 버스 정보 입력 (중복 최소화)
- 3중 루프로 최소값 갱신
- 출력 시 INF면 0

## 시간복잡도
- O(N³) → N=100이므로 충분히 가능.
- 메모리 O(N²)

---
##  주요 코드
```java
int[][] dist = new int[n + 1][n + 1];
for (int i = 1; i <= n; i++) {
  Arrays.fill(dist[i], INF);
  dist[i][i] = 0;
}

for (int i = 0; i < m; i++) {
  int a = sc.nextInt(), b = sc.nextInt(), c = sc.nextInt();
  dist[a][b] = Math.min(dist[a][b], c); // 중복 간선 최소화
}

// 핵심 3중 루프
for (int k = 1; k <= n; k++) {
  for (int i = 1; i <= n; i++) {
      for (int j = 1; j <= n; j++) {
          if (dist[i][k] + dist[k][j] < dist[i][j]) {
              dist[i][j] = dist[i][k] + dist[k][j];
          }
      }
  }
}
```
