# 문제
n x n 도시에서 m개 만큼의 치킨집만 남을 때 도시의 최소 치킨거리 구하기

## dfs + 백트래킹 이용
좌표값을 통해 치킨집과의 거리를 알 수 있으므로 bfs를 사용하지 않아도 된다.
- 사전에 치킨집의 좌표와 집의 좌표를 저장 -> `Point` 클래스 이용
- 선택된 치킨집을 구별 -> `selected` 배열 이용
- 치킨집을 없애는 경우의 수 -> dfs 이용 + 백트래킹 이용
- 없어진 경우의 수에서 치킨 거리 계산 -> `calcDist()`

## 1. Point 클래스
```java
class Point{
    int x, y;
    Point(int x, int y){
        this.x = x;
        this.y = y;
    }
}
```
- 좌표를 저장하기 위한 클래스

## 2. 선택된 치킨집을 찾기 위한 배열(백트래킹에 이용)
`public static boolean[] selected;`

## 3. 치킨집을 없애는 경우의 수
```java
public static void dfs(int start, int count){
    if(count == m){
        calcDist();
        return;
    }

    for(int i = start; i < chicken.size(); i++){
        selected[i] = true;
        dfs(i + 1, count + 1);
        selected[i] = false;
    }
}
```
- m개 만큼의 치킨 집이 남은 경우 치킨 거리를 계산한다.
- 그렇지 않다면 백트래킹을 이용하여 모든 경우의 수를 고려한다.

## 4. 치킨 거리 계산하기
```java
public static void calcDist(){
    int totalDist = 0;

    for(Point house : houses){
        int minDist = Integer.MAX_VALUE;

        for(int i = 0; i < chicken.size(); i++){
            if(selected[i]){
                int dist = Math.abs(house.x - chicken.get(i).x) + Math.abs(house.y - chicken.get(i).y);
                minDist = Math.min(dist, minDist);
            }
        }
        totalDist += minDist;
    }

    result = Math.min(result, totalDist);
}
```

### 전체 코드
```java
package kingmingyu.week12;

import java.util.*;
import java.io.*;

class Point{
    int x, y;
    Point(int x, int y){
        this.x = x;
        this.y = y;
    }
}

public class 문제3_BOJ15686_풀이 {
    public static int n, m;
    public static List<Point> houses = new ArrayList<>();
    public static List<Point> chicken = new ArrayList<>();
    public static boolean[] selected;
    public static int result = Integer.MAX_VALUE;

    public static void main(String[] args) throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        for(int i = 0; i < n; i++){
            st = new StringTokenizer(br.readLine());
            for(int j = 0; j < n; j++){
                int now = Integer.parseInt(st.nextToken());
                if(now == 1) houses.add(new Point(i, j));
                if(now == 2) chicken.add(new Point(i, j));
            }
        }

        dfs(0, 0);

        System.out.println(result);

    }

    public static void dfs(int start, int count){
        if(count == m){
            calcDist();
            return;
        }

        for(int i = start; i < chicken.size(); i++){
            selected[i] = true;
            dfs(i + 1, count + 1);
            selected[i] = false;
        }
    }

    public static void calcDist(){
        int totalDist = 0;

        for(Point house : houses){
            int minDist = Integer.MAX_VALUE;

            for(int i = 0; i < chicken.size(); i++){
                if(selected[i]){
                    int dist = Math.abs(house.x - chicken.get(i).x) + Math.abs(house.y - chicken.get(i).y);
                    minDist = Math.min(dist, minDist);
                }
            }
            totalDist += minDist;
        }

        result = Math.min(result, totalDist);
    }
}

```
