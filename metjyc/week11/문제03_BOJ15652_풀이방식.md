# 📌 BOJ 15651 - N과 M (3)

## 🔍 문제 요약

- 자연수 `N`, `M`이 주어진다.
- **1부터 N까지의 수 중에서 M개를 고른 수열**을 모두 출력한다.
- 같은 수를 **여러 번 선택할 수 있다**.
- 수열은 **사전순(오름차순)** 으로 출력한다.

---

## 🧠 핵심 개념

### 1️⃣ 백트래킹 (Backtracking)

- **모든 경우의 수를 탐색**하되,
- 조건에 맞는 경우만 출력하는 방식
- 재귀 함수로 구현하는 것이 일반적

---

### 2️⃣ depth의 의미

- `depth`는 **현재 몇 번째 자리를 채우고 있는지**를 의미
- `depth === M` 이면  
  → 길이 `M`의 수열이 완성된 상태

---

### 3️⃣ 중복 허용 → visited 필요 없음

- 같은 숫자를 여러 번 골라도 되기 때문에
- **이미 사용한 숫자를 체크할 필요가 없다**
- 따라서 `visited` 배열 없이 구현 가능

---

### 4️⃣ 사전순 출력이 자동으로 되는 이유

- 각 자리에서 숫자를 **1부터 N까지 순서대로 선택**
- 깊이 우선 탐색(DFS) 구조 자체가 사전순을 보장

---

## 🧩 접근 방법 정리

1. 길이 `M`짜리 배열 `arr` 생성
2. 재귀 함수 `dfs(depth)` 정의
3. 종료 조건
   - `depth === M` → 수열 완성 → 출력
4. 반복문
   - `1 ~ N`까지 숫자를 현재 자리에 넣고
   - 다음 자리로 이동 (`dfs(depth + 1)`)

---

## 💻 코드 구현 (Node.js)

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split(/\s+/).map(Number);

const [N, M] = input;

const arr = Array(M);
const out = [];

function dfs(depth) {
  if (depth === M) {
    out.push(arr.join(" "));
    return;
  }

  for (let i = 1; i <= N; i++) {
    arr[depth] = i;
    dfs(depth + 1);
  }
}

dfs(0);
console.log(out.join("\n"));
```
