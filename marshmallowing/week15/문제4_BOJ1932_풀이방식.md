# BOJ 1932 

## 문제 접근 방법 (DP)

정수 삼각형 문제는 위에서부터 아래로 내려가며 숫자를 선택할 때,
선택한 수들의 합이 최대가 되는 경로를 구하는 문제이다.

각 칸에서는 **바로 위의 대각선 왼쪽 또는 대각선 오른쪽**에서만 내려올 수 있으므로,
이전 행의 정보만을 이용해 현재 행의 최대 합을 구할 수 있다.

---

## DP 정의

`dp[i][j]`  
→ **i번째 행, j번째 열까지 도달했을 때 얻을 수 있는 최대 합**

---

## 점화식

삼각형의 각 위치는 세 가지 경우로 나뉜다.

1. **맨 왼쪽 (j = 0)**  
   바로 위의 왼쪽 대각선이 없으므로,
   ```
   dp[i][0] = dp[i - 1][0] + 현재 값
   ```

2. **맨 오른쪽 (j = i)**  
   바로 위의 오른쪽 대각선이 없으므로,
   ```
   dp[i][i] = dp[i - 1][i - 1] + 현재 값
   ```

3. **중간 위치 (0 < j < i)**  
   위에서 내려올 수 있는 두 경로 중 더 큰 값을 선택한다.
   ```
   dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + 현재 값
   ```

---

## 초기값

삼각형의 첫 번째 값은 그대로 사용한다.
```
dp[0][0] = triangle[0][0]
```

---

## 정답 도출

삼각형의 마지막 행에 있는 값들 중 **가장 큰 값**이
위에서부터 내려왔을 때 만들 수 있는 최대 합이다.

```
max(dp[n - 1][0], dp[n - 1][1], ..., dp[n - 1][n - 1])
```

## 핵심 정리

- 모든 경로를 직접 탐색할 필요는 없다.
- 각 위치까지 도달할 수 있는 **최대 합만 저장**하면 충분하다.
- 같은 위치에 도달한 경로 중 합이 작은 경로는,
  이후에 어떤 값을 더하더라도 큰 경로를 역전할 수 없으므로 버려도 된다.
