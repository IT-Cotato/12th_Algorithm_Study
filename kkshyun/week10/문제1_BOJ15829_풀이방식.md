## BOJ 15829 문제 요약

- 알파벳 소문자로 이루어진 길이 L의 문자열 입력
- 각 문자 `a~z`를 `1~26`으로 변환한 값 `val` 사용
- 해시값 계산 후 출력하는 문제

$$
H = \left( \sum_{i=0}^{L-1} (val_i \cdot 31^i) \right) \bmod 1234567891
$$

---

## 아이디어

- 모듈러 연산과 거듭제곱 누적 방식 사용
- `Math.pow(31, i)` 사용 시 실수 오차 발생 가능성이 있어 정수 누적 방식 채택
- `r`을 `31^i % MOD`로 유지하는 방식 적용
    - 초기값 `r = 1`은 `31^0` 의미
    - 다음 항으로 이동 시 `r = (r * 31) % MOD`로 갱신하는 구조
- 각 문자의 기여값을 `val * r`로 계산 후 `sum`에 누적하는 방식
- 매 단계마다 `% MOD` 적용하여 오버플로우 방지 및 모듈러 값 유지

---

## 알고리즘 단계

1. 입력으로 문자열 길이 L 읽기
2. 문자열 읽기
3. `sum = 0`, `r = 1`, `MOD = 1234567891` 초기화
4. `i = 0`부터 `L-1`까지 반복 수행
    - `val = (문자 - 'a' + 1)`로 문자값 변환
    - `sum = (sum + val * r) % MOD`로 누적합 갱신
    - `r = (r * 31) % MOD`로 다음 거듭제곱 값 갱신
5. 최종 `sum` 출력

---

## 코드

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        int L = Integer.parseInt(br.readLine());
        String charArray = br.readLine();
        long sum = 0L;
        long MOD = 1234567891L;
        long r = 1L;
        for (int i = 0; i < L; i++) {
            int val = charArray.charAt(i) - 'a' + 1;
            sum = (sum + val * r) % MOD;
            r = (r * 31) % MOD;
        }
        bw.write(sum+"\n");
        bw.flush();
        bw.close();
    }
}
```
