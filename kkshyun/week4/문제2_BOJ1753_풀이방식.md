## BOJ 1753 문제 요약

- 방향 그래프에서 시작 정점 KKK로부터 다른 모든 정점까지의 최단 거리를 구하는 문제
- 간선 가중치는 음수 없음
- 도달 불가능한 정점은 INF로 출력

---

## 아이디어

- 다익스트라 + 우선순위 큐로 시작 정점에서 모든 정점까지의 최단거리 계산
- visited 배열로 우선순위 큐에서 처음 꺼낸 시점에 최단거리 확정
- 인접 리스트(ArrayList<Node>[])로 그래프 저장
- 서로 다른 두 정점 사이에 간선이 여러 개여도, 다익스트라 과정에서 자연스럽게 더 짧은 경로만 살아남는다고 생각해 별도 전처리 과정을 거치지 않음

---

## 알고리즘 단계

- 입력으로 V, E, K 받고, 인접 리스트 그래프 구성
- dist=INF, dist[K]=0, visited=false로 초기화하고 우선순위 큐에 시작정점 (K,0) 넣음
- 우선순위 큐가 빌 때까지:
    - 최소 거리 정점 u를 pop → visited[u]=true
    - u의 이웃 v에 대해 dist[v] > dist[u] + w면 갱신하고 우선순위 큐에 넣음
- 모든 정점에 대해 dist 출력(도달 불가면 INF)

---

## 코드

```java
import java.io.*;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.PriorityQueue;

public class Main {
    static class Node {
        int index, cost;
        public Node(int end, int cost) {
            this.index = end;
            this.cost = cost;
        }
    }
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int V = Integer.parseInt(s[0]);
        int E = Integer.parseInt(s[1]);
        int K = Integer.parseInt(br.readLine());

        ArrayList<Node>[] graph = new ArrayList[V+1];
        for (int i = 0; i < graph.length; i++) {
            graph[i] = new ArrayList<>();
        }

        for (int i = 0; i < E; i++) {
            s = br.readLine().split(" ");
            int start = Integer.parseInt(s[0]);
            int end = Integer.parseInt(s[1]);
            int weight = Integer.parseInt(s[2]);
            graph[start].add(new Node(end, weight));
        }

        int[] dist = new int[V+1];
        boolean[] visited = new boolean[V+1];

        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[K] = 0;

        PriorityQueue<Node> pq = new PriorityQueue<>((o1,o2) -> Integer.compare(o1.cost, o2.cost));
        pq.add(new Node(K, 0));
        while(!pq.isEmpty()) {
            Node now = pq.poll();
            if(visited[now.index]) continue;
            visited[now.index] = true;

            for(Node next : graph[now.index]) {
                if(dist[next.index] > dist[now.index] + next.cost) {
                    dist[next.index] = dist[now.index] + next.cost;
                    pq.add(new Node(next.index, dist[next.index]));
                }
            }
        }

        for (int i = 1; i < V+1; i++) {
            if(dist[i] == Integer.MAX_VALUE)
                bw.write("INF\n");
            else
                bw.write(dist[i]+"\n");
        }
        bw.flush();
        bw.close();
    }
}
```
