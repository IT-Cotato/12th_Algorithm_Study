## BOJ 1806 문제 요약

- 길이 N인 양의 정수 배열이 주어진다.
- 연속된 부분 수열(연속 구간)의 합이 S 이상이 되는 것 중

  길이가 가장 짧은 부분 수열의 길이를 구하는 문제

- 조건을 만족하는 부분 수열이 없으면 0을 출력한다.

---

## 아이디어

- 배열 원소가 모두 양수이므로, 구간을 늘리면 합이 커지고 줄이면 합이 작아진다.
- 이 단조성을 이용해서 투 포인터(슬라이딩 윈도우)로 해결한다.
- 오른쪽 포인터 i를 한 칸씩 늘려가며 sum에 더하고,

  sum이 S 이상이 되는 순간부터는 왼쪽 포인터(startIndex)를 가능한 한 줄여서

  길이를 최소로 만든다.

- 매 순간 “조건을 만족하는 가장 짧은 현재 구간”을 갱신하고,

  전체 중 최소 길이를 답으로 유지한다.


---

## 알고리즘 단계

1. N, S를 입력받는다.
2. 배열 arr을 입력받는다.
3. 변수 준비
    - sum = 0 : 현재 구간 합
    - startIndex = 0 : 구간의 왼쪽 포인터
    - minLength = Integer.MAX_VALUE : 정답 후보(최소 길이)
4. i를 0부터 N-1까지 증가시키면서
    1. sum += arr[i] (오른쪽 포인터 확장)
    2. while (sum >= S) 반복
        - 현재 구간 [startIndex, i]는 조건을 만족하므로 길이 후보 갱신

          minLength = min(minLength, i - startIndex + 1)

        - 더 짧게 만들기 위해 왼쪽을 줄인다

          sum -= arr[startIndex]

          startIndex++

5. 반복이 끝난 뒤
    - minLength가 갱신되지 않았다면(여전히 MAX_VALUE) 조건을 만족하는 구간이 없음 → 0 출력
    - 아니면 minLength 출력

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int S = Integer.parseInt(s[1]);
        Integer[] arr = new Integer[N];
        s = br.readLine().split(" ");
        int sum = 0;
        int startIndex = 0;
        int minLength = Integer.MAX_VALUE;
        for (int i = 0; i < N; i++) {
            arr[i] = Integer.parseInt(s[i]);
            sum += arr[i];
            while(sum >= S) {
                minLength = Math.min(minLength, i-startIndex+1);
                sum -= arr[startIndex];
                startIndex++;
            }
        }
        if(minLength == Integer.MAX_VALUE)
            System.out.println(0);
        else
            System.out.println(minLength);
    }
}
```
