## BOJ 15651 문제 요약

- 1부터 N까지의 자연수 중에서 M개를 골라 수열을 만드는 문제
- 같은 수를 여러 번 선택할 수 있음
- 수열은 사전순으로 출력해야 함

---

## 아이디어

- 백트래킹 DFS
    - 선택을 하나씩 해가며 깊이 탐색하다가 끝나면 되돌아와 다른 선택으로 모든 경우를 탐색하는 DFS
- 길이가 M인 수열을 만들기 위해 depth를 1부터 시작해서 M까지 채움
- 매 depth마다 1부터 N까지 모든 숫자를 넣어보며 재귀 호출
- 중복 선택이 가능하므로 방문 체크 배열이 필요 없음

---

## 알고리즘 단계

1. 입력으로 N, M을 읽는다
2. 길이 M의 수열을 저장할 배열 arr을 만든다
3. 첫 번째 자리에 올 수 있는 값은 1부터 N까지이므로
    - i를 1부터 N까지 돌면서 dfs(i, 1)을 호출한다
4. dfs(node, depth) 동작
    - arr[depth] = node로 현재 자리를 채운다
    - depth가 M이면 수열 1개 완성이므로 arr[1]부터 arr[M]까지 출력하고 종료한다
    - depth가 M이 아니면 다음 자리를 채우기 위해
        - i를 1부터 N까지 돌면서 dfs(i, depth+1)을 호출한다
5. 모든 경우를 출력하면 종료한다

---

## 코드

```java
import java.io.*;

public class Main {
    static int M;
    static int N;
    static BufferedWriter bw;
    static int[] arr;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        N = Integer.parseInt(s[0]);
        M = Integer.parseInt(s[1]);
        arr = new int[M+1];
        for (int i = 1; i <= N; i++) {
            dfs(i,1);
        }
        bw.flush();
        bw.close();
    }

    static public void dfs(int node, int depth) throws IOException{
        arr[depth] = node;
        if(depth == M) {
            for (int i = 1; i <= M; i++) {
                bw.write(arr[i]+" ");
            }
            bw.write("\n");
            return;
        }
        for (int i = 1; i <= N; i++) {
            dfs(i, depth+1);
        }
    }
}
```
