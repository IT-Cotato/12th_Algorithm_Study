# 스택, 큐, 우선순위 큐 정리

## 📌 스택 (Stack)

- **정의**: LIFO (Last In, First Out) 구조. 마지막에 들어간 데이터가 가장 먼저 나옴.
- **주요 메서드**

  - `push(item)` : 데이터를 스택에 추가
  - `pop()` : 스택의 가장 위에 있는 데이터 제거 및 반환
  - `peek()` 또는 `top()` : 가장 위에 있는 데이터 반환 (제거하지 않음)
  - `isEmpty()` : 스택이 비어 있는지 확인

- **사용 예시**

  - 웹 브라우저 방문 기록 (뒤로 가기)
  - 괄호 검사
  - DFS(깊이 우선 탐색)

- **구현 방법**

```js
const stack = [];
stack.push(1);
stack.push(2);
console.log(stack.pop()); // 2
console.log(stack[stack.length - 1]); // top
```

## 📌 큐 (Queue)

- **정의**: FIFO (First In, First Out) 구조. 먼저 들어간 데이터가 먼저 나옴.
- **주요 메서드**

  - `enqueue(item)` : 데이터를 큐의 뒤에 추가
  - `dequeue()` : 큐의 앞에서 데이터 제거 및 반환
  - `peek()` 또는 `front()` : 가장 앞의 데이터 확인
  - `isEmpty()` : 큐가 비어 있는지 확인

- **사용 예시**

  - 프린터 대기열
  - BFS(너비 우선 탐색)
  - 캐시 구현 (LRU 등)

- **구현 방법**

```js
const queue = [];
queue.push(1); // enqueue
queue.push(2);
console.log(queue.shift()); // dequeue: 1
```

## 📌 우선순위 큐 (Priority Queue)

- **정의**: 각 요소에 우선순위를 부여하고, 우선순위가 높은 요소가 먼저 처리됨.
- **기본 구조**

  - 일반적으로 힙(Heap) 자료구조로 구현됨 (JavaScript는 내장 없음 → 직접 구현 필요)
  - **최대 힙**: 큰 값이 우선순위 높음
  - **최소 힙**: 작은 값이 우선순위 높음

- **사용 예시**

  - 작업 스케줄링
  - Dijkstra 알고리즘 (최단 경로)
  - 병원 응급실 환자 처리

- **구현 방법 예시 (최대 우선순위 기준 정렬 기반 구현)**

```js
class PriorityQueue {
  constructor() {
    this.queue = [];
  }

  enqueue(value) {
    this.queue.push(value);
    this.queue.sort((a, b) => b - a); // 우선순위 높은 순으로 정렬
  }

  dequeue() {
    return this.queue.shift();
  }

  peek() {
    return this.queue[0];
  }
}

const pq = new PriorityQueue();
pq.enqueue(5);
pq.enqueue(2);
pq.enqueue(10);
console.log(pq.dequeue()); // 10
```
