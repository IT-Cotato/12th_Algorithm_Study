# 🏠 공유기 설치 (BOJ 2110)

## 📖 문제 설명

N개의 집이 일직선 상에 있고, 각각의 좌표가 주어진다.\
이 집들 중 C개의 집에 공유기를 설치하려고 한다.

공유기를 설치할 때는 **가장 인접한 두 공유기 사이의 거리**를 가능한 한
크게 하려 한다.\
즉, 공유기 사이의 최소 거리를 최대로 만드는 것이 목표이다.

---

## 🧩 입력

- 첫째 줄: 집의 개수 `N`, 설치할 공유기 개수 `C`
- 다음 `N`줄: 각 집의 좌표

---

## 📤 출력

- 가장 인접한 두 공유기 사이의 **최대 거리**

---

## 🧠 핵심 아이디어

이 문제는 전형적인 **이분 탐색(Binary Search) + 그리디(Greedy)**
문제다.\
핵심은 "공유기 간 거리"를 기준으로 **탐색 범위를 이분 탐색**하는 것이다.

### 💡 핵심 개념

---

개념 설명

---

**이분 탐색(Binary Search)** 가능한 거리의 범위를 좁혀가며,
설치가 가능한 최대 거리를 탐색한다.

**그리디 배치(Greedy Placement)** 주어진 거리 `d`가 가능할 때,
왼쪽부터 순서대로 공유기를 설치하여
가능한 집을 세어본다.

**단조성(Monotonicity)** 거리 `d`가 가능하다면, 그보다 작은
거리도 항상 가능하다. 이 특성
덕분에 이분 탐색이 가능하다.

---

---

## 🧮 풀이 과정

1.  **좌표 정렬**\
    집들의 위치가 순서대로 정렬되어 있어야 거리 계산이 가능하다.

2.  **탐색 범위 설정**

    - 최소 거리(`lowDistance`) = 1\
    - 최대 거리(`highDistance`) = (가장 오른쪽 집 - 가장 왼쪽 집)

3.  **이분 탐색 진행**

    - `mid = (low + high) / 2`를 "거리 후보"로 둔다.
    - `canPlace(mid)` 함수를 통해 현재 거리로 C개의 공유기 설치가
      가능한지 확인한다.
    - 가능하다면 더 넓은 거리(`low = mid + 1`)로 탐색.
    - 불가능하면 더 좁은 거리(`high = mid - 1`)로 탐색.

4.  **설치 가능 여부 판단 (canPlace 함수)**\
    첫 번째 집에 공유기를 설치하고, 이후 현재 거리 `d` 이상 떨어진
    집에만 설치한다.\
    설치한 공유기 수가 `C`개 이상이면 거리 `d`는 "가능한 거리"로 본다.

---

## 🔢 예시

### 입력

    5 3
    1
    2
    8
    4
    9

### 과정 요약

- 정렬된 좌표: `[1, 2, 4, 8, 9]`
- 가능한 거리 후보를 이분 탐색:
  - `mid = 4` → 3개 설치 불가 → 거리 줄이기\
  - `mid = 2` → 설치 가능 → 거리 늘리기\
  - 최종 결과: **3**

### 출력

    3

## ⚙️ 시간 복잡도

구분 복잡도

---

정렬 O(N log N)
이분 탐색 O(log(MaxX - MinX))
각 거리 검증(`canPlace`) O(N)
**총합** **O(N log(MaxX - MinX))**

---

## 🧭 배운 점 & 핵심 포인트

- **탐색의 대상이 "값"일 수도 있다.**\
  인덱스가 아니라 "공유기 간 거리"라는 추상적인 값을 기준으로 이분
  탐색을 수행할 수 있다는 점을 배웠다.

- **그리디한 설치 검증의 단조성 덕분에 이분 탐색이 가능하다.**\
  "가능한 거리"가 넓어질수록 조건을 만족하기 어려워지는 단조 관계를
  이용했다.

- **경계 조건에 주의해야 한다.**

  - `low <= high`를 기준으로 탐색\
  - 가능한 경우 `answer = mid`로 갱신 후 `low = mid + 1`\
  - 불가능한 경우 `high = mid - 1`

## ✅ 핵심 정리

항목 내용

---

문제 유형 이분 탐색(Binary Search) + 그리디
탐색 대상 두 공유기 사이의 최소 거리
결정 함수 `canPlace(distance)` → C개 설치 가능 여부
정렬 필요 ✅ (좌표를 오름차순 정렬)
대표 예제 BOJ 2110 공유기 설치

## 🧾 참고 코드

```js
const fs = require("fs");

const input = fs.readFileSync(0, "utf8").trim().split("\n");
const [N, C] = input[0].split(" ").map(Number);

const distance = new Array(N);
for (let i = 0; i < N; i++) {
  distance[i] = Number(input[1 + i]);
}

distance.sort((a, b) => a - b);

let lowDistance = 1;
let highDistance = distance[N - 1] - distance[0];
let answer = 0;

function canPlace(d) {
  let count = 1;
  let last = distance[0];
  for (let i = 1; i < N; i++) {
    if (distance[i] - last >= d) {
      count++;
      last = distance[i];
      if (count >= C) return true;
    }
  }
  return false;
}

while (lowDistance <= highDistance) {
  const mid = Math.floor((lowDistance + highDistance) / 2);
  if (canPlace(mid)) {
    answer = mid;
    lowDistance = mid + 1;
  } else {
    highDistance = mid - 1;
  }
}

console.log(answer);
```

최적이다.
