## BOJ 2630 문제 요약

- N x N 크기의 종이가 주어진다. (N은 2의 거듭제곱)
- 각 칸은 0 또는 1로 이루어져 있고, 0은 흰색, 1은 파란색을 의미한다.
- 종이를 잘라서 모든 조각이 한 가지 색으로만 이루어지게 만들려고 한다.
- 규칙
    - 현재 종이 조각이 모두 같은 색이면 더 자르지 않고 그 색의 개수를 1 증가시킨다.
    - 한 조각 안에 0과 1이 섞여 있으면 4등분하여 같은 과정을 반복한다.
- 최종적으로 만들어진 흰색 종이 조각 수와 파란색 종이 조각 수를 출력한다.

---

## 아이디어

- 분할 정복(재귀)을 사용한다.
- 특정 구간(size x size)이 모두 같은 색인지 검사한다.
    - 모두 같은 색이면 해당 색 카운트를 증가시키고 종료한다.
    - 다른 색이 섞여 있으면 size를 절반으로 줄여 4개의 사분면에 대해 재귀 호출한다.
- 계속 4등분을 반복하면 결국 모든 조각이 단색이 되는 형태로 분해된다.

---

## 알고리즘 단계

1. N을 입력받고, N x N 배열 graph에 종이 정보를 저장한다.
2. 흰색 조각 개수 whiteCount, 파란색 조각 개수 blueCount를 0으로 초기화한다.
3. cal(0, 0, N)을 호출해 전체 종이를 처리한다.
4. cal(startX, startY, size) 동작:
    1. (startX, startY)를 기준으로 size x size 범위를 검사한다.
    2. 범위 안의 모든 값이 graph[startX][startY]와 같으면:
        - 값이 0이면 whiteCount++
        - 값이 1이면 blueCount++
        - return
    3. 하나라도 다르면 size를 절반으로 나눠 4개 구역에 대해 재귀 호출한다.
        - 왼쪽 위: (startX, startY)
        - 오른쪽 위: (startX + size/2, startY)
        - 왼쪽 아래: (startX, startY + size/2)
        - 오른쪽 아래: (startX + size/2, startY + size/2)
5. 재귀가 모두 끝나면 whiteCount와 blueCount를 출력한다.

---

## 코드

```java
import java.io.*;

public class Main {
    static int[][] graph;
    static int whiteCount = 0;
    static int blueCount = 0;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int N = Integer.parseInt(br.readLine());
        graph = new int[N][N];
        for (int i = 0; i < N; i++) {
            String[] s = br.readLine().split(" ");
            for (int j = 0; j < N; j++) {
                graph[i][j] = Integer.parseInt(s[j]);
            }
        }

        cal(0,0,N);
        bw.write(whiteCount+"\n");
        bw.write(blueCount+"\n");
        bw.flush();
        bw.close();
    }
    public static void cal(int startX, int startY, int size) {
        boolean sameColor = true;
        int color = graph[startX][startY];

        // 범위 안에 있는 숫자가 다 같은 숫자 -> 색깔++;
        // 다른 숫자가 하나라도 나오면 -> 재귀적으로 호출

        for (int i = startX; i < startX + size; i++) {
            for (int j = startY; j < startY + size; j++) {
                if(color != graph[i][j]) {
                    sameColor = false;
                }
            }
        }
        
        if(sameColor) {
            if(color == 0)
                whiteCount++;
            else
                blueCount++;
            return;
        }

        cal(startX, startY, size/2);
        cal(startX+size/2, startY, size/2);
        cal(startX, startY+size/2, size/2);
        cal(startX+size/2, startY+size/2, size/2);
    }
}
```
