# 문제
듣지도 못한 사람이면서 보지도 못한 사람을 모아서 몇명인지 출력하고 사전순으로 출력하는 프로그램 작성하기

## 풀이
듣지도 못한 사람을 먼저 Set에 저장하고(탐색 속도`O(1)`) 보지도 못한 사람을 입력받으면서 듣지도 못한 사람인지 체크하면서 만약 있다면 List에 저장한다.

그 후 List를 정렬하여(`Collections.sort(answer)`) 출력한다.

## 전체 코드
```java
package kingmingyu.week10;

import java.io.*;
import java.util.*;

public class 문제2_BOJ1764_풀이 {
    public static void main(String[] args) throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        Set<String> see = new HashSet<>();
        List<String> answer = new ArrayList<>();

        // 듣지도 못한 사람 입력받기
        for(int i = 0; i < n; i++){
            see.add(br.readLine());
        }
        
        for(int i = 0; i < m; i++){
            String name = br.readLine();
            //만약 듣지도 못한 사람이라면
            if(see.contains(name)){
                //List에 저장
                answer.add(name);
            }
        }
        
        // 이름 정렬
        Collections.sort(answer);
        System.out.println(answer.size());
        for(String name : answer){
            System.out.println(name);
        }
    }
}

```
