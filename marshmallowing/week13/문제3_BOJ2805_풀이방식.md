## 백준 2805

## 문제 요약
- N개의 나무가 있고, 각 나무의 높이가 주어진다.
- 절단기 높이를 H로 정하면, 높이가 H보다 큰 나무만 (나무 높이 - H) 만큼 잘린다.
- 잘라서 얻은 나무 길이의 총합이 **최소 M 이상**이 되도록 하는
  **절단기 높이 H의 최댓값**을 구하라.

---

## 해결 전략: 이분탐색
- 탐색 대상: **절단기 높이 H**
- 목표: `sum(H) >= M`을 만족하는 **가장 큰 H**

### 탐색 구간 설정
- `low = 0`
- `high = max(나무 높이)`

### mid에서의 판단
1. `mid` 높이로 자른다.
2. 모든 나무에 대해:
    - 나무 높이 > mid 인 경우만 `(height - mid)`를 더한다.
3. 합계 `sum` 계산

### 포인터 이동 규칙
- `sum >= M` (가능)
    - 더 높게 잘라도 되는지 확인
    - `answer = mid`
    - `low = mid + 1`
- `sum < M` (불가능)
    - 너무 높게 잘랐음
    - `high = mid - 1`

---

## 시간 복잡도
- 이분탐색: `O(log maxHeight)`
- 각 단계마다 나무 N개 순회
- 총 시간: `O(N log maxHeight)`

---
## 핵심 코드
```java
int low = 0;
int high = max;
int answer = 0;

while (low <= high) {
    int mid = low + (high - low) / 2;
    long sum = 0;

    for (int h : arr) {
        if (h > mid) {
            sum += (h - mid);
        }
    }

    if (sum >= m) {          // 가능한 경우
        answer = mid;        // 후보 저장
        low = mid + 1;       // 더 높은 높이 탐색
    } else {                 // 불가능한 경우
        high = mid - 1;      // 높이 낮춤
    }
}
