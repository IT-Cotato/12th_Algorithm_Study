### 스택(Stack)

> 리스트의 한쪽 끝으로만 자료의 삽입, 삭제 작업이 이루어지는 자료 구조

- **인터페이스**: `Deque<E>`
- **구현체**: 보통 `ArrayDeque<E>` 사용
- LIFO(후입선출) 방식으로 자료를 처리
- 저장할 기억 공간이 없는 상태에서는 데이터가 삽입되면 오버플로(Overflow) 발생
- 삭제할 데이터가 없는 상태에서 데이터를 삭제하면 언더플로(Underflow) 발생
- 사용 사례
    - **함수 호출 관리:**  함수 호출 시 콜 스택(Call Stack)을 사용하여 현재 실행 중인 함수의 상태를 저장한다. 함수가 호출될 때마다 스택에 새로운 프레임이 추가되고,
    - 함수가 종료되면 해당 프레임이 제거된다.
    - **역순 데이터 처리:** 문자열을 뒤집거나, 깊이 우선 탐색(DFS) 알고리즘에서 사용
    - **브라우저의 뒤로 가기 기능:** 사용자가 방문한 페이지의 기록을 스택에 저장
    - **수식 계산:** 수식의 괄호 검증 및 후위 표기법(Postfix) 계산 등

### 큐(Queue)

> 리스트의 한쪽에서는 삽입 작업이 이루어지고 다른 한쪽에서는 삭제 작업이, 양방향으로 이루어지는 자료 구조

- **인터페이스**: `Queue<E>`
- **구현체**:  `ArrayDeque<E>` or `LinkedList<E>`
    - 중간 삽입/삭제 많음 → `LinkedList` 고려
- FIFO(선입선출) 방식으로 자료를 처리
- 사용 사례
    - **프로세스 스케줄링**: 운영체제에서 프로세스를 관리할 때 큐를 사용
    - **네트워크 패킷 관리**: 데이터 패킷이 도착한 순서대로 처리
    - **실시간 데이터 스트림 처리**: 실시간으로 들어오는 데이터를 순차적으로 처리

  ```java
  Queue<Integer> queue = new LinkedList<>();
  System.out.println(queue.isEmpty());
  queue.add(10);
  queue.offer(20);
  queue.offer(30);
  
  System.out.println(queue.peek());//10
  System.out.println(queue.poll());//10
  System.out.println(queue.poll());//20
  ```

### 우선순위 큐(Priority Queue)

> 값이 들어간 순서와 상관없이 각 데이터가 우선순위를 가지며 높은 우선순위를 가진 데이터가 먼저 처리되는 구조

- **인터페이스**: `Queue<E>`
- **구현체**: `PriorityQueue<E>`
- 높은 우선순위의 요소를 먼저 꺼내서 처리하는 구조
    - 큐에 들어가는 원소는 비교가 가능한 기준이 있어야함
- 일반적으로 트리 종류 중 하나인 힙(heap)을 이용해 구현
    - 힙(heap)

      > 모든 부모 노드가 자식보다 작거나 같은 값을 갖는 이진트리
      >
        - 최댓값과 최솟값을 찾는 연산을 빠르게 하기 위해 고안된 완전이진트리를 기본트리로 취급
        - 최소 힙: 부모 노드의 키 값이 자식 노드의 키 값보다 항상 작은 힙 (기본)
        - 최대 힙: 부모 노드의 키 값이 자식 노드의 키 값보다 항상 큰 힙
- 내부구조가 힙으로 구성되어 있기에 시간 복잡도는 O(NLogN)
- 사용 사례
    - **다익스트라 알고리즘**: 최단 경로를 찾는 알고리즘에서 우선순위 큐를 사용하여 현재까지의 최단 거리를 관리
    - **이벤트 스케줄링**: 우선순위에 따라 이벤트를 처리
    - **히프 정렬(Heap Sort)**: 정렬 알고리즘에서 우선순위 큐를 활용

  ```java
  Queue<Integer> pq = new PriorityQueue<>();
  pq.offer(5);
  pq.offer(1);
  pq.offer(3);
  
  System.out.println(pq.poll()); // 1
  System.out.println(pq.poll()); // 3
  System.out.println(pq.poll()); // 5
  ```

  ```java
  import java.util.PriorityQueue; //import
  
  //int형 priorityQueue 선언 (우선순위가 낮은 숫자 순)
  PriorityQueue<Integer> priorityQueue = new PriorityQueue<>();
  
  //int형 priorityQueue 선언 (우선순위가 높은 숫자 순)
  PriorityQueue<Integer> priorityQueue = new PriorityQueue<>(Collections.reverseOrder());
  
  //String형 priorityQueue 선언 (우선순위가 낮은 숫자 순)
  PriorityQueue<String> priorityQueue = new PriorityQueue<>(); 
    
    //String형 priorityQueue 선언 (우선순위가 높은 숫자 순)
    PriorityQueue<String> priorityQueue = new PriorityQueue<>(Collections.reverseOrder());
    ```

### 덱(Deque)

> Double Ended Queue의 줄임말고, 큐의 양 사이드에서 엘리먼트의 삽입과 삭제가 가능한 자료구조

- Queue 인터페이스를 확장한 인터페이스
- queue와 stack이 합쳐진 구조로, 자료구조의 맨 앞과 맨 뒤 삽입, 삭제를 모두 지원
- LinkedList 보다는 ArrayDeque 을 사용을 권장

  ```java
  class TestClass {
        
      public static void main(String[] args) throws InterruptedException {
          
          System.out.println("Stack!!");
          Deque<String> stack = new ArrayDeque<>();
          stack.addFirst("Element1");
          stack.addFirst("Element2");
          stack.addFirst("Element3");
          System.out.println(stack.removeFirst());
          System.out.println(stack.removeFirst());
          System.out.println(stack.removeFirst());
          
          System.out.println("Queue!!");
          Deque<String> queue = new ArrayDeque<>();
          queue.addFirst("Element1");
          queue.addFirst("Element2");
          queue.addFirst("Element3");
          System.out.println(queue.removeLast());
          System.out.println(queue.removeLast());
          System.out.println(queue.removeLast());
      }
  }
  ```
