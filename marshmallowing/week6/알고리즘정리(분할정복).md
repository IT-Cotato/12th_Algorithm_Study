# Divide and Conquer (분할 정복 알고리즘)

## 개념

> **큰 문제를 작은 문제로 나누어 각각 해결한 뒤 결과를 합치는 알고리즘 설계 기법**

즉, 다음 3단계를 거칩니다.

1. **Divide (분할)** : 문제를 더 작은 하위 문제로 나눈다.
2. **Conquer (정복)** : 하위 문제를 재귀적으로 해결한다.
3. **Combine (통합)** : 하위 문제의 결과를 합쳐 원래 문제의 답을 만든다.

---

## 대표 예시
### 1. Merge Sort (합병 정렬)
- 배열을 반으로 나누어 각각 정렬한 후 병합하는 정렬 알고리즘

```java
public class MergeSort {
public static void mergeSort(int[] arr, int left, int right) {
if (left >= right) return; // 더 이상 나눌 수 없을 때 종료

        int mid = (left + right) / 2;
        
        // 1. Divide
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        
        // 2. Conquer + Combine
        merge(arr, left, mid, right);
    }

    private static void merge(int[] arr, int left, int mid, int right) {
        int[] temp = new int[right - left + 1];
        int i = left, j = mid + 1, k = 0;

        while (i <= mid && j <= right) {
            if (arr[i] <= arr[j]) temp[k++] = arr[i++];
            else temp[k++] = arr[j++];
        }

        while (i <= mid) temp[k++] = arr[i++];
        while (j <= right) temp[k++] = arr[j++];
        
        for (int t = 0; t < temp.length; t++) {
            arr[left + t] = temp[t];
        }
    }

    public static void main(String[] args) {
        int[] arr = {38, 27, 43, 3, 9, 82, 10};
        mergeSort(arr, 0, arr.length - 1);
        for (int num : arr) System.out.print(num + " ");
    }
}
```

### 2. Quick Sort (퀵 정렬)
- 피벗(Pivot)을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽으로 분할하여 재귀 정렬

```java
public class QuickSort {
public static void quickSort(int[] arr, int left, int right) {
if (left >= right) return;

        int pivot = partition(arr, left, right);
        quickSort(arr, left, pivot - 1);
        quickSort(arr, pivot + 1, right);
    }

    private static int partition(int[] arr, int left, int right) {
        int pivot = arr[right];
        int i = left - 1;
        for (int j = left; j < right; j++) {
            if (arr[j] <= pivot) {
                i++;
                swap(arr, i, j);
            }
        }
        swap(arr, i + 1, right);
        return i + 1;
    }

    private static void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

    public static void main(String[] args) {
        int[] arr = {10, 80, 30, 90, 40, 50, 70};
        quickSort(arr, 0, arr.length - 1);
        for (int num : arr) System.out.print(num + " ");
    }
}
```

### 3. Binary Search (이진 탐색)
- 정렬된 배열에서 중앙값을 기준으로 탐색 범위를 절반씩 줄이는 방식

```java
public class BinarySearch {
public static int binarySearch(int[] arr, int target, int left, int right) {
if (left > right) return -1;

        int mid = (left + right) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] > target) return binarySearch(arr, target, left, mid - 1);
        else return binarySearch(arr, target, mid + 1, right);
    }

    public static void main(String[] args) {
        int[] arr = {1, 3, 5, 7, 9, 11};
        int target = 7;
        int index = binarySearch(arr, target, 0, arr.length - 1);
        System.out.println("Index: " + index);
    }
}
```

## Divide and Conquer 특징
- 핵심 아이디어
  - 큰 문제를 작은 문제로 분할 후 결과 병합
- 형태
  - 재귀 기반 설계
- 대표 알고리즘
  - Merge Sort, Quick Sort, Binary Search
- 장점
  - 병렬 처리 가능, 효율적인 시간 복잡도
- 단점	
  - 재귀 호출로 인한 오버헤드, 스택 메모리 사용 증가

 > Divide and Conquer는 큰 문제 → 작은 문제로 나누고 → 각각 해결 → 합치는 재귀적 접근이다. 
 > 정렬(Quick, Merge)과 탐색(Binary Search)의 핵심 기반이 된다.
