# 백준 1931번 풀이 

## 해석

목표:

* N개의 회의시간 (start, end)이 주어지면, 회의이 겹치지 않게 가장 많은 회의를 지정하기

핵심 아이디어:

* **빠른 시간에 끝나는 회의을 먼저 선호**한다
* 끝나는 시간이 빠른 회의을 먼저 선호하면, 뒤에 더 많은 회의를 넣을 수 있기 때문이다

---

## 알고리즘 설명 (Greedy)

1. **회의 목록을 각각 (start, end) 로 배열에 저장**
2. **회의를 정렬:**

    * 1차: 끝나는 시간이 빠른 순서 (end 오름차순)
    * 2차: 끝나는 시간이 같을 때는 시작 시간이 빠른 순서 (start 오름차순)
3. **순회하면서 겹치지 않는 회의만 선호**

    * 현재 회의의 시작 시간이 이전 회의의 끝시간과 같거나 더 뒤에 있으면 선호

---

## 정렬 기준 해석

```java
Arrays.sort(meetings, (a, b) -> {
    if (a[1] == b[1])
        return a[0] - b[0]; // 끝시간이 같을 때는 시작 시간이 빠른 순서
    return a[1] - b[1];     // 끝시간이 빠른 순서
});
```

* `a` 과 `b`는 현재 비교 중인 두 회의의 정보
  * Arrays.sort()가 내부적으로 여러 번 a, b를 꺼내 비교한다
* `a[1] - b[1]`가 음수면 a가 더 빠른 시간에 끝나면 앞에 오고, 양수면 뒤로 감
* `a[1] == b[1]`일 때 `a[0] - b[0]`으로 비교 → 같은 끝 시간 내에서는 시작 시간 빠른 회의가 앞으로



> "끝나는 시간이 빠른 순서로 정렬하되, 같으면 시작이 빠른 순서로 정렬"

## 전체 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int n = Integer.parseInt(br.readLine());
        int[][] meetings = new int[n][2];

        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            meetings[i][0] = Integer.parseInt(st.nextToken()); // 시작
            meetings[i][1] = Integer.parseInt(st.nextToken()); // 끝
        }

        // 정렬 기준 적용
        Arrays.sort(meetings, (a, b) -> {
            if (a[1] == b[1])
                return a[0] - b[0];
            return a[1] - b[1];
        });

        int count = 0;
        int endTime = 0;

        for (int i = 0; i < n; i++) {
            if (meetings[i][0] >= endTime) { // 겹치지 않으면 선택
                count++;
                endTime = meetings[i][1];
            }
        }

        bw.write(String.valueOf(count));
        bw.newLine();
        bw.flush();
        bw.close();
    }
}
```

---

## 시간 복잡도

* 정렬: O(N log N)
* 순회: O(N)
  → 전체: **O(N log N)**
