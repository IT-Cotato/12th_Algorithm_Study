## BOJ 11047 문제 요약

- N개의 동전 종류가 주어진다.
- 각 동전은 가치가 다르며, 같은 동전은 여러 번 사용할 수 있다.
- 합이 K원이 되도록 동전을 사용하려고 할 때, 필요한 동전 개수의 최솟값을 구한다.

---

## 아이디어

- 큰 동전부터 가능한 만큼 쓰는 그리디 전략을 사용한다.
- 현재 남은 금액 K에서, 가장 큰 동전 coin을 최대한 많이 사용하면 동전 개수를 최소화할 수 있다.
- 즉, coins를 큰 값부터 내려오면서 K가 coin 이상일 때 계속 빼고 count를 증가시킨다.
- K가 0이 되면 더 이상 계산할 필요가 없으므로 바로 종료한다.

---

## 알고리즘 단계

1. 입력으로 N, K를 받는다.
2. N개의 동전 가치를 배열 coins에 저장한다.
3. count를 0으로 초기화한다.
4. coins 배열을 뒤에서부터(가장 큰 동전부터) 순회한다.
5. 각 동전 coins[i]에 대해:
    - K가 0이면 반복을 종료한다.
    - K가 coins[i] 이상인 동안:
        - count를 1 증가시킨다.
        - K에서 coins[i]를 뺀다.
6. 최종 count를 출력한다.

---

## 코드

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int K = Integer.parseInt(s[1]);
        int[] coins = new int[N];
        int count = 0;
        for (int i = 0; i < N; i++) {
            coins[i] = Integer.parseInt(br.readLine());
        }

        for (int i = coins.length-1; i >=0 ; i--) {
            if(K == 0)
                break;
            while(K >= coins[i]) {
                count++;
                K -= coins[i];
            }
        }
        bw.write(count+"\n");
        bw.flush();
        bw.close();
    }
}
```
