# 🧭 그래프 최단 경로 알고리즘 정리 (Dijkstra & Floyd–Warshall)

## 📘 개요

그래프(Graph)는 **정점(Vertex)** 과 **간선(Edge)** 으로 이루어진 자료구조입니다.  
최단 경로(Shortest Path)는 **두 정점 간 이동 시 비용이 최소가 되는 경로**를 의미합니다.

대표적인 최단 경로 알고리즘에는 다음 두 가지가 있습니다:

1. **다익스트라 알고리즘 (Dijkstra’s Algorithm)**
2. **플로이드–워셜 알고리즘 (Floyd–Warshall Algorithm)**

이 두 알고리즘은 **입력 조건과 목적**에 따라 선택이 달라집니다.

---

## 🚀 1️⃣ 다익스트라 알고리즘 (Dijkstra)

### 💡 개념

- 하나의 **시작 정점(Start Node)** 에서 **모든 다른 정점**으로의 최단 경로를 구하는 알고리즘.
- 모든 간선의 가중치가 **음수(negative)** 가 아니어야 함.
- **탐욕적(Greedy)** 접근 방식으로, 가장 짧은 거리의 정점을 하나씩 확정시켜 나감.

---

### ⚙️ 동작 과정

1. 시작 정점의 거리를 0으로, 나머지는 무한대(`INF`)로 초기화.
2. “아직 방문하지 않은 정점 중 거리 값이 가장 작은 정점”을 선택.
3. 해당 정점을 기준으로 인접한 노드의 거리를 갱신(`relaxation`).
4. 모든 정점이 확정될 때까지 반복.

---

### 🧮 점화식

\[
dist[v] = \min(dist[v],\ dist[u] + w)
\]

- `u → v` 간선의 가중치가 `w`일 때,  
  `u`를 거쳐 `v`로 가는 경로가 더 짧으면 갱신.

---

### 🧠 핵심 특징

| 항목          | 내용                                      |
| ------------- | ----------------------------------------- |
| 알고리즘 성격 | 탐욕적(Greedy)                            |
| 입력 조건     | 음수 가중치 없음                          |
| 목적          | 단일 시작점에서 모든 노드까지의 최단 거리 |
| 자료구조      | **최소 힙(Min-Heap)** 기반 우선순위 큐    |
| 시간 복잡도   | `O(E log V)`                              |
| 대표 문제     | BOJ 1753 (최단 경로)                      |

---

## 🌐 2️⃣ 플로이드–워셜 알고리즘 (Floyd–Warshall)

### 💡 개념

- **모든 정점 쌍 (i, j)** 사이의 최단 경로를 한 번에 구하는 알고리즘.
- **동적 계획법(Dynamic Programming)** 기반의 전형적인 **DP 최단 경로** 알고리즘.
- 음수 가중치는 허용되지만, **음수 사이클(Negative Cycle)** 이 존재하면 사용 불가.

---

### ⚙️ 동작 과정

1. 모든 정점 쌍의 초기 거리 배열(`dist[i][j]`)을 구성.
   - 자기 자신(`i == j`)은 0,
   - 직접 연결된 간선은 해당 가중치로 설정,
   - 그 외는 `INF`.
2. **모든 정점 k**를 중간 경유지로 고려하며,  
   `i → k → j` 경로가 기존 `i → j`보다 짧으면 갱신.
3. 세 중첩 반복문(`k, i, j`)을 통해 전체 최단 거리 계산.

---

### 🧮 점화식

\[
dist[i][j] = \min(dist[i][j],\ dist[i][k] + dist[k][j])
\]

- `k`는 경유 가능한 중간 노드.

---

### 🧠 핵심 특징

| 항목          | 내용                                 |
| ------------- | ------------------------------------ |
| 알고리즘 성격 | 동적 계획법(DP)                      |
| 입력 조건     | 음수 가중치 가능 (단, 음수 사이클 X) |
| 목적          | 모든 정점 쌍 간의 최단 거리 계산     |
| 자료구조      | 2차원 배열(`dist[i][j]`)             |
| 시간 복잡도   | `O(V³)`                              |
| 대표 문제     | BOJ 11404 (모든 도시의 최소 비용)    |

---

---

## ⚖️ 3️⃣ 다익스트라 vs 플로이드–워셜 비교

| 구분              | 다익스트라            | 플로이드–워셜                   |
| ----------------- | --------------------- | ------------------------------- |
| **목적**          | 한 정점 → 모든 정점   | 모든 정점 → 모든 정점           |
| **가중치 조건**   | 음수 불가             | 음수 가능(단, 음수 사이클 불가) |
| **기반 개념**     | 탐욕(Greedy)          | 동적 계획법(DP)                 |
| **자료구조**      | 최소 힙 (우선순위 큐) | 2차원 배열                      |
| **시간 복잡도**   | `O(E log V)`          | `O(V³)`                         |
| **메모리 사용량** | `O(V + E)`            | `O(V²)`                         |
| **적합한 상황**   | 시작점이 하나일 때    | 모든 쌍의 최단 경로 필요할 때   |

---

## 🧭 4️⃣ 선택 가이드

| 상황                                               | 추천 알고리즘                           |
| -------------------------------------------------- | --------------------------------------- |
| **시작점이 하나** (예: 1번 노드에서 모든 노드까지) | ✅ 다익스트라                           |
| **모든 도시 쌍의 이동 비용 필요**                  | ✅ 플로이드–워셜                        |
| **간선 가중치가 음수일 수 있음**                   | ⚠️ 다익스트라 불가 → 플로이드–워셜 사용 |
| **그래프가 크고 희소함(Sparse)**                   | ✅ 다익스트라                           |
| **그래프가 작고 조밀함(Dense)**                    | ✅ 플로이드–워셜                        |

---

## 🧩 요약

- **다익스트라:** “한 점에서 출발하는 최단 경로”
- **플로이드–워셜:** “모든 점 사이의 최단 경로”
- 두 알고리즘 모두 “최단 거리 갱신”이라는 공통 구조를 가지지만,  
  **탐욕(Greedy)** vs **DP(Dynamic Programming)** 로 접근 방식이 다르다.
