### **핵심 아이디어: 포함/미포함 결정**

1. **상태 정의:** 백트래킹 함수 `backtrack(index, currentSum)`은 현재 `index`에 있는 원소를 다룰 차례이며, 지금까지의 합이 `currentSum`이라는 상태를 나타냅니다.
2. **재귀적 선택:** 각 인덱스 `index`에서 다음 두 가지 경로로 재귀 호출합니다.
    - **포함 (Include):** `backtrack(index + 1, currentSum + numbers[index])` → `numbers[index]`를 부분수열에 포함하고 다음 원소로 이동.
    - **미포함 (Exclude):** `backtrack(index + 1, currentSum)` → `numbers[index]`를 포함하지 않고 다음 원소로 이동.
3. **종료 및 카운트:** `index == N`에 도달하면 모든 원소에 대한 선택이 끝난 것이므로, 최종 `currentSum`이 목표 합 S와 같은지 확인하고 `count`를 증가시킵니다.
4. **공집합 처리:** 이 방식은 모든 원소를 미포함하는 **공집합**의 경우까지 포함하여 탐색합니다. 문제 조건상 공집합을 제외해야 하므로, S=0일 경우 공집합의 합이 0이 되어 카운트되는 1을 최종적으로 빼줍니다.

    ```java
    // 전역 변수 설정 (N: 수열 길이, S: 목표 합, numbers: 입력 배열)
    static int N, S;
    static int[] numbers;
    static int count = 0;
    
    void backtrack(int index, int currentSum) {
        
        // 3. 종료 및 카운트
        if (index == N) {
            if (currentSum == S) {
                count++;
            }
            return;
        }
    
        // 2-1. 포함 (Include) 경로
        backtrack(index + 1, currentSum + numbers[index]);
        
        // 2-2. 미포함 (Exclude) 경로
        backtrack(index + 1, currentSum);
    }
    
    // 메인 함수 실행 후 공집합 처리
    ```
