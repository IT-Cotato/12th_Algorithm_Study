# 🧠 알고리즘 정리 - Greedy Algorithm (탐욕 알고리즘)

---

## 📘 개념 정리

**Greedy Algorithm (그리디 알고리즘)** 은 문제를 해결할 때  
**현재 시점에서 가장 좋아 보이는 선택(국소 최적)** 을 반복하여  
**전체적으로 최적의 해(전역 최적)** 에 도달하려는 방법이다.

> 💡 즉, "매 순간 최선의 선택을 하는 알고리즘" 이다.

---

## ⚙️ 핵심 아이디어

그리디 알고리즘은 다음 두 가지 조건을 만족할 때 최적해를 보장할 수 있다.

| 조건                                        | 설명                                                          |
| ------------------------------------------- | ------------------------------------------------------------- |
| **탐욕 선택 속성 (Greedy Choice Property)** | 매 단계에서의 지역적 최적 선택이 전체 최적해로 이어진다.      |
| **최적 부분 구조 (Optimal Substructure)**   | 전체 문제의 최적해가 부분 문제의 최적해로부터 구성될 수 있다. |

---

## 🧩 장단점

| 구분         | 내용                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| ✅ 장점      | 구현이 간단하고 빠르다 (보통 O(N log N) 이하)                                |
| ⚠️ 단점      | 항상 최적해를 보장하지는 않는다.                                             |
| 💡 사용 조건 | 위의 두 조건(탐욕 선택 속성, 최적 부분 구조)을 만족하는 문제에서만 사용 가능 |

---

## 💡 대표적인 예시 문제

| 문제                                | 핵심 아이디어                    | 설명                                                             |
| ----------------------------------- | -------------------------------- | ---------------------------------------------------------------- |
| **거스름돈 문제**                   | 큰 동전부터 사용                 | 각 단계에서 가장 큰 단위의 동전을 최대한 사용하면 최소 개수 보장 |
| **회의실 배정 문제 (BOJ 1931)**     | 끝나는 시간이 빠른 회의부터 선택 | 가장 빨리 끝나는 회의를 먼저 배정하면 최대 개수 보장             |
| **최소 신장 트리 (Kruskal / Prim)** | 가장 가중치가 낮은 간선부터 선택 | 싸이클을 만들지 않도록 주의하며 선택                             |
| **다익스트라 알고리즘**             | 현재 최단 거리 정점부터 선택     | 방문하지 않은 정점 중 최단 거리 선택 반복                        |

---

## 💻 예제 1 - 거스름돈 문제

> 손님에게 거슬러 줄 돈이 4720원일 때,  
> 동전 단위가 [500, 100, 50, 10]원이라면  
> 최소 개수의 동전으로 거스름돈을 줄 수 있는 방법을 구하시오.

```js
function greedyCoinChange(amount, coins) {
  let count = 0;

  for (let coin of coins) {
    const num = Math.floor(amount / coin); // 해당 동전 몇 개 사용 가능한가?
    count += num;
    amount -= num * coin; // 거슬러 준 만큼 차감
  }

  return count;
}

const coins = [500, 100, 50, 10];
const amount = 4720;

console.log(greedyCoinChange(amount, coins)); // 출력: 13
```

| 단계 | 동전 단위 | 사용 개수 | 남은 금액 |
| ---- | --------- | --------- | --------- |
| 1    | 500원     | 9개       | 220       |
| 2    | 100원     | 2개       | 20        |
| 3    | 50원      | 0개       | 20        |
| 4    | 10원      | 2개       | 0         |

✅ **총 13개 동전**

## 💻 예제 2 - 회의실 배정 문제 (BOJ 1931)

> 한 개의 회의실이 있고, 겹치지 않게 회의를 배정해야 할 때  
> 최대한 많은 회의를 선택하는 방법을 구하시오.

```js
const meetings = [
  [1, 4],
  [3, 5],
  [0, 6],
  [5, 7],
  [3, 8],
  [5, 9],
  [6, 10],
  [8, 11],
  [8, 12],
  [2, 13],
  [12, 14],
];

function greedyMeeting(meetings) {
  meetings.sort((a, b) => a[1] - b[1]); // 종료 시간 기준 정렬
  let count = 0;
  let endTime = 0;

  for (let [start, end] of meetings) {
    if (start >= endTime) {
      count++;
      endTime = end;
    }
  }

  return count;
}

console.log(greedyMeeting(meetings)); // 출력: 4
```

| 선택된 회의 | 시작 | 끝  |
| ----------- | ---- | --- |
| (1,4)       | 1    | 4   |
| (5,7)       | 5    | 7   |
| (8,11)      | 8    | 11  |
| (12,14)     | 12   | 14  |

✅ **총 4개 회의 배정 가능**

## 🧠 핵심 정리

| 항목              | 내용                                     |
| ----------------- | ---------------------------------------- |
| **알고리즘 유형** | 탐욕(Greedy)                             |
| **핵심 전략**     | 매 순간 최선의 선택 반복                 |
| **적용 조건**     | 탐욕 선택 속성, 최적 부분 구조           |
| **대표 문제**     | 거스름돈, 회의실 배정, Kruskal, Dijkstra |
| **시간 복잡도**   | 보통 O(N log N) 이하                     |
