## BOJ 1654 문제 요약

- 길이가 각각 다른 K개의 랜선이 주어진다.
- 이 랜선들을 같은 길이로 잘라서 N개 이상 만들고 싶다.
- 만들 수 있는 랜선 조각의 길이 L 중에서, 조건을 만족하는 L의 최댓값을 구하는 문제
    - 조건: sum(kLength[i] / L) >= N
- 출력은 가능한 최대 길이 L이다.

---

## 아이디어

- 길이 L을 정하면 만들 수 있는 조각 개수는 각 랜선 길이를 L로 나눈 몫의 합이다.
- L이 커질수록 조각 개수는 줄어든다.
    - 즉, “L에 대한 가능 여부”가 단조성을 가진다.
- 따라서 최댓값을 찾는 이분 탐색(파라메트릭 서치)을 사용한다.
    - 가능한 구간과 불가능한 구간의 경계(최대 가능한 L)를 찾는다.
- 코드에서는 upper bound 방식으로
    - start는 가능한 쪽으로 밀고 end는 불가능한 쪽으로 당겨서
    - 최종적으로 end가 “처음으로 불가능해지는 길이”가 되게 만든다.
    - 그래서 정답은 end - 1이다.

---

## 알고리즘 단계

1. K, N을 입력받는다.
2. K개의 랜선 길이를 배열 kLength에 저장하면서 최댓값 max를 구한다.
3. 이분 탐색 범위를 [1, max+1) 로 잡는다.
    - max도 값이 될 수 있기 때문
4. binarySearch(1, max+1)을 수행해 불가능이 시작되는 첫 길이 end를 구한다.
5. 정답은 end - 1을 출력한다.

---

## binarySearch 동작 설명 (upper bound)

- 입력: start(포함), end(미포함처럼 쓰는 느낌)
- while (start < end)
    1. mid = (start + end) / 2
    2. count = sum(kLength[i] / mid) 계산
    3. count < N 이면
        - mid 길이로는 N개를 못 만드니 길이가 너무 큼 → end = mid
    4. count >= N 이면
        - mid 길이로는 가능하니 더 큰 길이를 시도 → start = mid + 1
- 루프 종료 시 end는 “처음으로 count < N이 되는 길이”
- 따라서 가능한 최대 길이는 end - 1

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    static int K, N;
    static int[] kLength;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] s = br.readLine().split(" ");
        K = Integer.parseInt(s[0]);
        N = Integer.parseInt(s[1]);
        kLength = new int[K];
        long max = 0;
        for (int i = 0; i < K; i++) {
            kLength[i] = Integer.parseInt(br.readLine());
            max = Math.max(max, kLength[i]);
        }
        System.out.println(binarySearch(1,max+1)-1);
    }

    public static long binarySearch(long start, long end) {
        long mid, count;
        while(start < end) {
            mid = (start + end) / 2;
            count = 0;
            for (int i = 0; i < K; i++) {
                count += kLength[i] / mid;
            }
            if(count < N)
                end = mid;
            else
                start = mid + 1;
        }
        return end;
    }
}
```
