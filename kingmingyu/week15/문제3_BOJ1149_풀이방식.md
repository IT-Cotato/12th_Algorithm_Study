# 문제
N개의 집을 3가지 색으로 칠하는데 N과 N-1번째 집이 색이 겹치지 않도록 칠하는 최소 비용을 출력하는 프로그램을 작성하기

### 1. 문제 입력받기
```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

int n = Integer.parseInt(br.readLine());

int[][] houses = new int[n][3];

for(int i = 0; i < n; i++){
    StringTokenizer st = new StringTokenizer(br.readLine());
    for(int j = 0; j < 3; j++){
        houses[i][j] = Integer.parseInt(st.nextToken());
    }
}
```
N개의 집과 3가지 색을 칠하는데 필요한 비용을 저장하기 위해 `int[n][3]` 배열 선언

### 2. dp 이용
```java
int[][] dp = new int[n][3];

// 첫번 째 집은 이전 집이 없으므로 최소 비용
dp[0][0] = houses[0][0];
dp[0][1] = houses[0][1];
dp[0][2] = houses[0][2];

// 두번 째 집부터 계산
for(int i = 1; i < n; i++){
    dp[i][0] = houses[i][0] + Math.min(dp[i-1][1], dp[i-1][2]);
    dp[i][1] = houses[i][1] + Math.min(dp[i-1][0], dp[i-1][2]);
    dp[i][2] = houses[i][2] + Math.min(dp[i-1][0], dp[i-1][1]);
}
```
1. 가장 첫번째 집은 이전 집과 비교할 것이 없으므로 dp[0]은 자기 자신 값으로 초기화
2. 반복문을 돌면서 i번째에 각 RGB로 칠하면 드는 비용의 최솟값을 저장
   - 0인 경우는 1, 2와 
   - 1인 경우는 0, 2와 
   - 2인 경우는 0, 1와 
   - 비교하며 최솟값 구하기(색이 겹치지 않도록 하기 위해)


### 3. 정답 출력하기
```java
System.out.println(Math.min(Math.min(dp[n-1][0], dp[n-1][1]), dp[n-1][2]));
```
n개의 개수의 집을 모두 칠한 결과에서 가장 작은 값 출력하기

### 전체 코드
```java
package kingmingyu.week15;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class 문제3_BOJ1149_풀이 {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[][] houses = new int[n][3];

        for(int i = 0; i < n; i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            for(int j = 0; j < 3; j++){
                houses[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int[][] dp = new int[n][3];

        // 첫번 째 집은 이전 집이 없으므로 최소 비용
        dp[0][0] = houses[0][0];
        dp[0][1] = houses[0][1];
        dp[0][2] = houses[0][2];

        // 두번 째 집부터 계산
        for(int i = 1; i < n; i++){
            dp[i][0] = houses[i][0] + Math.min(dp[i-1][1], dp[i-1][2]);
            dp[i][1] = houses[i][1] + Math.min(dp[i-1][0], dp[i-1][2]);
            dp[i][2] = houses[i][2] + Math.min(dp[i-1][0], dp[i-1][1]);
        }

        System.out.println(Math.min(Math.min(dp[n-1][0], dp[n-1][1]), dp[n-1][2]));
    }
}

```
