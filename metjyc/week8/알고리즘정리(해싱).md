# 🧠 알고리즘 정리 - 해싱(Hashing)

해싱(Hashing)은 **탐색·중복·빈도** 문제를 빠르게 해결하기 위한 핵심 알고리즘 개념이다.

---

## 1️⃣ 해싱(Hashing)이란?

해싱이란 데이터를 **해시 함수(Hash Function)** 를 이용해 특정 값(해시값)으로 변환하고,
이를 기반으로 저장·조회하는 기법이다.

- 배열 탐색: O(N)
- 해싱 탐색: **O(1) (평균)**

👉 "값을 어디에 둘지 미리 계산"해서 바로 접근하는 구조

---

## 2️⃣ 해싱이 필요한 이유

다음 조건이 보이면 해싱을 떠올려야 한다.

- 데이터 개수가 많다 (N ≥ 100,000)
- 특정 값의 **존재 여부**를 자주 묻는다
- **중복 제거**가 필요하다
- **빈도수(개수)** 를 세야 한다

❌ 이중 반복문 → 시간 초과
⭕ 해싱 사용 → O(N)

---

## 3️⃣ JavaScript에서의 해싱 자료구조

JavaScript에서는 주로 **Set**과 **Map**을 사용한다.

---

## 4️⃣ Set (집합)

### 🔹 개념

- 중복을 허용하지 않는 자료구조
- 값(value)만 저장

### 🔹 주요 연산

| 연산      | 설명      | 시간 복잡도 |
| --------- | --------- | ----------- |
| add(v)    | 값 추가   | O(1)        |
| has(v)    | 존재 여부 | O(1)        |
| delete(v) | 삭제      | O(1)        |
| size      | 원소 개수 | O(1)        |

### 🔹 예시

```js
const set = new Set();
set.add(1);
set.add(2);
set.add(1); // 중복 무시

set.has(2); // true
```

### 🔹 사용 상황

- 중복 제거
- 빠른 존재 여부 확인
- 교집합 / 차집합

---

## 5️⃣ Map (키-값 해시)

### 🔹 개념

- key → value 형태의 자료구조
- 빈도수 계산에 최적

### 🔹 주요 연산

| 연산      | 설명          | 시간 복잡도 |
| --------- | ------------- | ----------- |
| set(k,v)  | 값 저장       | O(1)        |
| get(k)    | 값 조회       | O(1)        |
| has(k)    | key 존재 여부 | O(1)        |
| delete(k) | 삭제          | O(1)        |

### 🔹 예시 (빈도수)

```js
const map = new Map();

for (const x of arr) {
  map.set(x, (map.get(x) || 0) + 1);
}
```

---

## 6️⃣ Set vs Map 선택 기준

| 문제 유형      | 사용 |
| -------------- | ---- |
| 중복 제거      | Set  |
| 존재 여부 확인 | Set  |
| 빈도수 세기    | Map  |
| 데이터 매핑    | Map  |

---

## 7️⃣ 알고리즘 문제에서 자주 쓰이는 패턴

### ✅ 중복 제거

```js
const unique = [...new Set(arr)];
```

### ✅ 존재 여부 확인

```js
const set = new Set(arr);
if (set.has(x)) {
  /* ... */
}
```

### ✅ 두 배열의 교집합

```js
const setA = new Set(A);
const result = [];

for (const x of B) {
  if (setA.has(x)) result.push(x);
}
```

---

## 8️⃣ 시간 복잡도 비교

| 연산 | 배열 | 해싱(Set/Map) |
| ---- | ---- | ------------- |
| 탐색 | O(N) | **O(1)**      |
| 삽입 | O(1) | O(1)          |
| 삭제 | O(N) | O(1)          |

---

## 9️⃣ 자주 하는 실수

- Set은 인덱스 접근 불가
- Map.get(key) → 없으면 undefined
- 문자열 입력 시 trim() 누락
- 객체({}) 대신 Map 사용 권장

---

## 🔚 핵심 요약

> **존재 · 중복 · 빈도 문제가 보이면 해싱(Set/Map)부터 생각한다**

---

📌 해싱은 알고리즘 문제 해결 속도를 한 단계 끌어올려 주는 핵심 개념이다.
