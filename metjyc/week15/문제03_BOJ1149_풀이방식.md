# RGB 거리 (BOJ 1149)

## 📌 문제 요약

1번 집부터 N번 집까지 일렬로 놓여 있고,  
각 집을 **빨강(R), 초록(G), 파랑(B)** 중 하나의 색으로 칠해야 한다.

각 집마다 색별 비용이 주어지며,  
**이웃한 집끼리는 같은 색을 사용할 수 없다.**

이 조건을 만족하면서 **모든 집을 칠하는 최소 비용**을 구하는 문제이다.

---

## 🧠 핵심 아이디어 (Dynamic Programming)

이 문제는 **이전 선택이 현재 선택에 영향을 주는 구조**이므로  
동적 계획법(DP)을 사용한다.

### DP의 핵심 사고

- i번째 집을 칠할 때 필요한 정보는  
  **i-1번째 집까지의 결과**뿐이다.
- 집을 어떤 색으로 칠했는지가 중요하므로  
  **마지막 집의 색별 최소 비용**을 상태로 유지한다.

---

## 📐 DP 상태 정의

- `dpR` : 현재 집까지 칠했을 때, **마지막 집이 빨강(R)** 인 경우의 최소 비용
- `dpG` : 마지막 집이 **초록(G)** 인 경우의 최소 비용
- `dpB` : 마지막 집이 **파랑(B)** 인 경우의 최소 비용

👉 항상 이 **3개의 값만 유지**하면 된다.

---

## 🚀 초기값 설정 (1번 집)

1번 집은 이전 집이 없으므로 제약 없이 시작할 수 있다.

- `dpR = 1번 집을 빨강으로 칠하는 비용`
- `dpG = 1번 집을 초록으로 칠하는 비용`
- `dpB = 1번 집을 파랑으로 칠하는 비용`

이 값들이 DP의 출발점이 된다.

---

## 🔁 점화식 (2번 집부터 N번 집까지)

현재 집의 비용이 `(r, g, b)`일 때:

- 현재 집을 **R**로 칠하면 → 이전 집은 **G 또는 B**
- 현재 집을 **G**로 칠하면 → 이전 집은 **R 또는 B**
- 현재 집을 **B**로 칠하면 → 이전 집은 **R 또는 G**

따라서 점화식은 다음과 같다:

- `nextR = min(dpG, dpB) + r`
- `nextG = min(dpR, dpB) + g`
- `nextB = min(dpR, dpG) + b`

계산 후:

- `dpR = nextR`
- `dpG = nextG`
- `dpB = nextB`

⚠️ 기존 dp 값을 바로 덮어쓰지 않기 위해  
반드시 임시 변수(`nextR`, `nextG`, `nextB`)를 사용한다.

---

## ✅ 최종 정답

N번 집까지 계산이 끝난 뒤:

```text
정답 = min(dpR, dpG, dpB)
```
