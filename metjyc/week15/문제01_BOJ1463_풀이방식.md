# 📘 1로 만들기 (Dynamic Programming)

## 🔍 문제 개요

정수 `N`이 주어졌을 때, 다음 연산을 사용하여 `N`을 `1`로 만들려고 한다.  
이때 필요한 **연산 횟수의 최솟값**을 구하는 문제이다.

### 사용할 수 있는 연산

1. `X → X - 1`
2. `X → X / 2` (단, X가 2로 나누어 떨어질 때)
3. `X → X / 3` (단, X가 3으로 나누어 떨어질 때)

---

## 💡 풀이 아이디어 (DP)

이 문제는 **작은 문제의 최적해를 이용해 큰 문제를 해결**하는  
**동적 계획법(Dynamic Programming)** 문제이다.

### 핵심 정의

- `dp[i]` : 정수 `i`를 **1로 만드는 데 필요한 최소 연산 횟수**

---

## 🧠 점화식

정수 `i (i ≥ 2)`에 대해:

1. 기본적으로 `i - 1`에서 오는 경우

dp[i] = dp[i - 1] + 1

2. `i`가 2로 나누어 떨어질 경우

dp[i] = min(dp[i], dp[i / 2] + 1)

3. `i`가 3으로 나누어 떨어질 경우

dp[i] = min(dp[i], dp[i / 3] + 1)

이렇게 **가능한 모든 이전 상태 중 최솟값**을 선택한다.

---

## 🧪 초기값

dp[1] = 0

이미 1이므로 연산이 필요 없다.

---

## 🧩 코드 구현 (JavaScript / Node.js)

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const n = Number(input[0]);

// dp[i] = i를 1로 만드는 최소 연산 횟수
const dp = Array(n + 1).fill(0);

for (let i = 2; i <= n; i++) {
  // 1을 빼는 경우
  dp[i] = dp[i - 1] + 1;

  // 2로 나누어지는 경우
  if (i % 2 === 0) {
    dp[i] = Math.min(dp[i], dp[i / 2] + 1);
  }

  // 3으로 나누어지는 경우
  if (i % 3 === 0) {
    dp[i] = Math.min(dp[i], dp[i / 3] + 1);
  }
}

console.log(dp[n]);


⸻

⏱ 시간 복잡도
	•	O(N)
→ 2부터 N까지 한 번씩 계산

💾 공간 복잡도
	•	O(N)
→ DP 배열 사용

```
