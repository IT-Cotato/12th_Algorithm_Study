# 📘 Z 탐색 (BOJ 1074) — README

## 📌 문제 설명

`2^N × 2^N` 크기의 배열을 **Z 모양(Z-order)** 으로 방문한다고 할 때,  
특정 위치 `(r, c)`가 **몇 번째로 방문되는지** 출력하는 문제입니다.

Z 모양 탐색은 다음 순서를 따릅니다.

1. 왼쪽 위
2. 오른쪽 위
3. 왼쪽 아래
4. 오른쪽 아래

각 사분면을 다시 같은 방식으로 4등분하여 재귀적으로 방문합니다.

---

## 📚 핵심 개념 정리

### ✔ 1. 분할 정복 (Divide & Conquer)

배열 전체를 4등분하여  
**특정 좌표가 어느 사분면에 속하는지**를 판별하고,  
그 사분면 내부에서 다시 같은 문제를 반복합니다.

---

### ✔ 2. 2차원 Z-Order Indexing

Z 탐색은 공간을 다음처럼 네 덩어리로 나누고 순서대로 탐색합니다:

```
┌─────────┬─────────┐
│   0번   │   1번   │
├─────────┼─────────┤
│   2번   │   3번   │
└─────────┴─────────┘
```

각 블록의 크기:

```
area = (2^(n-1)) × (2^(n-1))
```

---

### ✔ 3. 사분면 판단 기준

```
half = 2^(n-1)
```

| 조건               | 방향            | 사분면  |
| ------------------ | --------------- | ------- |
| r < half, c < half | 위쪽 & 왼쪽     | 1사분면 |
| r < half, c ≥ half | 위쪽 & 오른쪽   | 2사분면 |
| r ≥ half, c < half | 아래쪽 & 왼쪽   | 3사분면 |
| r ≥ half, c ≥ half | 아래쪽 & 오른쪽 | 4사분면 |

---

### ✔ 4. 사분면별 건너뛰는 칸 수

| 사분면 | 추가되는 방문 수 |
| ------ | ---------------- |
| 1      | `0 × area`       |
| 2      | `1 × area`       |
| 3      | `2 × area`       |
| 4      | `3 × area`       |

---

## 🕒 시간 복잡도

```
O(N)
```

---

## ✅ 정답 코드 (JavaScript / Node.js)

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split(" ")
  .map(Number);

const [N, r, c] = input;

function z(n, row, col) {
  if (n === 0) return 0;

  const half = 1 << (n - 1);
  const area = half * half;

  if (row < half && col < half) {
    return z(n - 1, row, col);
  } else if (row < half && col >= half) {
    return area + z(n - 1, row, col - half);
  } else if (row >= half && col < half) {
    return area * 2 + z(n - 1, row - half, col);
  } else {
    return area * 3 + z(n - 1, row - half, col - half);
  }
}

console.log(z(N, r, c));
```

## 🧩 요약

- Z 탐색은 분할 정복 기반 탐색
- (r, c)의 사분면을 판별 후 건너뛸 칸 수 계산
- 좌표를 내부 사분면 기준으로 변환하여 재귀 호출
- 시간복잡도 O(N)
