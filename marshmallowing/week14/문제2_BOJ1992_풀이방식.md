# BOJ 1992

## 문제 요약
- 크기 N×N (N은 2의 제곱)인 흑백 영상이 주어진다.
- 각 칸은 `0`(흰색) 또는 `1`(검은색)이다.
- 영상을 **쿼드트리(Quadtree)** 방식으로 압축하여 문자열로 출력한다.

### 출력 규칙
1. 영역이 모두 같은 값이면 `0` 또는 `1`을 출력한다.
2. 영역에 `0`과 `1`이 섞여 있으면
    - `(` 출력
    - 4분할한 영역을 **왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래** 순서로 처리
    - `)` 출력

---

## 핵심 아이디어 (분할 정복)
이 문제는 **Divide & Conquer(분할 정복)** 문제이다.

- 현재 영역이 **하나의 숫자로만 이루어져 있는지** 확인
- 같다면 더 이상 분할하지 않고 바로 출력
- 다르다면 영역을 4등분하여 같은 과정을 재귀적으로 반복

---

## 입력 처리 방식 (문자열 → 2차원 배열)

입력으로 주어지는 영상 정보는 각 행이 공백 없이 이어진 문자열 형태로 제공된다.
따라서 한 줄을 공백 기준으로 나눌 수 없고,  
문자열을 **한 글자씩 순회하며 숫자로 변환**해야 한다.
```java
for (int i = 0; i < n; i++) {
    String line = br.readLine();
    for (int j = 0; j < n; j++) {
        matrix[i][j] = line.charAt(j) - '0';
    }
}
```
- line.charAt(j)는 '0' 또는 '1' 문자(char)를 반환한다.
- 문자 '0', '1'은 내부적으로 숫자값을 가지므로
  '0'을 빼주면 실제 숫자 0 또는 1로 변환된다.


## 재귀 함수 설계

### `solve(int x, int y, int size)`
- `(x, y)` : 현재 영역의 왼쪽 위 좌표
- `size` : 현재 영역의 한 변 길이

동작:
- `isSameNumber(x, y, size)`가 `true`이면 해당 값을 출력
- `false`이면 괄호로 감싸고 4분할 처리

## 영역 검사 함수

### `isSameNumber(int x, int y, int size)`
- 현재 영역의 모든 값이 `matrix[x][y]`와 같은지 확인
- 하나라도 다르면 `false`
- 전부 같으면 `true`

## 한 줄 요약

> 그 과정을 재귀적으로 문자열로 표현하는 분할 정복 알고리즘이다.
