## BOJ 1463 문제 요약

- 정수 N이 주어진다.
- 다음 연산을 이용해서 N을 1로 만들려고 한다.
    - N이 3으로 나누어떨어지면 3으로 나눈다.
    - N이 2로 나누어떨어지면 2로 나눈다.
    - 1을 뺀다.
- 연산을 사용하는 횟수의 최솟값을 출력하는 문제

---

## 아이디어

- 어떤 수 i를 1로 만드는 최소 연산 횟수를 dp[i]라고 두면,

  i에서 한 번의 연산으로 갈 수 있는 이전 상태들의 dp 값 + 1 중 최솟값이 dp[i]가 된다.

- 가능한 이전 상태
    - i-1
    - i/2 (i가 2로 나누어떨어질 때)
    - i/3 (i가 3으로 나누어떨어질 때)
- 작은 값부터 차례대로 dp를 채우면(dp[1]부터) dp[N]을 구할 수 있다.

---

## 알고리즘 단계

1. N을 입력받는다.
2. 크기 N+1인 배열 result(dp)를 준비한다. (result[i] = i를 1로 만드는 최소 연산 횟수)
3. i를 2부터 N까지 순서대로 result[i]를 채운다.
4. 각 i에 대해 경우를 나눠서 점화식을 적용한다.
    - i % 6 == 0 인 경우 (2와 3으로 모두 나눌 수 있음)
        - result[i] = min(result[i/3], result[i/2]) + 1
    - else if i % 3 == 0 인 경우 (3으로 나누거나 1을 빼는 두 선택지)
        - result[i] = min(result[i/3], result[i-1]) + 1
    - else if i % 2 == 0 인 경우 (2로 나누거나 1을 빼는 두 선택지)
        - result[i] = min(result[i/2], result[i-1]) + 1
    - else (1을 빼는 방법만 가능)
        - result[i] = result[i-1] + 1
5. result[N]을 출력한다.

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int[] result = new int[N+1];
        for (int i = 2; i < result.length; i++) {
            if(i % 6 == 0) {
                result[i] = Math.min(result[i/3], result[i/2]) + 1;
            } else if(i % 3 == 0)
                result[i] = Math.min(result[i/3], result[i-1]) + 1;
            else if(i % 2 == 0)
                result[i] = Math.min(result[i/2], result[i-1]) + 1;
            else
                result[i] = result[i-1] + 1;
        }
        System.out.println(result[N]);
    }
}
```
