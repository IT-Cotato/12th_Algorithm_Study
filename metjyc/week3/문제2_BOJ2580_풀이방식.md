# 스도쿠 완전형 구현 (BOJ 2239)

## 📁 문제 설명

각 행, 열, 그리고 3x3 박스(블록)에 1부터 9까지의 숫자가 한 번씩만 등장해야 하는 스도쿠 퍼즐을 푸는 문제이다. 입력으로 주어지는 9x9 스도쿠 보드에서 숫자 0은 빈 칸을 의미하며, 이 빈 칸들을 스도쿠 규칙에 맞게 모두 채워야 한다.

입력 데이터를 기반으로 먼저 빈 칸 좌표들을 수집하여 목록으로 저장하고, 각 빈 칸에 대해 가능한 숫자를 하나씩 시도하면서 재귀적으로 탐색한다. 이때 사용하는 재귀 함수가 `dfs(index)`이며, index는 현재 몇 번째 빈 칸을 채우는 중인지를 나타낸다.

## ✅ 풀이 절차 요약

1. 9x9 크기의 2차원 배열을 입력으로 받아 보드 상태를 저장한다.
2. 값이 0인 칸의 좌표를 `blanks` 배열에 저장한다.
3. `dfs(index)`를 호출하여 `blanks` 배열의 index번째 좌표를 채우기 시작한다.
4. `isValid(x, y, num)` 함수를 통해 해당 좌표에 숫자 num을 넣을 수 있는지 판단한다.

   - 가로, 세로, 3x3 박스 내에서 중복되는 숫자가 없어야 한다.

5. 유효한 숫자를 넣고 다음 칸으로 넘어가며, 불가능할 경우 백트래킹으로 되돌아간다.

## 👉 isValid(x, y, num)

```js
function isValid(x, y, num) {
  // 가로 중복 검사
  for (let i = 0; i < 9; i++) {
    if (board[x][i] === num) return false;
  }
  // 세로 중복 검사
  for (let i = 0; i < 9; i++) {
    if (board[i][y] === num) return false;
  }
  // 3x3 박스 검사
  const startX = Math.floor(x / 3) * 3;
  const startY = Math.floor(y / 3) * 3;
  for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
      if (board[startX + i][startY + j] === num) return false;
    }
  }
  return true;
}
```

### 📌 설명: `startX`, `startY`의 의미

- (x, y) 좌표가 속한 **3x3 박스(블록)**의 시작 좌표를 구하기 위한 공식이다.
- `Math.floor(x / 3) * 3`은 x가 속한 박스의 첫 행 좌표를 계산하고,
- `Math.floor(y / 3) * 3`은 y가 속한 박스의 첫 열 좌표를 계산한다.
- 이 좌표를 기준으로 가로 3칸, 세로 3칸을 순회하면서 중복 숫자가 있는지 확인한다.

이렇게 하면 (x, y) 좌표가 속한 3x3 박스 내부의 숫자 중복 여부를 정확히 검사할 수 있다.

## 🔄 DFS (Backtracking)

```js
function dfs(index) {
  if (index === blanks.length) {
    board.forEach((row) => console.log(row.join(" ")));
    process.exit();
  }

  const [x, y] = blanks[index];
  for (let num = 1; num <= 9; num++) {
    if (isValid(x, y, num)) {
      board[x][y] = num;
      dfs(index + 1);
      board[x][y] = 0;
    }
  }
}
```

### 구조 설명

| 파라미터          | 설명                                         |
| ----------------- | -------------------------------------------- |
| `index`           | blanks 목록의 현재 채우는 순서를 나타내는 키 |
| `dfs(index + 1)`  | 다음 빈 칸 채우기                            |
| `board[x][y] = 0` | 백트래킹: 숫자를 되돌려 놓기 (원상복구)      |

## 🔄 모든 경우를 완전탐색할 수 있는 이유는?

- 첫 번째 빈 칸부터 `dfs(0)`으로 시작
- `blanks` 배열에 저장된 순서대로 빈 칸을 하나씩 채워 나감
- `index === blanks.length`에 도달하면 모든 빈 칸을 채운 상태 → 출력 후 종료
- 채우는 도중 유효하지 않은 숫자가 나오면 `board[x][y] = 0`으로 되돌리며 다음 수 시도 (백트래킹)
