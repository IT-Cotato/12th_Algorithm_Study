## 스택

### 01. “스택” 이란?

- 상자에 물건을 쌓아 올리듯이 데이터를 쌓는 자료 구조
- 마지막에 저장한 데이터를 가장 먼저 꺼내게 되는 구조 (LIFO)
- 주요 연산: push(삽입), pop(삭제), peek(맨 위 조회), isEmpty, size

### 02. 구현 방법 - Deque

- 자바의 Stack 클래스(Vector 클래스 상속받음)를 사용하여 구현 가능
- Stack 클래스는 대신 Deque를 사용하는 것이 좋음
- Deque : 양방향으로 넣고 꺼낼 수 있는 향상된 큐 → 따라서 상황에 따라 큐처럼 사용하거나 스택처럼 사용 가능
- Stack 처럼 사용할 때

    ```java
    Deque<String> stack = new ArrayDeque<>();
    stack.push("a");
    stack.pop();
    ```

- Queue 처럼 사용할 때

    ```java
    Deque<String> queue = new ArrayDeque<>();
    stack.offer("a"); // 실패 시 false
    stack.add("b"); // 용량 제약이 있으면 예외(IllegalStateException)
    stack.poll();
    ```

## 큐

### 01. “큐” 란?

- 삽입 순으로 나열되어 가장 먼저 삽입한 원소가 가장 먼저 삭제됨(FIFO)
- 용어: enqueue(뒤에 삽입), dequeue(앞에서 삭제), 앞(front), 뒤(rear)
- 큐는 한쪽 끝은 front로 정하여 삭제 연산만 수행
    - 한 쪽 끝은 rear로 정하여 삽입 연산만 수행

### 02. 구현 방법

- 인터페이스: Queue<E>
- 구현체: ArrayDeque, LinkedList(Queue Interface 구현) 등

    ```java
    Queue<Integer> stack = new LinkedList<>();
    queue.add(1); // 1 추가
    queue.offer(3); // 3 추가
    queue.poll(); // 첫번째 값 반환하고 제거, 비어있으면 null
    queue.remove(); // 첫번째 값 제거
    queue.peek(); // 첫번째 값 참조
    queue.clear(); // 초기화
    ```


### 03. 원형 큐

- 선형 큐의 앞에서 꺼낼 때 뒤의 모든 원소를 한 칸씩 당겨야 하는 비효율 해결
- 구현 방법
    - 고정 크기 배열 + 두 포인터(front, rear) + 모듈러 연산으로 구현
    - 삽입: rear = (rear + 1) % capacity
    - 삭제: front = (front + 1) % capacity
- 원소 이동 없음 → 삭제 시 front, 삽입시 rear만 한칸씩 이동함

## 우선순위 큐

### 01. “우선순위 큐” 란?

- 들어온 순서가 아니라 우선순위가 높은 원소가 먼저 나오는 큐
- 자바의 PriorityQueue는 기본이 최소 힙(가장 작은 값이 먼저 나옴)

### 02. 구현 방법

- 일반적으로 힙을 이용하여 구현
    - 우선순위 큐를 위해 고안된 완전이진트리 형태의 자료구조
    - 여러 개의 값 중 최댓값 또는 최솟값을 찾아내는 연산이 빠름
    - 부모노드와 서브트리간 대소관계 성립(반정렬 상태)
    - 중복된 값이 허용됨
    - 힙의 종류 : 최대 힙(부모 노드의 키 값이 자식 노드보다 크거나 같은 완전이진트리), 최소 힙(부모 노드의 키 값이 자식 노드보다 작거나 같은 완전이진트리)

    ```java
    	// 우선순위 낮은 (작은 숫자 우선)
    	PriorityQueue<Integer> minQ = new PriorityQueue<>();
    	// 우선순위 높은 (큰 숫자 우선)
    	PriorityQueue<Integer> maxQ = new PriorityQueue<>(Collections.reverseOrder());
    	
    	minQ.offer(10);        // 삽입, 실패 시 false (용량 제한 큐에서)
    	minQ.add(20);          // 삽입, 실패 시 예외 (용량 제한 큐에서)
    	Integer x = minQ.peek();  // 맨 앞(최솟값) 조회, 비어있으면 null
    	Integer y = minQ.poll();  // 맨 앞 꺼내기, 비어있으면 null
    	boolean e = minQ.isEmpty();
    	int sz = minQ.size();
    	minQ.clear(); // 초기화
    ```


### 03. 사용자 정의 우선순위(Comparator)

- Comparator 리턴값
    - compare(o1, o2) < 0 → o1 < o2 → o1이 앞
    - compare(o1, o2) == 0 → 같음 (순서 유지)
    - compare(o1, o2) > 0 → o1 > o2 → o2가 앞
- PriorityQueue 특징
    - 내부적으로 최소 힙 사용 → 작다고 판정된 원소가 먼저 나옴
    - 오름차순 → (a, b) -> a - b
    - 내림차순 → (a, b) -> b - a

    ```java
    // 절댓값 기준 → 같으면 실제 값이 작은(음수 우선) 순서
    PriorityQueue<Integer> queue = new PriorityQueue<>((o1, o2) -> {
        int a = Math.abs(o1), b = Math.abs(o2);
        if (a == b) return Integer.compare(o1, o2); // 음수 먼저
        return Integer.compare(a, b);               // 절댓값 작은 게 우선
    });
    
    // 도메인 객체 비교
    class StudentComparator implements Comparator<Student> {
        @Override
        public int compare(Student s1, Student s2) {
            if (s1.mathScore == s2.mathScore) {
                return Integer.compare(s2.engScore, s1.engScore); // 영어 점수 내림차순
            }
            return Integer.compare(s1.mathScore, s2.mathScore);   // 수학 점수 오름차순
        }
    }
    
    PriorityQueue<Student> pq = new PriorityQueue<>(new StudentComparator());
    
    // 최대 힙(내림차순)
    PriorityQueue<Integer> maxQ = new PriorityQueue<>(
        (a, b) -> Integer.compare(b, a)   // 큰 값이 우선
    );
    ```
