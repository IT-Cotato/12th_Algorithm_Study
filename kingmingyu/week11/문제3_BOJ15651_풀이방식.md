# 문제
자연수 N, M이 주어졌을 때
- 1부터 N까지 자연수 중에서 M개를 고른 수열
- 같은 수를 여러 번 골라도 된다.

를 만족하는 수열을 모두 출력하는 프로그램을 작성하기

## 자료구조
```java
public static int n;
public static int m;
public static int[] arr;
```
문제 입력값을 받을 n, m 변수와 수열을 만들기 위한 arr 배열

## DFS 이용
```java
public static void dfs(int depth){
    // m개를 모두 고른 경우 sb에 추가
    if(depth == m){
        for(int i = 0; i < m; i++){
            sb.append(arr[i]).append(" ");
        }
        sb.append('\n');
        return ;
    }

    // 재귀 로직 1부터 n까지
    for(int i = 1; i <= n; i++){
        arr[depth] = i; // 현재 자리에 i 저장
        dfs(depth + 1); // 다음 자리 채우러 재귀 호출
    }
}
```
- 깊이가 0부터 m-1까지 자리수를 1개씩 채워가면서 재귀호출
- 깊이가 m이 된 경우 sb에 추가
- StringBuilder를 사용하지 않는 경우 시간초과

## 전체 코드
```java
package kingmingyu.week11;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class 문제3_BOJ15651_풀이 {
    public static int n;
    public static int m;
    public static int[] arr;

    public static StringBuilder sb = new StringBuilder();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        arr = new int[m];

        dfs(0);
        System.out.println(sb);
    }
    public static void dfs(int depth){
        if(depth == m){
            for(int i = 0; i < m; i++){
                sb.append(arr[i]).append(" ");
            }
            sb.append('\n');
            return ;
        }

        for(int i = 1; i <= n; i++){
            arr[depth] = i;
            dfs(depth + 1);
        }
    }
}

```
