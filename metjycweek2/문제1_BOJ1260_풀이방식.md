# 백준 1260번 - DFS와 BFS

## 📌 문제 설명

- 정점의 개수 `N`, 간선의 개수 `M`, 탐색 시작 정점 번호 `V`가 주어진다.
- 이어서 `M`개의 줄에 간선 정보가 주어진다.
- 정점 번호가 작은 것을 우선하여 **DFS**와 **BFS**를 수행한 결과를 출력한다.

---

## 🧩 입력

- 첫 줄: `N M V`
  - `N`: 정점 개수 (1 ≤ N ≤ 1,000)
  - `M`: 간선 개수 (1 ≤ M ≤ 10,000)
  - `V`: 탐색 시작 정점
- 이후 `M`개의 줄: 간선 연결 정보 (양방향)

## 🧩 출력

- 첫 줄: DFS 수행 결과
- 둘째 줄: BFS 수행 결과

---

## 💡 핵심 개념

1. **그래프 표현 (Adjacency List)**

   - 각 정점마다 연결된 노드를 리스트 형태로 저장.
   - `Array.from({ length: N + 1 }, () => [])` 로 생성.

2. **정렬**

   - 문제 조건에 따라 **번호가 작은 정점부터 탐색**해야 하므로  
     각 정점의 인접 리스트를 오름차순 정렬.

3. **DFS (Depth First Search, 깊이 우선 탐색)**

   - 스택/재귀로 구현.
   - 방문하지 않은 노드가 있으면 더 깊이 탐색 후 돌아옴 (**백트래킹** 성격).

4. **BFS (Breadth First Search, 너비 우선 탐색)**

   - 큐(Queue)를 사용.
   - 시작점에서 가까운 노드부터 차례대로 방문.

5. **방문 체크 (visited 배열)**
   - DFS와 BFS 각각 별도의 `visited` 배열 필요.
   - 한 탐색에서 방문 여부가 공유되면 안 되므로 따로 관리.

---

## 🛠 풀이 방식

1. 입력을 받아 그래프를 인접 리스트로 구성한다.
2. 인접 리스트를 정렬하여 항상 작은 정점부터 탐색되도록 한다.
3. **DFS**:
   - 시작 정점을 방문 처리 후 재귀 호출.
   - 방문하지 않은 인접 노드가 있으면 재귀적으로 탐색.
4. **BFS**:
   - 시작 정점을 큐에 넣고, 방문 처리.
   - 큐에서 하나씩 꺼내며 인접한 노드를 큐에 삽입.
