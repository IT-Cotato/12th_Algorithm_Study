# 📌 랜선 자르기 (BOJ 1654)

## 1. 문제 개요

이미 가지고 있는 `K`개의 랜선을 잘라서  
**같은 길이의 랜선 `N`개 이상**을 만들려고 한다.

- 각 랜선의 길이는 제각각
- 자른 후 남는 길이는 버림
- 랜선은 **정수 길이(cm)** 로만 자를 수 있음
- **N개 이상** 만들 수 있으면 성공
- 만들 수 있는 **랜선 길이의 최댓값**을 구하는 문제

---

## 2. 핵심 아이디어

### 🔑 이분 탐색 (Binary Search)

이 문제는 **길이를 기준으로 한 이분 탐색 문제**다.

### 이유

- 랜선 길이가 짧아질수록 → 만들 수 있는 개수는 많아짐
- 랜선 길이가 길어질수록 → 만들 수 있는 개수는 줄어듦

즉, 길이에 대해 다음과 같은 **단조성**이 존재한다.

---

## 3. 탐색 대상과 범위

### 탐색 대상

- 랜선의 길이 (`mid`)

### 탐색 범위

- 최소: `1`
- 최대: 가지고 있는 랜선 중 가장 긴 길이

4. 핵심 로직 설명


Math.floor(lan[i] / mid)

	•	i번째 랜선에서 mid 길이로 만들 수 있는 랜선 개수
	•	소수점 이하는 버림 (정수 길이만 가능)

전체 랜선에서 만들 수 있는 총 개수

for (let i = 0; i < K; i++) {
  count += Math.floor(lan[i] / mid);
}

5. 이분 탐색 판단 기준

if (count >= N) {
  // N개 이상 만들 수 있음 → 길이를 더 늘려본다
  answer = mid;
  left = mid + 1;
} else {
  // N개 못 만듦 → 길이를 줄여야 한다
  right = mid - 1;
}

	•	count >= N
→ 현재 길이 가능 → 더 긴 길이 탐색
	•	count < N
→ 현재 길이 불가능 → 더 짧은 길이 탐색

⸻

6. 시간 복잡도 분석
	•	이분 탐색 횟수: log₂(최대 길이) ≈ 31
	•	각 탐색마다 K개의 랜선 검사

⏱ 시간 복잡도

O(K × log MaxLength)

7. 전체 코드 (Node.js)

const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

const [K, N] = input[0].split(" ").map(Number);
const lan = input.slice(1).map(Number);

let left = 1;
let right = Math.max(...lan);
let answer = 0;

while (left <= right) {
  const mid = Math.floor((left + right) / 2);

  let count = 0;
  for (let i = 0; i < K; i++) {
    count += Math.floor(lan[i] / mid);
  }

  if (count >= N) {
    answer = mid;
    left = mid + 1;
  } else {
    right = mid - 1;
  }
}

console.log(answer);
