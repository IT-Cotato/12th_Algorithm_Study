# BOJ 14497 - 주난의 난

## 문제 요약
교실 지도에서
- `0` : 빈 공간 (그냥 이동 가능)
- `1` : 친구들이 서 있음 (한 번의 점프로 부수고 지나갈 수 있음)
- `*` : 주난
- `#` : 목표

주난이가 `#`에 도달하기 위한 **최소 점프 횟수**를 출력한다.

## 핵심 해석
이 문제에서 점프는 사실상
- 빈 칸(0)은 비용 0
- 친구(1)는 비용 1
  처럼 **이동 비용이 0 또는 1**인 최단거리 문제로 바꿀 수 있다.

## 왜 BFS인가?
간선 가중치가 0 또는 1뿐이라서
- 다익스트라(PQ)도 가능하지만,
- 0-1 BFS(Deque)를 쓰면 더 단순하고 빠르다.

BFS 규칙:
- 가중치 0 이동이면 덱의 앞(addFirst)
- 가중치 1 이동이면 덱의 뒤(addLast)

이렇게 하면 덱에서 꺼낼 때 항상 현재까지 비용이 작은 상태부터 처리되는 효과가 생긴다.

## 알고리즘
1) dist 배열을 INF로 초기화
2) 시작점 dist=0, 덱에 삽입
3) 덱에서 pop:
    - 네 방향 확인
    - 이동 비용 w(0 또는 1) 계산
    - dist 갱신되면
        - w==0: addFirst
        - w==1: addLast
4) 목표 지점의 dist 출력

## 시간/공간 복잡도
- 각 칸은 dist가 개선될 때만 덱에 들어가며, 0-1 BFS는 사실상 O(V+E)
- V = N*M, E ≈ 4*N*M
- 시간: O(N*M)
- 공간: O(N*M)
