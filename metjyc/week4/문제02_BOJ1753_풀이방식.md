# 🚀 단일 시작점 최단 경로 (BOJ 1753)

## 📘 문제 개요

하나의 시작 정점에서 모든 다른 정점으로 가는 **최단 거리**를 구하는 문제입니다.  
간선은 방향성이 있으며, 각 간선에는 **양의 가중치**(비용)가 주어집니다.  
도달할 수 없는 정점은 `INF`로 표시해야 합니다.

---

## 🧠 핵심 개념

### 1️⃣ 다익스트라 알고리즘 (Dijkstra’s Algorithm)

- **단일 시작점 최단 경로**를 구하는 대표적인 알고리즘입니다.
- 가중치가 **음수가 아닌 그래프**에서 사용됩니다.
- 매 단계마다 “현재까지 가장 짧은 거리의 정점”을 선택하고,  
  인접한 노드들의 거리를 **완화(relaxation)** 하며 최소값을 갱신합니다.
- 효율적인 구현을 위해 **최소 힙(Min-Heap)** 자료구조를 사용합니다.

**점화식:**
\[
dist[v] = \min(dist[v],\ dist[u] + w)
\]

- `u → v` 간선의 가중치가 `w`일 때,  
  `u`를 거쳐서 `v`로 가는 비용이 더 작다면 갱신합니다.

---

### 2️⃣ 최소 힙(Min-Heap)

- 가장 작은 값을 빠르게 꺼내기 위한 **우선순위 큐**입니다.
- 다익스트라에서 “현재 거리 값이 가장 짧은 정점”을 찾는 데 사용됩니다.
- 삽입(push), 삭제(pop) 모두 `O(log N)`의 시간 복잡도를 가집니다.

---

### 3️⃣ INF (무한대) 정의

- 아직 도달하지 못한 정점을 구분하기 위해 매우 큰 수(`1e18`)를 사용합니다.
- 최종 출력 시 `INF`로 표시합니다.

---

## 🧩 알고리즘 단계 요약

| 단계                   | 설명                                                |
| ---------------------- | --------------------------------------------------- |
| **1. 입력 처리**       | 정점 수(V), 간선 수(E), 시작점(K) 입력              |
| **2. 그래프 구성**     | 인접 리스트 형태로 저장 (`graph[u] = [{to: v, w}]`) |
| **3. 초기화**          | `dist` 배열을 `INF`로 채우고 `dist[K] = 0`          |
| **4. 최소 힙 생성**    | `(0, K)`를 힙에 삽입                                |
| **5. 다익스트라 수행** | 힙에서 최단 거리 정점을 꺼내 인접 노드 거리 갱신    |
| **6. 결과 출력**       | 도달 불가 시 `INF`, 가능 시 거리 출력               |

---

## 💻 구현 코드 (JavaScript)

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const [V, E] = input[0].split(" ").map(Number);
const K = Number(input[1]);

// 인접 리스트
const graph = Array.from({ length: V + 1 }, () => []);
for (let i = 2; i < 2 + E; i++) {
  const [u, v, w] = input[i].split(" ").map(Number);
  graph[u].push({ to: v, w });
}

// 거리 배열 초기화
const INF = 1e18;
const dist = Array(V + 1).fill(INF);
dist[K] = 0;

// 최소 힙 구현
class MinHeap {
  constructor() {
    this.h = [];
  }
  size() {
    return this.h.length;
  }
  _swap(a, b) {
    [this.h[a], this.h[b]] = [this.h[b], this.h[a]];
  }

  push(val) {
    this.h.push(val);
    let i = this.h.length - 1;
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (this.h[p][0] <= this.h[i][0]) break;
      this._swap(p, i);
      i = p;
    }
  }

  pop() {
    const n = this.h.length;
    if (n === 0) return null;
    if (n === 1) return this.h.pop();

    this._swap(0, n - 1);
    const out = this.h.pop();

    let i = 0;
    while (true) {
      const l = i * 2 + 1;
      const r = i * 2 + 2;
      let m = i;
      if (l < this.h.length && this.h[l][0] < this.h[m][0]) m = l;
      if (r < this.h.length && this.h[r][0] < this.h[m][0]) m = r;
      if (m === i) break;
      this._swap(i, m);
      i = m;
    }
    return out;
  }
}

// 다익스트라 알고리즘
const pq = new MinHeap();
pq.push([0, K]);

while (pq.size()) {
  const cur = pq.pop();
  if (!cur) break;
  const [d, u] = cur;
  if (d !== dist[u]) continue;

  for (const { to: v, w } of graph[u]) {
    const nd = d + w;
    if (nd < dist[v]) {
      dist[v] = nd;
      pq.push([nd, v]);
    }
  }
}

// 결과 출력
let out = "";
for (let i = 1; i <= V; i++) {
  out += (dist[i] === INF ? "INF" : String(dist[i])) + "\n";
}
console.log(out.trim());
```

---

## 📈 시간 복잡도

- **힙 기반 다익스트라:** `O(E log V)`
- 정점 20,000개, 간선 300,000개까지 충분히 처리 가능

---

## 📚 주요 포인트 요약

- **음수 가중치가 없을 때만** 다익스트라 사용 가능
- **중복 간선**은 더 작은 가중치의 간선만 결과에 반영됨
- **최소 힙**을 사용하면 시간 복잡도를 `O(E log V)`로 줄일 수 있음
- **도달 불가한 노드**는 반드시 `"INF"`로 출력해야 함
