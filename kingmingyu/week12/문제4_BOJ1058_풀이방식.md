# 문제
친구가 가장 많은 사람의 친구 수 출력하기(직접 아는 사이 + 건너 아는 사이)

## 친구 수 추가
```java
for(int i = 0; i < n; i++){
    int count = 0;
    for(int j = 0; j < n; j++){
        // 자기 자신인 경우
        if(i == j) continue;
        boolean isFriend = false;

        if(isFriendArr[i][j] == 1){
            isFriend = true;
        }
        for(int k = 0; k < n; k++){
            if(isFriendArr[i][k] + isFriendArr[k][j] == 2){
                isFriend = true;
                break;
            }
        }
        if (isFriend) count++;
    }
    max = Math.max(max, count);
}
```
1. 직접 친구인 경우(1)
2. 건너서 아는 경우(합이 2)
- 중복 저장하지 않기 위해 isFriend 변수로 한번만 추가

## 전체 코드
```java
package kingmingyu.week12;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class 문제4_BOJ1058_풀이 {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        int isFriendArr[][] = new int[n][n];
        for(int i = 0; i < n; i++){
            String str = br.readLine();
            for(int j = 0; j < n; j++){
                if(i == j) isFriendArr[i][j] = 0;

                if(str.charAt(j) == 'N') isFriendArr[i][j] = 999;
                else isFriendArr[i][j] = 1;
            }
        }

        int max = 0;


        for(int i = 0; i < n; i++){
            int count = 0;
            for(int j = 0; j < n; j++){
                // 자기 자신인 경우
                if(i == j) continue;
                boolean isFriend = false;

                if(isFriendArr[i][j] == 1){
                    isFriend = true;
                }
                for(int k = 0; k < n; k++){
                    if(isFriendArr[i][k] + isFriendArr[k][j] == 2){
                        isFriend = true;
                        break;
                    }
                }
                if (isFriend) count++;
            }
            max = Math.max(max, count);
        }
        System.out.println(max);
    }
}

```
