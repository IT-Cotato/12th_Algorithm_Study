## BOJ 14235 문제 요약

- 아이들에게 줄 선물을 관리하는 문제
- 총 n번의 입력이 주어짐
    - 입력이 0이면 저장된 선물 중 가장 큰 값을 꺼내서 출력
    - 입력이 x a1 a2 ... ax 형태이면 선물 x개를 저장
- 꺼낼 선물이 없는데 0이 들어오면 -1 출력

---

## 아이디어

- 우선순위 큐 사용
- 가장 큰 값을 빠르게 꺼내야 하므로 최대 힙이 필요함
- 자바 PriorityQueue는 기본이 최소 힙이라 비교자를 사용해 내림차순으로 구성
- 입력 처리
    - count가 0이면
        - 비어있으면 -1 출력
        - 아니면 pq에서 poll 해서 출력
    - count가 0이 아니면
        - count만큼 선물을 pq에 넣기
- 항상 가장 큰 선물이 루트에 위치하므로 poll이 곧 최댓값 출력

---

## 알고리즘 단계

1. 입력으로 n을 읽는다
2. 최대 힙 역할을 하는 PriorityQueue를 만든다
3. i를 0부터 n-1까지 반복하며 한 줄씩 입력을 처리한다
4. 입력의 첫 값 count를 확인한다
    - count가 0인 경우
        - pq가 비어 있으면 -1 출력
        - pq가 비어 있지 않으면 pq.poll 값을 출력
    - count가 0이 아닌 경우
        - 뒤에 따라오는 count개의 값을 pq에 모두 추가한다
5. 반복이 끝날 때까지 위 과정을 수행한다

---

## 코드

```java
import java.io.*;
import java.util.PriorityQueue;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        int n = Integer.parseInt(br.readLine());
        PriorityQueue<Integer> pq = new PriorityQueue<>((o1,o2)->o2-o1);
        for (int i = 0; i < n; i++) {
            String[] s = br.readLine().split(" ");
            int count = Integer.parseInt(s[0]);
            if(count == 0) {
                if(pq.isEmpty())
                    bw.write("-1\n");
                else
                    bw.write(pq.poll()+"\n");
                continue;
            }
            for (int j = 1; j <= count; j++) {
                pq.add(Integer.parseInt(s[j]));
            }
        }
        bw.flush();
        bw.close();
    }
}
```
