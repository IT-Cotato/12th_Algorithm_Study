## BOJ 12865 문제 요약

- N개의 물건이 있고 각 물건은 무게 W, 가치 V를 가짐
- 최대 무게 K를 넘지 않게 물건을 골라 담을 때 얻을 수 있는 가치의 최댓값을 구하는 문제
- 각 물건은 1번만 선택 가능

---

## 아이디어

- DP
- dp[i][j]를 i번째 물건까지 고려했을 때, 배낭 용량이 j일 때 얻을 수 있는 최대 가치라고 둠
- 각 물건 i에 대해 선택지가 2가지로 나뉨
    1. 물건 i를 담지 않는 경우
        - 가치 변화 없음
        - dp[i][j] = dp[i-1][j]
    2. 물건 i를 담는 경우
        - 현재 용량 j에서 물건 무게 W를 뺀 용량 j-W에서의 최적값에 V를 더함
        - dp[i][j] = dp[i-1][j-W] + V
        - 단, j < W이면 담을 수 없어서 이 경우는 불가능
- 따라서 점화식
    - j < W 이면 dp[i][j] = dp[i-1][j]
    - j >= W 이면 dp[i][j] = max(dp[i-1][j], dp[i-1][j-W] + V)
- dp에서 i-1을 참조하는 이유
    - 같은 물건을 중복 선택하지 않기 위해 이전 행의 값만 사용

---

## 알고리즘 단계

1. 입력으로 N, K를 읽는다
2. dp 배열을 (N+1)×(K+1) 크기로 만든다
    - dp[i][j]는 i번째 물건까지 고려, 용량 j일 때 최대 가치
3. items 배열에 각 물건의 무게와 가치를 저장한다
4. i를 1부터 N까지 반복하면서
    - j를 1부터 K까지 반복
    - 만약 j < items[i][0] 이면
        - 현재 물건은 담을 수 없으므로 dp[i][j] = dp[i-1][j]
    - 아니면
        - 담지 않는 경우와 담는 경우 중 최대값을 선택
        - dp[i][j] = max(dp[i-1][j], dp[i-1][j-items[i][0]] + items[i][1])
- dp[N][K]를 출력한다

---

## 코드

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int K = Integer.parseInt(s[1]);
        int[][] dp = new int[N+1][K+1];
        int[][] items = new int[N+1][2];
        for (int i = 1; i < items.length; i++) {
            s = br.readLine().split(" ");
            items[i][0] = Integer.parseInt(s[0]);
            items[i][1] = Integer.parseInt(s[1]);
        }
        for (int i = 1; i < items.length; i++) {
            for (int j = 1; j <= K; j++) {
                if(j < items[i][0])
                    dp[i][j] = dp[i-1][j];
                else
                    dp[i][j] = Math.max(dp[i-1][j], dp[i-1][j-items[i][0]] + items[i][1]);
            }
        }
        bw.write(dp[N][K]+"\n");
        bw.flush();
        bw.close();
    }
}
```
