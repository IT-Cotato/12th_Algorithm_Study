## BOJ 1932 문제 요약

- 크기 n의 정수 삼각형이 주어진다.
- 맨 위에서 시작해서 아래로 내려가며 숫자를 더한다.
- 내려갈 때는 바로 아래 칸 또는 아래 오른쪽 칸으로만 이동할 수 있다.
- 이렇게 내려가면서 만들 수 있는 경로들 중 합이 최대가 되는 값을 출력하는 문제

---

## 아이디어

- dp[i][j]를 i번째 줄 j번째 칸까지 내려왔을 때 얻을 수 있는 최대 합으로 정의한다.
- (i, j)에 올 수 있는 경우는 딱 두 가지뿐이다.
    - (i-1, j-1)에서 내려오는 경우
    - (i-1, j)에서 내려오는 경우
- 따라서 점화식은

  dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + arr[i][j]

- dp를 위에서부터 채우고, 마지막 줄 dp[n][1..n] 중 최댓값이 정답이다.

---

## 알고리즘 단계

1. n을 입력받는다.
2. 삼각형 값을 arr[n+1][n+1]에 입력받는다. (1-based)
3. dp[n+1][n+1] 배열을 준비한다.
4. dp[1][1] = arr[1][1]로 시작값을 넣는다.
5. i를 1부터 n까지 순회하면서 j를 1부터 i까지 순회한다.
    - dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + arr[i][j] 로 갱신한다.
6. 마지막 줄 dp[n][1..n] 중 최댓값을 result로 구해 출력한다.

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int[][] arr = new int[n+1][n+1];
        for (int i = 1; i < n+1; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 1; j < i+1; j++) {
                arr[i][j] = Integer.parseInt(st.nextToken());
            }
        }
        int[][] dp = new int[n+1][n+1];
        dp[1][1] = arr[1][1];
        int result = 0;
        for (int i = 1; i < n+1; i++) {
            for (int j = 1; j < i+1; j++) {
                dp[i][j] = Math.max(dp[i-1][j-1], dp[i-1][j]) + arr[i][j];
            }
        }
        for (int i = 1; i < n+1; i++) {
            result = Math.max(result, dp[n][i]);
        }
        System.out.println(result);
    }
}
```
