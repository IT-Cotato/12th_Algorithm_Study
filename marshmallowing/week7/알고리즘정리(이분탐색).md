# 이분 탐색(Binary Search)

## 1. 개념
이분 탐색(Binary Search)은 **정렬된 배열**에서 원하는 값을
탐색 범위를 절반씩 줄이며 찾는 알고리즘이다.

- 전제 조건: 반드시 **정렬된 배열**이어야 한다.
- 시간 복잡도: **O(log N)**

---

## 2. 동작 과정

1. `low` = 0
2. `high` = 배열 길이 - 1
3. 다음을 반복:
    - `mid = (low + high) / 2`
    - `arr[mid] == target` → 값 찾음
    - `arr[mid] < target` → 오른쪽 반만 탐색 (`low = mid + 1`)
    - `arr[mid] > target` → 왼쪽 반만 탐색 (`high = mid - 1`)
4. `low > high`가 되면 탐색 실패

---

## 3. Java 코드 예시

```java
public static int binarySearch(int[] arr, int target) {
int low = 0;
int high = arr.length - 1;

while (low <= high) {
    int mid = low + (high - low) / 2; 

    if (arr[mid] == target) {
        return mid;
    } else if (arr[mid] < target) {
        low = mid + 1;
    } else {
        high = mid - 1;
    }
}
return -1;
```
