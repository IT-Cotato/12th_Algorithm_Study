# BOJ 1260 - DFS와 BFS

## 문제

- 그래프가 주어졌을 때 DFS와 BFS 결과를 출력.
- 정점 번호가 작은 것을 먼저 방문.

---

## 풀이 아이디어

- 그래프: 인접 리스트(ArrayList) 사용 후 정렬.
- DFS: 재귀 호출로 방문.
- BFS: 큐(Queue) 이용.
- 방문 여부는 `visited[]` 배열로 관리.

---

## 핵심 코드

```java
// DFS
void dfs(int node) {
    visited[node] = true;
    bw.write(node + " ");
    for (int next : graph[node]) {
        if (!visited[next]) dfs(next);
    }
}

// BFS
void bfs(int start) {
    Queue<Integer> q = new LinkedList<>();
    visited[start] = true;
    q.add(start);

    while (!q.isEmpty()) {
        int node = q.poll();
        bw.write(node + " ");
        for (int next : graph[node]) {
            if (!visited[next]) {
                visited[next] = true;
                q.add(next);
            }
        }
    }
}
