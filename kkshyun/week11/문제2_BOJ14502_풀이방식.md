## BOJ 14502 문제 요약

- N×M 연구소가 주어지고 각 칸은 다음 중 하나
    - 0 빈 칸
    - 1 벽
    - 2 바이러스
- 빈 칸 중 3개를 골라 벽을 세운 뒤 바이러스를 퍼뜨렸을 때
- 최종적으로 남는 안전 영역(0)의 최대 크기를 구하는 문제

---

## 아이디어

- 벽 3개를 세우는 모든 경우를 백트래킹 DFS로 탐색
- 벽을 3개 세운 상태마다 BFS로 바이러스 확산을 시뮬레이션
- 확산 후 남아있는 0의 개수를 세어서 max 갱신
- 원본 graph를 직접 바꾸면 복구가 복잡하므로
    - 벽 세우기는 graph에 직접 표시하고 DFS가 끝나면 원상복구
    - 바이러스 확산은 clone 배열에 복사해서 수행

---

## 알고리즘 단계

1. 입력으로 N, M을 읽고 연구소 상태를 graph에 저장한다
2. dfs(depth, start)를 호출해서 벽 3개를 세우는 조합을 탐색한다
3. dfs 동작
    - depth가 3이면 벽을 다 세운 상태이므로 cal을 호출하고 종료한다
    - start부터 N*M-1까지 1차원 인덱스로 순회하며
        - (r, c)로 변환 후 graph[r][c]가 0이면 벽을 세울 수 있음
        - graph[r][c]를 1로 바꾸고 dfs(depth+1, i+1) 호출
        - 재귀가 끝나면 graph[r][c]를 다시 0으로 되돌려 원상복구
4. cal 동작
    - graph를 clone 배열로 복사한다
    - 연구소 전체를 순회하며 바이러스(2)를 발견하면 bfs를 실행한다
    - 모든 바이러스 확산이 끝나면 clone에서 값이 0인 칸 개수를 temp로 센다
    - max를 max와 temp 중 큰 값으로 갱신한다
5. bfs(row, col, clone) 동작
    - 큐를 이용해 바이러스 확산을 수행한다
    - 상하좌우 4방향으로 퍼뜨리며 벽(1)이 아닌 곳으로 진행한다
    - 퍼지는 칸은 clone에서 2로 바꾼다
6. 모든 경우를 다 돌면 max를 출력한다

---

## 코드

```java
import java.io.*;
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Queue;

public class Main {
    static int max = 0;
    static int[] drow = {-1,1,0,0};
    static int[] dcol = {0,0,-1,1};
    static int[][] graph;
    static int N;
    static int M;
    static boolean[][] visited;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        N = Integer.parseInt(s[0]);
        M = Integer.parseInt(s[1]);
        graph = new int[N][M];
        visited = new boolean[N][M];
        for (int i = 0; i < N; i++) {
            s = br.readLine().split(" ");
            for (int j = 0; j < M; j++) {
                graph[i][j] = Integer.parseInt(s[j]);
            }
        }

        // 1을 백트래킹으로 3개 세우고, bfs로 넓이 찾기
        dfs(0,0);
        bw.write(max+"\n");
        bw.flush();
        bw.close();

    }
    public static void dfs(int depth, int start) {
        if(depth == 3) {
            cal();
            return;
        }
        for (int i = start; i < N * M; i++) {
            int r = i / M; // 행 계산
            int c = i % M; // 열 계산

            if (graph[r][c] == 0) {
                graph[r][c] = 1;       // 선택
                dfs(depth + 1, i + 1); // 다음 depth에서는 현재 인덱스 + 1부터 탐색
                graph[r][c] = 0;       // 백트래킹 (원상복구)
            }
        }
    }

    public static void cal() {
        int temp = 0;
        int[][] clone = new int[graph.length][];
        for (int i = 0; i < graph.length; i++) {
            clone[i] = graph[i].clone();
        }

        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if(graph[i][j] == 2) {
                    bfs(i,j,clone);
                }
            }
        }
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if(clone[i][j] == 0) {
                    temp += 1;
                }
            }
        }
        max = Math.max(temp, max);
    }

    public static void bfs(int row, int col, int[][] clone) {
        Queue<int[]> queue = new ArrayDeque<>();
        queue.add(new int[]{row, col});
        for (int i = 0; i < N; i++) {
            Arrays.fill(visited[i],false);
        }
        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            for (int i = 0; i < 4; i++) {
                int x = curr[0] + drow[i];
                int y = curr[1] + dcol[i];
                if(x >= 0 && y >= 0 && x < graph.length && y < graph[0].length && clone[x][y]!=1) {
                    clone[x][y] = 2;
                    if(visited[x][y])
                        continue;
                    visited[x][y] = true;
                    queue.add(new int[]{x, y});
                }
            }
        }
    }
}
```
