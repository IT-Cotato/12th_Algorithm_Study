# 부분수열의 합 (BOJ 1182)

## 📁 문제 설명

하나의 수열이 주어졌을 때, 그 수열의 **양수 크기를 가진 부분수열** 중 원소의 합이 **정수 S**가 되는 경우의 수를 구하는 문제다.

- 입력:

  - 첫 줄: 두 정수 `N`과 `S` (수열의 길이와 목표 합)
  - 둘째 줄: 수열을 이루는 N개의 정수 (음수, 양수, 0 포함)

- 출력:

  - 조건을 만족하는 부분수열의 개수

### 입력 예시

```
5 0
-7 -3 -2 5 8
```

### 출력 예시

```
1
```

---

## 📉 문제 조건 정보 및 기능 요약

| 항목           | 설명                                                           |
| -------------- | -------------------------------------------------------------- |
| 부분수열       | 원소 일부를 순서를 유지하며 선택한 조합                        |
| 양수 크기 제한 | 원소를 하나도 선택하지 않은 경우(빈 부분수열)는 제외           |
| 선택 방식      | 각 원소마다 "선택 or 비선택"의 분기 구조를 따라 DFS 탐색 수행  |
| 부분합 계산    | 선택된 원소들의 합을 `currentSum`에 누적                       |
| 조건 만족 여부 | `currentSum === S`이고 `pickedCount > 0`인 경우에만 count 증가 |

---

## ✨ 문제 해결 전략

- `dfs(index, currentSum, pickedCount)` 형태의 백트래킹(DFS) 함수 사용
- 수열을 앞에서부터 하나씩 보면서:

  - **선택하거나** → currentSum에 값 더하고 pickedCount 증가
  - **선택하지 않거나** → currentSum 변화 없이 다음 index로

- 종료조건 (`index === N`)에서 조건이 맞는지 검사 후 count 증가
- pickedCount > 0 조건은 **빈 부분수열을 제외**하기 위해 반드시 필요

---

## ⚡ DFS 재귀 함수 구조

```js
function dfs(index, currentSum, pickedCount) {
  if (index === N) {
    if (currentSum === S && pickedCount > 0) {
      count += 1;
    }
    return;
  }

  // 현재 원소를 선택하는 경우
  dfs(index + 1, currentSum + numbers[index], pickedCount + 1);

  // 현재 원소를 선택하지 않는 경우
  dfs(index + 1, currentSum, pickedCount);
}
```

### 매개변수 설명

| 매개변수      | 의미                                                               |
| ------------- | ------------------------------------------------------------------ |
| `index`       | 현재 탐색 중인 수열의 인덱스                                       |
| `currentSum`  | 지금까지 선택한 숫자들의 합                                        |
| `pickedCount` | 선택한 숫자의 개수 (0이면 빈 부분수열이므로 카운트 제외 조건 필요) |

---

## 🌳 DFS 호출 흐름 예시 (numbers = [1, 2])

```
dfs(0, 0, 0)
├─ dfs(1, 1, 1)  // 1 선택
│   ├─ dfs(2, 3, 2)  // 2 선택
│   └─ dfs(2, 1, 1)  // 2 비선택
└─ dfs(1, 0, 0)  // 1 비선택
    ├─ dfs(2, 2, 1)  // 2 선택
    └─ dfs(2, 0, 0)  // 빈 부분수열 → 제외 대상
```

---

## ✅ 정리 요약

- `2^N`개의 부분수열 조합 중에서 합이 `S`가 되는 조합만 카운트
- 각 원소는 "선택 or 미선택" 2가지 경우로 분기됨
- 빈 부분수열은 제외해야 하므로 `pickedCount > 0` 조건 필수
- `N ≤ 20`이므로 완전탐색으로 충분히 해결 가능

---

## 💡 팁

- count를 전역 변수로 관리하면 DFS 내에서 편리하게 누적 가능
- `dfs(0, 0, 0)` 으로 탐색 시작
- 필요하면 `input.txt` 또는 `/dev/stdin` 을 통해 로컬·온라인 모두 테스트 가능
