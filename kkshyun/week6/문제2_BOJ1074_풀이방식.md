## BOJ 1074 문제 요약

- 크기 2^N × 2^N 배열을 Z-모양 순서로 방문한다고 할 때,
- 좌표 (r, c)가 몇 번째로 방문되는지(0-기준) 출력하는 문제

---

## 아이디어

- (실패 접근) 처음에는 N=1일때까지 다 쪼갠 다음, 전부 방문하면서 배열에 저장하고 해당 위치이면 배열값을 반환하고 종료하려고 했으나 메모리 초과 및 시간 초과 문제가 생김
- 분할 정복(재귀)

  한 변 길이가 2^N인 정사각형을 4개 사분면(좌상/우상/좌하/우하)으로 쪼개며,

  (r, c)가 속한 사분면을 찾아 그 사분면 이전까지의 방문 개수를 count에 더하고, 해당 사분면으로 재귀

- 각 단계에서 사분면의 한 변은 pow = 2^(N-1)이고, 사분면 방문 순서와 오프셋은:
    1. 좌상: +0 * pow*pow
    2. 우상: +1 * pow*pow
    3. 좌하: +2 * pow*pow
    4. 우하: +3 * pow*pow
- 기저: N=1이면 2×2 칸을 실제 순회하며 count를 증가시키다가 (r,c)에서 출력하고 종료

---

## 알고리즘 단계

1. 입력(N, r, c)을 읽고 route(0, 0, N) 호출
2. route(startR, startC, NSize):
    - NSize == 1이면 startR..startR+1, startC..startC+1을 Z 순서로 훑으면서 count++; (r,c)면 출력하고 리턴
    - NSize > 1이면 pow = 2^(NSize-1) 계산
        - (r,c)가 좌상에 있으면 오프셋 없이 route(startR, startC, NSize-1)
        - 우상이면 count += pow*pow 후 route(startR, startC+pow, NSize-1)
        - 좌하이면 count += 2*pow*pow 후 route(startR+pow, startC, NSize-1)
        - 우하이면 count += 3*pow*pow 후 route(startR+pow, startC+pow, NSize-1)
3. 재귀가 (r,c)에 도달하면 누적 count를 출력하고 종료

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    static int count = -1;
    static int r;
    static int c;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        r = Integer.parseInt(s[1]);
        c = Integer.parseInt(s[2]);
        // 재귀적으로 계산
        route(0,0, N);
    }

    public static void route(int startR, int startC, int NSize) {
        if(NSize == 1) {
            for (int i = startR; i < startR+2; i++) {
                for (int j = startC; j < startC+2; j++) {
                    count++;
                    if(i == r && j == c) {
                        System.out.println(count);
                        return;
                    }
                }
            }
        }
        else if(NSize > 1) {
            int pow = (int)Math.pow(2, NSize - 1);
            if(r >= startR && r < startR + pow) {
                if(c >= startC && c < startC + pow)
                    route(startR, startC, NSize-1);
                else {
                    count += pow*pow;
                    route(startR, startC + pow, NSize-1);
                }
            } else {
                if(c >= startC && c < startC + pow) {
                    count += pow*pow*2;
                    route(startR + pow, startC, NSize-1);
                }
                else {
                    count += pow*pow*3;
                    route(startR + pow, startC + pow, NSize-1);
                }
            }
        }
    }
}
```
