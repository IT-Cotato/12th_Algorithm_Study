# 📈 가장 긴 증가하는 부분 수열 (LIS)

## 1. 문제 개요

수열 A가 주어졌을 때, **가장 긴 증가하는 부분 수열(Longest Increasing Subsequence, LIS)**의 길이를 구하는 문제이다.

- **부분 수열**이란?
  - 원래 수열에서 **일부 원소를 골라 순서를 유지**한 수열
  - 연속일 필요는 없다

### 예시

A = [10, 20, 10, 30, 20, 50]

가능한 증가 부분 수열 중 하나:

[10, 20, 30, 50]

➡ 길이 = **4**

---

## 2. 왜 단순한 그리디 풀이가 실패하는가?

단순히 앞에서부터 보면서:

- 이전 값보다 크면 선택

이 방식은 **현재 선택이 미래의 최적 선택을 보장하지 않는다.**

### 반례

[5, 1, 2, 3, 4]

- 그리디: `5`만 선택 → 길이 1 ❌
- 정답 LIS: `[1, 2, 3, 4]` → 길이 4 ✅

👉 따라서 **모든 경우를 고려하는 DP 접근**이 필요하다.

---

## 3. DP 접근 방식

### 핵심 아이디어

> `dp[i]` = **i번째 원소로 끝나는** 가장 긴 증가 부분 수열의 길이

---

### 3.1 초기값

모든 원소는 혼자만으로 길이 1인 증가 수열을 만들 수 있다.

```js
dp[i] = 1


⸻

3.2 점화식

현재 위치 i에 대해,
이전의 모든 위치 j (0 ≤ j < i)를 확인한다.

조건:
	•	arr[j] < arr[i]
→ 증가 수열 조건 만족

갱신:

dp[i] = max(dp[i], dp[j] + 1)

의미:
	•	j에서 끝난 증가 수열 뒤에 i를 붙일 수 있다면
	•	그중 가장 긴 경우만 선택

⸻

3.3 왜 이중 for문인가?
	•	LIS는 연속이 아니어도 되므로
	•	i 앞에 올 수 있는 모든 j를 확인해야 한다

for (i = 0..N-1)
  for (j = 0..i-1)


⸻

4. 알고리즘 흐름 요약
	1.	dp 배열을 모두 1로 초기화
	2.	각 i에 대해:
	•	이전 j들을 순회
	•	증가 조건을 만족하면 dp 갱신
	3.	dp 배열의 최대값이 정답

⸻

5. 예제 흐름 (dp 변화)

입력:

10 20 10 30 20 50

dp 변화:

[1, 2, 1, 3, 2, 4]

최대값 = 4

⸻

6. 최종 코드 (JavaScript)

const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const N = Number(input[0]);
const arr = input[1].split(" ").map(Number);

const dp = Array(N).fill(1);

for (let i = 0; i < N; i++) {
  for (let j = 0; j < i; j++) {
    if (arr[j] < arr[i]) {
      dp[i] = Math.max(dp[i], dp[j] + 1);
    }
  }
}

console.log(Math.max(...dp));


⸻

7. 시간 / 공간 복잡도
	•	시간 복잡도: O(N²)
	•	공간 복잡도: O(N)

※ N ≤ 1000이므로 충분히 통과 가능

⸻

8. 핵심 정리
	•	LIS는 그리디로 해결 불가
	•	“현재 선택”이 아닌 “모든 가능성”을 비교해야 함
	•	dp[i]는 반드시 arr[i]로 끝나는 경우만 의미함
	•	이중 for문 + 조건문은 의미적으로 필수
```
