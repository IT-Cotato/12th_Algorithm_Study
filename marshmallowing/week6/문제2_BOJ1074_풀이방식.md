# BOJ 1074 — Z 

## 문제 개요

크기가 2^N × 2^N인 배열을 Z 모양 순서로 탐색할 때,  
특정 좌표 (r, c)가 **몇 번째로 방문되는지**를 구하는 문제

## 접근 방법 (분할 정복)

> 핵심 아이디어: 현재 배열을 4개의 사분면으로 나누고,  
> 목표 좌표 (r, c)가 어느 사분면에 속하는지 찾아 재귀적으로 좁혀간다.

### 알고리즘 단계

1. **기본 구조**
- 현재 정사각형의 크기를 `n`이라고 할 때, 네 사분면의 크기는 `(n/2) × (n/2)` 이다.

2. (r, c)가 어느 사분면에 속하는지 조건문으로 판단한다:
- **0번 사분면:** `r < n/2 && c < n/2`
- **1번 사분면:** `r < n/2 && c >= n/2`
- **2번 사분면:** `r >= n/2 && c < n/2`
- **3번 사분면:** `r >= n/2 && c >= n/2`

3. 각 사분면의 시작 인덱스는 다음과 같다.

   | 사분면 | 더해줘야 하는 개수 |
   |---|-------------------|
   | 0 | `0`  |
   | 1 | `(n*n)/4` |
   | 2 | `(n*n)/4 * 2` |
   | 3 | `(n*n)/4 * 3` |

4. 해당 사분면 안으로 들어갈 때는,  
   행과 열을 사분면 기준으로 다시 조정해서 재귀 호출한다.

## 코드

```java
import java.io.*;
import java.util.StringTokenizer;

public class Main {
 static int count = 0; // 현재까지의 방문 순서 카운트

 public static void main(String[] args) throws Exception {
     BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
     BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
     StringTokenizer st = new StringTokenizer(br.readLine());

     int N = Integer.parseInt(st.nextToken());
     int r = Integer.parseInt(st.nextToken());
     int c = Integer.parseInt(st.nextToken());

     find(1 << N, r, c); // 배열 크기는 2^N

     bw.write(String.valueOf(count));
     bw.flush();
     bw.close();
 }

 private static void find(int n, int r, int c) {
     if (n == 1) return; // 크기가 1이면 종료 (마지막 칸 도달)

     int half = n / 2; // 절반 크기

     if (r < half && c < half) {              // 0번째 사분면
         find(half, r, c);
     } else if (r < half && c >= half) {      // 1번째 사분면
         count += half * half;                // 0번 사분면 건너뛰기
         find(half, r, c - half);
     } else if (r >= half && c < half) {      // 2번째 사분면
         count += 2 * half * half;            // 0, 1번 사분면 건너뛰기
         find(half, r - half, c);
     } else {                                 // 3번째 사분면
         count += 3 * half * half;            // 0, 1, 2번 사분면 건너뛰기
         find(half, r - half, c - half);
     }
 }
}
```

### 코드 설명
  - count	방문 순서를 저장하는 전역 변수 
  - find(n, r, c)	크기 n×n의 격자에서 좌표 (r, c)의 순서를 찾는 재귀 함수 
  - half = n/2	현재 영역을 4등분했을 때 한 변의 크기 
  - count += half*half*k	앞선 사분면들을 건너뛰며 순서 누적 (k은 사분면 번호 0~3)

### 요약 
> Z 모양 탐색을 4개의 사분면으로 나누어,  해당 좌표가 속한 사분면 이전의 영역 개수를 누적하고, 
> 사분면 내부 좌표로 재귀적으로 좁혀가는 분할 정복 문제.
