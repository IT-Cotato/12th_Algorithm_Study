# 문제
입력된 L개의 문자를 해시함수를 통해 숫자로 변환하는 프로그램 작성하기

1. a, b, c, ..., z -> 1, 2, 3, ..., 26 
2. 자리수 마다 31씩 곱한다 
3. 결과에서 1234567891을 나눈다.

## 1. 알파벳 숫자로 변환
`(str.charAt(i) - 'a' + 1)`
- 알파벳의 각 자리수에 'a'를 빼서 숫자로 변환(a가 1이므로 값 보정`+1`)
## 2. 자리수마다 31씩 곱하기
`pow = pow * 31`
## 3. 결과에서 1234567891을 나눈다.
```java
long sum = 0;
long pow = 1;
double bundle = Math.pow(31, 5);
for(int i = 0; i < n; i++){
    sum += (str.charAt(i) - 'a' + 1) * pow % 1234567891;
    pow = pow * 31 % 1234567891;
}
System.out.println(sum % 1234567891);
```
- 31을 계속 곱하면 자료형을 초과하기 때문에 `% 1234567891`로 계속해서 나누면서 초과하지 않도록 조정

        long sum = 0;
        long pow = 1;
        double bundle = Math.pow(31, 5);
        for(int i = 0; i < n; i++){
            sum += (str.charAt(i) - 'a' + 1) * pow % 1234567891;
            pow = pow * 31 % 1234567891;
        }
        System.out.println(sum % 1234567891);
    }
}
