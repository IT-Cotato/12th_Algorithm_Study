# 🚌 모든 도시 쌍의 최소 비용 구하기 (BOJ 11404)

## 📘 문제 개요

`n`개의 도시와 `m`개의 버스 노선이 주어질 때,  
모든 도시 쌍 `(A, B)`에 대해 **A에서 B로 가는 최소 비용**을 구하는 문제이다.  
직행 노선이 여러 개 있을 수 있으며, 그 중 **가장 비용이 낮은 노선만 반영**해야 한다.  
만약 A에서 B로 갈 수 없다면 해당 위치에는 **0**을 출력한다.

---

## 🧠 핵심 개념

### 1️⃣ 플로이드–워셜(Floyd–Warshall) 알고리즘

- **모든 정점 쌍 사이의 최단 거리**를 한 번에 구할 수 있는 알고리즘.
- 다익스트라와 달리, 특정 출발점에서만이 아니라 **모든 도시 쌍을 동시에** 고려한다.
- 동적 계획법(DP, Dynamic Programming)의 한 형태로,  
  “경유 도시”를 하나씩 늘려가며 점진적으로 최단 거리를 갱신한다.

**점화식:**
\[
dist[i][j] = \min(dist[i][j],\ dist[i][k] + dist[k][j])
\]

- `dist[i][j]`: 도시 i에서 j로 가는 현재까지의 최소 비용
- `k`: 중간에 거칠 수 있는 경유 도시

---

### 2️⃣ INF(무한대) 개념

- 두 도시가 아직 연결되지 않았다는 뜻을 나타내기 위해  
  매우 큰 수(`1e15`)를 `INF`로 정의한다.
- 경로 갱신 시 “연결되지 않은 거리(INF)”는 계산에서 제외한다.
- 최종 출력 시 `INF`로 남은 값은 **0**으로 출력한다.

---

### 3️⃣ 알고리즘 단계

| 단계                      | 내용                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------- |
| **1. 초기화**             | `dist[i][j]`를 전부 `INF`로 초기화하고, `dist[i][i] = 0`으로 설정한다.                          |
| **2. 간선 입력 반영**     | 주어진 노선 `(a, b, c)`에 대해 `dist[a][b] = min(dist[a][b], c)`로 설정한다. (중복 간선 최소화) |
| **3. 플로이드–워셜 수행** | 세 개의 반복문(`k`, `i`, `j`)을 이용해 모든 도시 쌍의 최소 비용을 갱신한다.                     |
| **4. 결과 출력**          | `INF` 값은 `0`으로 바꾸고, 공백으로 구분해 한 줄씩 출력한다.                                    |

## 💻 구현 코드 (JavaScript)

```js
const fs = require("fs");
const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const n = Number(input[0]);
const m = Number(input[1]);
const INF = 1e15;

// 거리 배열 초기화
const dist = Array.from({ length: n + 1 }, () => Array(n + 1).fill(INF));
for (let i = 1; i <= n; i++) dist[i][i] = 0;

// 간선 입력 반영
for (let idx = 2; idx < 2 + m; idx++) {
  const [a, b, c] = input[idx].split(" ").map(Number);
  if (c < dist[a][b]) dist[a][b] = c;
}

// 플로이드–워셜 알고리즘
for (let k = 1; k <= n; k++) {
  for (let i = 1; i <= n; i++) {
    if (dist[i][k] === INF) continue;
    for (let j = 1; j <= n; j++) {
      if (dist[k][j] === INF) continue;
      const via = dist[i][k] + dist[k][j];
      if (via < dist[i][j]) dist[i][j] = via;
    }
  }
}

// 결과 출력
let out = "";
for (let i = 1; i <= n; i++) {
  const row = [];
  for (let j = 1; j <= n; j++) {
    row.push(dist[i][j] === INF ? 0 : dist[i][j]);
  }
  out += row.join(" ") + "\n";
}
console.log(out.trim());
```

---

## 📈 시간 복잡도

- **O(n³)**  
  (최대 n=100 → 약 1,000,000 연산으로 충분히 처리 가능)

---

## 📚 배운 점 요약

- **플로이드–워셜**은 “모든 쌍 최단 경로”를 구하는 대표적인 DP 알고리즘이다.
- 중복 간선 처리 시 반드시 **최솟값만 유지**해야 한다.
- **자기 자신으로 가는 거리**(`dist[i][i]`)는 항상 0으로 초기화해야 한다.
- **INF 값 처리**를 통해 도달 불가능한 도시를 구분할 수 있다.
- 시간 복잡도는 `O(n³)`이지만, n ≤ 100이면 충분히 효율적이다.
