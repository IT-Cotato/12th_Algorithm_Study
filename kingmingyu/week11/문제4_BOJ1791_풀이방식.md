# 문제
테스트 케이스 c와 사람 n, 진료실 m, 각 환자마다 방문해야하는 진료실의 개수 k와 방문할 진료실들을 입력받아 가장 마지막에 진료가 끝나는 시간을 구하는 프로그램을 작성하는 문제

## 자료구조
### 1. 각 환자 정보가 담긴 Visitor class
```java
static class Visitor implements Comparable<Visitor> {
    int id, arrivalTime, step;
    int[] schedule;

    public Visitor(int id, int arrivalTime, int[] schedule) {
        this.id = id;
        this.arrivalTime = arrivalTime;
        this.schedule = schedule;
        this.step = 0;
    }

    @Override
    public int compareTo(Visitor o) {
        // 1. 시간순 정렬
        if (this.arrivalTime != o.arrivalTime)
            return Integer.compare(this.arrivalTime, o.arrivalTime);
        // 2. 시간 같으면 번호순 정렬
        return Integer.compare(this.id, o.id);
    }
}
```
- 환자마다 id와 도착시간, 현재 받아야하는 진료(step), 스케줄 정보를 갖는다.
- 우선순위 큐를 위해 Comparable을 implements하여 시간순으로 정렬하고 시간이 동일하다면 회원번호로 정렬하여 우선순위 큐에 집어 넣는다.

## 2. 우선순위 큐와 배열
```java
//환자를 우선순위 큐에 넣음
PriorityQueue<Visitor> pq = new PriorityQueue<>();
// 각 진료실의 의사가 진료를 마치는 시간
int[] doctor = new int[m + 1];
```
- 환자를 시간 순으로 꺼내기 위한 우선순위 큐
- 각 진료실의 의사가 진료를 마치는 시간을 저장하기 위한 배열

## 순서
### 1. 문제 입력값 받기
```java
// 테스트 케이스 개수
```

- c를 입력받아 test 케이스 개수 만큼 반복
- 방문자수 n과 진료실 수 m을 입력받아 저장
- 그 후 각 방문자수 만큼 반복하면서 방문자의 정보를 저장(도착 시간, 방문해야하는 진료실의 개수와 스케줄)

### 2. 시뮬레이션
```java
int lastT = 0;

while(!pq.isEmpty()){
    Visitor v = pq.poll();
    int cur = v.schedule[v.step];

    int startT = Math.max(v.arrivalTime, doctor[cur]);
    int finishT = startT + 1;

    doctor[cur] = finishT;

    if(v.step + 1 < v.schedule.length){
        v.step++;
        v.arrivalTime = finishT;
        pq.add(v);
    }
    else {
        lastT = Math.max(lastT, finishT);
    }
}
System.out.println(lastT);
```
- 각 환자가 시간 순으로 저장된 우선 순위 큐에서 1명 꺼내오기
- `Math.max(v.arrivalTime, doctor[cur])` 를 통해 더 늦게 끝나는 작업을 선택하여 진료 시작
- `doctor[cur] = finishT`를 통해 진료 끝나는 시간 업데이트
- 만약 진료해야하는 스케줄이 남았다면 계속 진행
- 아니라면 가장 늦게 끝나는 시간을 출력하기


## 전체 코드
```java
package kingmingyu.week11;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;


public class 문제4_BOJ1791_풀이 {
    static class Visitor implements Comparable<Visitor> {
        int id, arrivalTime, step;
        int[] schedule;

        public Visitor(int id, int arrivalTime, int[] schedule) {
            this.id = id;
            this.arrivalTime = arrivalTime;
            this.schedule = schedule;
            this.step = 0;
        }

        @Override
        public int compareTo(Visitor o) {
            // 1. 시간순 정렬
            if (this.arrivalTime != o.arrivalTime)
                return Integer.compare(this.arrivalTime, o.arrivalTime);
            // 2. 시간 같으면 번호순 정렬
            return Integer.compare(this.id, o.id);
        }
    }
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 테스트 케이스 개수
        int c = Integer.parseInt(br.readLine());

        for(int i = 0; i < c; i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            // 방문자 수
            int n = Integer.parseInt(st.nextToken());
            // 진료실 수
            int m = Integer.parseInt(st.nextToken());
            PriorityQueue<Visitor> pq = new PriorityQueue<>();
            // 각 진료실의 의사가 진료를 마치는 시간
            int[] doctor = new int[m + 1];

            for(int j = 0; j < n; j++){
                st = new StringTokenizer(br.readLine());
                // 도착 시간
                int t = Integer.parseInt(st.nextToken());
                // 방문할 진료실의 개수
                int k = Integer.parseInt(st.nextToken());

                int[] schedule = new int[k];
                for(int i2 = 0; i2 < k; i2++){
                    schedule[i2] = Integer.parseInt(st.nextToken());
                }
                pq.add(new Visitor(j, t, schedule));
            }

            int lastT = 0;

            while(!pq.isEmpty()){
                Visitor v = pq.poll();
                int cur = v.schedule[v.step];

                int startT = Math.max(v.arrivalTime, doctor[cur]);
                int finishT = startT + 1;

                doctor[cur] = finishT;

                if(v.step + 1 < v.schedule.length){
                    v.step++;
                    v.arrivalTime = finishT;
                    pq.add(v);
                }
                else {
                    lastT = Math.max(lastT, finishT);
                }
            }
            System.out.println(lastT);
        }
    }
}
```
