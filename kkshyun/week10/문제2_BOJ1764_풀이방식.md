## BOJ 1764 문제 요약

- 듣도 못한 사람 N명, 보도 못한 사람 M명 입력
- 두 목록에 모두 포함되는 사람(교집합) 찾기 문제
- 교집합 인원 수 출력 후, 이름을 사전순으로 출력하는 문제

---

## 아이디어

- 해시 기반 조회 사용
- 듣도 못한 사람 이름을 `HashMap`에 저장하는 방식
- 보도 못한 사람을 입력받으며 `map.containsKey(name)`으로 교집합 여부 확인하는 방식
- 교집합인 경우 카운트 증가 및 해당 이름을 표시값 `1`로 변경하는 방식
- 전체 입력 이후 `map`을 순회하면서 값이 `1`인 이름만 리스트에 수집
- 리스트 정렬 후 사전순 출력 진행

---

## 알고리즘 단계

1. 입력으로 N, M 읽기
2. `HashMap` 생성 후 듣도 못한 사람 N명을 key로 저장하기
3. 보도 못한 사람 M명을 입력받으며 다음 작업 수행
    - `map.containsKey(name)`이면 교집합에 해당하는 이름으로 판단
    - `count` 증가 처리
    - `map`의 해당 key 값을 `1`로 변경 처리
4. `map.keySet()` 순회하며 값이 `1`인 key만 리스트에 추가
5. 리스트 `Collections.sort()`로 사전순 정렬 처리
6. `count` 출력 후 정렬된 리스트를 한 줄씩 출력 처리

## 코드

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int M = Integer.parseInt(s[1]);
        HashMap map = new HashMap<String,Integer>();
        String str;
        for (int i = 0; i < N; i++) {
            str = br.readLine();
            map.put(str,0);
        }
        int count = 0;
        for (int i = 0; i < M; i++) {
            str = br.readLine();
            if(map.containsKey(str)) {
                count++;
                map.replace(str,0, 1);
            }
        }
        bw.write(count+"\n");
        List<String> list = new LinkedList<>();
        for (Object key : map.keySet()) {
            if(map.get(key).equals(1)) {
                list.add((String) key);
            }
        }
        Collections.sort(list);
        for (String name : list) {
            bw.write(name+"\n");
        }
        bw.flush();
        bw.close();
    }
}
```

## 시간 복잡도

- 메모리: 26604 KB, 시간: 284 ms
- 시간 복잡도: O(N + M + K log K) 형태
    - `HashMap` 삽입 N회, 조회 M회 수행
    - 교집합 크기를 K라고 할 때, 정렬 비용 `K log K` 발생
