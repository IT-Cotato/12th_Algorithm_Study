# 알고리즘 정리

백트래킹(Backtracking) 알고리즘은 **해결책을 찾는 과정에서 현재의 경로가 해답으로 이어지지 않을 것 같으면, 이전에 왔던 길(즉, 백)으로 되돌아가(트랙킹) 다른 경로를 탐색**하는 범용적인 탐색 기법입니다. 주로 제약 조건 만족 문제(Constraint Satisfaction Problems)를 해결하는 데 사용되며, 가능한 모든 경우의 수를 탐색하는 **깊이 우선 탐색(DFS)의 한 형태**입니다.

---

## 1. 백트래킹의 핵심 개념

### 가. 기본 원리

백트래킹은 '상태 공간 트리(State Space Tree)'를 기반으로 합니다. 이 트리는 문제 해결을 위한 모든 가능한 선택지와 그 결과 상태를 나타냅니다.

1. **경로 선택 (Promising):** 현재 상태에서 가능한 다음 선택지를 고르고, 해답의 가능성이 있는지 검사합니다.
2. **전망성 검사 (Pruning/Bounding):** 선택한 경로가 **제약 조건을 위반**하거나 **최종 해답에 도달할 가능성이 없다**고 판단되면, 그 경로의 하위 노드들은 더 이상 탐색하지 않고 **가지치기(Pruning)**하여 탐색을 중단합니다.
3. **되돌아가기 (Backtrack):** 현재 노드에서 더 이상 탐색할 경로가 없거나, 탐색을 중단했다면 이전 노드(부모 노드)로 되돌아가서(backtrack) 다른 선택지를 탐색합니다.

### 나. DFS와의 차이점

- **DFS:** 모든 경로를 끝까지 탐색합니다.
- **백트래킹:** 탐색 도중에 해답이 될 가능성이 없는 경로는 즉시 **가지치기(Pruning)**하여 탐색 시간을 극적으로 줄입니다.

## 2. 자바(Java)로 구현하는 기본 구조

백트래킹은 일반적으로 재귀 함수(Recursive Function)를 사용하여 구현합니다.
public class BacktrackingExample {

    // 문제 해결을 위한 주 함수 (예: N-Queen 문제에서 퀸을 배치하는 함수)
    public void solve(int level, ... 제약조건에 필요한 매개변수) {
        
        // 1. 종료 조건 (Termination Condition): 해답을 찾은 경우
        if (level == 최종_깊이) {
            // 해답 기록 또는 출력
            printSolution();
            return;
        }

        // 2. 가능한 모든 선택지 반복 (Iterate through all choices)
        for (int choice : 가능한_선택지_집합) {
            
            // 3. 전망성 검사 (Is it Promising?): 제약 조건을 만족하는지 검사
            if (isSafe(level, choice)) {
                
                // 4. 선택 및 상태 업데이트 (Choose and Update State)
                makeChoice(level, choice); 

                // 5. 재귀 호출 (Recursive Call) - 다음 단계로 이동 (DFS)
                solve(level + 1, ...);

                // 6. 되돌리기 (Backtrack) - 상태 복원
                // 다음 반복문에서 다른 선택지를 시도하기 위해 상태를 이전으로 되돌립니다.
                unmakeChoice(level, choice); 
            }
        }
    }
}
