# ✅ BOJ 1764 - 듣보잡

**듣도 못한 사람 목록(N)** 과 **보도 못한 사람 목록(M)** 이 주어질 때,
두 목록에 **공통으로 포함된 이름(교집합)** 을 찾아 **사전순으로 출력**한다.

---

## 1) 핵심 포인트

- N, M 최대 **500,000** → 단순 비교(이중 반복문)는 무조건 시간 초과
- 필요한 건 딱 2가지

  1. **존재 여부를 빠르게 확인**하기
  2. 결과를 **사전순 정렬**하기

따라서 **해싱(Set)** 을 사용한다.

---

## 2) 풀이 아이디어

### ✅ 전략

1. 듣도 못한 사람 N명을 `Set`에 저장한다.
2. 보도 못한 사람 M명을 하나씩 보면서

   - `Set.has(name)` 이면 듣보잡이므로 결과 배열에 추가한다.

3. 결과 배열을 `sort()`로 사전순 정렬한다.
4. 결과 개수와 이름 목록을 출력한다.

---

## 3) 왜 Set을 쓰는가?

### ❌ 이중 반복문(비추천)

- `N * M`이 될 수 있음
- 최악: 500,000 × 500,000 → 말도 안 되는 연산량

### ✅ Set 사용(추천)

- `Set.has()`는 평균 **O(1)**
- 전체는 **O(N + M)** 수준으로 해결 가능

---

## 4) 단계별 풀이 과정 (사고 흐름)

### Step 1. 입력 파싱

- 첫 줄에서 N, M을 읽는다.
- 다음 N줄은 듣도 못한 사람
- 그 다음 M줄은 보도 못한 사람

### Step 2. 듣도 못한 사람을 Set에 저장

- 이후 조회를 빠르게 하기 위함

### Step 3. 보도 못한 사람을 순회하며 교집합 찾기

- 이름을 하나씩 꺼내서 `heardSet.has(name)` 검사
- true면 결과 배열에 push

### Step 4. 사전순 정렬

- 문제 요구사항: 이름을 사전순으로 출력

### Step 5. 출력 포맷 맞추기

- 첫 줄: 결과 개수
- 이후: 결과 이름들(한 줄에 하나)

---

## 5) 구현 코드 (Node.js)

```js
const fs = require("fs");

const input = fs.readFileSync(0, "utf8").trim().split("\n");

const [N, M] = input[0].split(" ").map(Number);

// 듣도 못한 사람 목록을 Set에 저장
const heardSet = new Set();

for (let i = 1; i <= N; i++) {
  heardSet.add(input[i].trim());
}

// 듣보잡 후보 찾기
const result = [];

for (let i = N + 1; i <= N + M; i++) {
  const name = input[i].trim();
  if (heardSet.has(name)) {
    result.push(name);
  }
}

// 사전순 정렬
result.sort();

// 출력
let output = "";
output += result.length + "\n";
output += result.join("\n");
console.log(output);
```

---

## 6) 시간 복잡도 분석

- Set에 N명 저장: **O(N)**
- M명 조회: **O(M)**
- 결과 K명 정렬: **O(K log K)**

✅ 전체: **O(N + M + K log K)**

> K는 교집합(듣보잡)의 수이며, 보통 N+M에 비해 작거나 같은 수준.

---

## 8) 이 문제에서 얻어갈 것

- "두 집합의 교집합" 문제는 해싱(Set)이 정답에 가깝다
- 큰 입력에서는 `includes()` 같은 선형 탐색을 피해야 한다
- 결과 출력 형식을 문자열로 모아 한 번에 출력하면 안전하다
