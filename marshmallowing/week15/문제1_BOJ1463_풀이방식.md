# BOJ 1463

## 문제 핵심
정수 N이 주어졌을 때,  
다음 연산을 사용해 **1을 만드는 최소 연산 횟수**를 구한다.

가능한 연산:
1. N이 3으로 나누어 떨어지면 → N / 3
2. N이 2로 나누어 떨어지면 → N / 2
3. N에서 1을 뺀다 → N - 1

---

## DP 정의
dp[i] = **정수 i를 1로 만드는 데 필요한 최소 연산 횟수**

---

## 초기값
dp[1] = 0  
(이미 1이므로 연산이 필요 없음)

---

## 점화식 유도 과정

어떤 수 i에서 1로 가려면  
**반드시 한 번의 연산을 먼저 수행**해야 한다.

즉,
- i → i-1
- i → i/2 (가능할 때)
- i → i/3 (가능할 때)

이 세 경우 중 **가장 적은 연산 횟수 경로**를 선택하면 된다.

---

## 점화식

1. 항상 가능한 경우 (기본값)
```
dp[i] = dp[i - 1] + 1
```

2. 2로 나누어 떨어질 경우
```
dp[i] = min(dp[i], dp[i / 2] + 1)
```

3. 3으로 나누어 떨어질 경우
```
dp[i] = min(dp[i], dp[i / 3] + 1)
```

> 모든 가능한 첫 연산을 비교해서 **최솟값 선택**

---

## 전체 반복 구조

```
for i = 2 to N:
    dp[i] = dp[i - 1] + 1

    if i % 2 == 0:
        dp[i] = min(dp[i], dp[i / 2] + 1)

    if i % 3 == 0:
        dp[i] = min(dp[i], dp[i / 3] + 1)
```

---

## 최소가 보장되는 이유

- dp[i-1], dp[i/2], dp[i/3]는 이미 **최소 연산 횟수**
- 거기에 현재 연산 1회를 더한 값만 비교
- 따라서 더 좋은 경로가 나중에 생길 수 없음

> **모든 가능한 첫 선택을 다 비교했기 때문**

---

## 핵심

> dp[i]는  
> **i에서 한 번 갈 수 있는 모든 경우 중  
> 가장 적은 연산 횟수를 가진 경로 + 1 이다.**

---

## 시간 & 공간 복잡도
- 시간 복잡도: O(N)
- 공간 복잡도: O(N)
