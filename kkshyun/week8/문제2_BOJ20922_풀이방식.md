## BOJ 20922 문제 요약

- 길이 N인 수열이 주어지고, 정수 K가 주어진다.
- 연속된 부분 수열 중에서, 어떤 숫자도 K번을 초과해서 등장하지 않는 부분 수열들만 고려했을 때, 만들 수 있는 부분 수열의 최대 길이를 구하는 문제

---

## 아이디어

- 투 포인터 / 슬라이딩 윈도우
- 윈도우를 `[start, i]` 라고 두고, 오른쪽 포인터 `i`를 0부터 끝까지 확장하면서:
   1. `sequence[i]` 값을 윈도우에 포함시키려고 할 때,

      이미 이 값이 윈도우 안에서 K번 등장했다면 더 이상 넣을 수 없음.

   2. 이때는 왼쪽 포인터 `start`를 오른쪽으로 당기면서
      - 윈도우에서 값을 하나씩 제거하고(등장 횟수 감소),
      - `sequence[i]`가 들어갈 수 있을 만큼(= 등장 횟수가 K 미만이 될 때까지) 줄여준다.
   3. 조건을 만족하게 줄인 뒤에 `sequence[i]`를 윈도우에 포함.
   4. 매 번 윈도우 길이 `temp`를 갱신하면서 `max`와 비교해 최댓값을 업데이트.
- 등장 횟수 관리는 `Map<Integer, Integer>`로:
   - `map.getOrDefault(x, 0)` : 현재 윈도우에서 x가 몇 번 나왔는지
   - 왼쪽 포인터를 옮길 때마다 해당 값의 카운트를 1 줄여준다.

---

## 알고리즘 단계

1. 입력으로 N(수열 길이), K(허용 최대 등장 횟수)를 읽는다.
2. 길이 N의 수열 `sequence`를 입력받는다.
3. 다음과 같이 슬라이딩 윈도우를 초기화한다.
   - `start = 0` : 왼쪽 포인터
   - `temp = 0` : 현재 윈도우 길이
   - `max = 0` : 지금까지 본 최대 길이
   - `map` : 각 값의 등장 횟수 저장용 `HashMap`
4. i를 0부터 N-1까지 순회하면서:
   - `sequence[i]`가 이미 윈도우 안에서 K번 나와 있다면,
      - `start`를 오른쪽으로 옮기며 값을 제거:
         - `sequence[start]`의 등장 횟수를 1 감소시키고,
         - `temp`도 1 감소,
         - `sequence[start] == sequence[i]`인 지점을 만나면 그 값 하나를 제거한 뒤 멈춘다.
   - 이제 `sequence[i]`를 윈도우에 넣을 수 있으므로:
      - `map`에서 해당 값 등장 횟수를 +1
      - `temp++`
   - `max = Math.max(max, temp)`로 최대 길이 갱신.
- 반복이 끝나면 `max`가 조건을 만족하는 연속 부분 수열의 최대 길이이므로 출력한다.

## 코드

```java
import java.io.*;
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int K = Integer.parseInt(s[1]);
        int[] sequence = new int[N];
        s = br.readLine().split(" ");
        for (int i = 0; i < N; i++) {
            sequence[i] = Integer.parseInt(s[i]);
        }
        int max = 0;
        int temp = 0;
        int start = 0;
        Map<Integer, Integer> map = new HashMap<Integer, Integer>();
        for (int i = 0; i < sequence.length; i++) {
            if(map.containsKey(sequence[i])&& map.get(sequence[i]) == K) {
                while(start < i) {
                    if(sequence[start] == sequence[i]) {
                        start++;
                        temp--;
                        break;
                    }else {
                        map.put(sequence[start], map.get(sequence[start]) - 1);
                        start++;
                        temp--;
                    }
                }
            } else {
                map.put(sequence[i], map.getOrDefault(sequence[i], 0) + 1);
            }
            temp++;
            max = Math.max(max, temp);
        }
        bw.write(max+"\n");
        bw.flush();
        bw.close();
    }
}
```
