## BOJ 11053 문제 요약

- 길이 N인 수열이 주어진다.
- 이 수열에서 일부 원소를 골라(순서는 유지, 연속일 필요 없음) 증가하는 부분 수열을 만들 수 있다.
- 그중 가장 길이가 긴 증가하는 부분 수열의 길이를 출력하는 문제
- 증가 조건은 앞의 값 < 뒤의 값이다.

---

## 아이디어

- dp[i]를 i번째 원소(arr[i])를 반드시 포함하는 증가하는 부분 수열의 최대 길이라고 둔다.
- i보다 앞에 있는 모든 j를 보면서
    - arr[j] < arr[i] 인 경우에만 i 뒤에 붙일 수 있다.
    - 그때 dp[i]는 dp[j] + 1 후보가 된다.
- 모든 j를 확인해서 dp[i]의 최댓값을 만든다.
- 전체 답은 dp[i]들 중 최댓값이다.

---

## 알고리즘 단계

1. N을 입력받고 수열 arr을 저장한다. (코드에서는 편의를 위해 1부터 사용하고 arr[0]은 0으로 둠)
2. dp 배열을 준비한다.
    - dp[i] = i번째 값을 포함하는 LIS 길이
3. i를 1부터 N까지 순회한다.
    1. j를 0부터 i-1까지 순회한다.
    2. arr[j] < arr[i] 이면
        - dp[i] = max(dp[i], dp[j] + 1) 로 갱신한다.
4. i마다 max = max(max, dp[i]) 로 전체 최댓값을 갱신한다.
5. max를 출력한다.

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int[] arr = new int[N+1];
        st = new StringTokenizer(br.readLine());
        for (int i = 1; i <= N; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        int[] dp = new int[N+1]; // 해당 인덱스를 포함하는 가장 긴 부분 수열
        int max = 0;
        for (int i = 1; i < dp.length; i++) {
            for (int j = 0; j < i; j++) {
                // 무조건 포함해야 업데이트
                if(arr[j] < arr[i])
                    dp[i] = Math.max(dp[j]+1, dp[i]);
            }
            max = Math.max(max, dp[i]);
        }
        System.out.println(max);
    }
}
```
