# 문제
공백으로 구분된 문자열을 뒤집는 문제이다.
이 때 <>안에 든 문자열은 뒤집지 않아야 한다.

## 구현 방식
1. 문자열를 입력받는다.
2. 문자를 하나씩 확인하면서 <인지 아닌지 확인한다.
3. 만약 '<'라면 `inflag`를 true로 만든다. -> 문자를 뒤집지 않고 바로 정답 문자열에 추가한다.
4. `inflag`가 false라면 임시로 StringBuilder에 저장한다.
5. 모든 문자열을 확인하고 남은 StringBuilder를 비워주고 정답을 출력한다.

```java
package kingmingyu.week12;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Deque;
import java.util.LinkedList;

public class 문제1_BOJ17413_풀이 {
    public static void main(String[] args) throws IOException {
        
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 임시로 문자들을 저장할 공간
        StringBuilder sb = new StringBuilder();
        // 정답을 저장할 공간
        StringBuilder answer = new StringBuilder();
        // 1. 문자열 입력받기
        String str = br.readLine();

        boolean intag = false;
        // 모든 문자에 대해서 반복문
        for(int i = 0; i < str.length(); i++){
            // 만약 '<'라면 지금까지 임시 배열에 저장되어 있던 문자들을 뒤집어서 정답에 저장 및 초기화
            // 역순으로 저장할 필요 없으므로 바로 정답에 저장 + inflag = true
            if(str.charAt(i) == '<'){
                answer.append(sb.reverse());
                sb.setLength(0);

                answer.append(str.charAt(i));
                intag = true;
            }
            else if(str.charAt(i) == '>'){
                answer.append(str.charAt(i));
                intag = false;
            }
            // <> 안에 있는 경우이므로 바로 정답에 저장
            else if(intag){
                answer.append(str.charAt(i));
            }
            else if(str.charAt(i) == ' '){
                answer.append(sb.reverse()).append(" ");
                sb.setLength(0);
            }
            else{
                sb.append(str.charAt(i));
            }
        }
        // 마지막으로 임시 배열에 저장된 문자를 정답 배열에 저장
        answer.append(sb.reverse());
        System.out.println(answer);
    }
}
```
