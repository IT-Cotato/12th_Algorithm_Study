# BOJ 1780 -- 종이의 개수 (분할 정복)

## 문제 설명

크기가 N×N인 종이가 있고, 각 칸에는 **-1, 0, 1** 중 하나가 적혀 있다.
우리는 종이를 다음 규칙에 따라 잘라야 한다:

1.  **현재 종이가 모두 같은 숫자로 이루어져 있으면** 더 이상 자르지 않고
    하나로 센다.
2.  **같은 숫자가 아니라면** 종이를 같은 크기의 **9개(3×3)** 로 자르고,
    각 조각에 대해 위 규칙을 반복한다.

출력:\

- -1로만 이루어진 종이 개수
- 0으로만 이루어진 종이 개수
- 1로만 이루어진 종이 개수

---

## 핵심 아이디어 (Divide & Conquer)

- 종이가 한 숫자로만 이루어져 있으면 → 카운트 후 종료
- 그렇지 않으면 → 9조각으로 분할하여 재귀 호출
- `size`가 1이 되면 한 칸만 검사하므로 무조건 카운트됨
- N은 3^k 꼴이므로 정확히 나눠짐

---

## 구현 아이디어

### 한 종이 검사

1.  `(x, y)` 값을 기준값으로 잡는다.
2.  종이 전체가 기준값과 같은지 확인한다.
3.  전부 같으면 카운트 후 종료
4.  하나라도 다르면 9조각으로 분할해 재귀 호출

### 분할 방식

`size`를 `newSize = size / 3`으로 나누고
다음 9개 영역을 재귀 호출한다:

    (x + 0·newSize, y + 0·newSize)
    (x + 0·newSize, y + 1·newSize)
    (x + 0·newSize, y + 2·newSize)

    (x + 1·newSize, y + 0·newSize)
    (x + 1·newSize, y + 1·newSize)
    (x + 1·newSize, y + 2·newSize)

    (x + 2·newSize, y + 0·newSize)
    (x + 2·newSize, y + 1·newSize)
    (x + 2·newSize, y + 2·newSize)

## JavaScript 코드

```js
const fs = require("fs");

const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const N = Number(input[0]);
const paper = input.slice(1).map((line) => line.split(" ").map(Number));

let minusCount = 0;
let zeroCount = 0;
let plusCount = 0;

function cut(x, y, size) {
  const first = paper[x][y];
  let same = true;

  for (let i = x; i < x + size; i++) {
    for (let j = y; j < y + size; j++) {
      if (paper[i][j] !== first) {
        same = false;
        break;
      }
    }
    if (!same) break;
  }

  if (same) {
    if (first === -1) minusCount++;
    else if (first === 0) zeroCount++;
    else plusCount++;
    return;
  }

  const newSize = size / 3;

  for (let dx = 0; dx < 3; dx++) {
    for (let dy = 0; dy < 3; dy++) {
      cut(x + dx * newSize, y + dy * newSize, newSize);
    }
  }
}

cut(0, 0, N);

console.log(minusCount);
console.log(zeroCount);
console.log(plusCount);
```

## 요약

- 전형적인 **분할 정복** 문제
- 한 종이가 같은 숫자인지 판단 → 그렇지 않으면 3×3 분할
- 재귀 깊이는 log₃(N)
- 모든 종이(부분 행렬)를 9개씩 분할하며 해결
