📌 슬라이딩 윈도우 (Sliding Window) 알고리즘 정리

🔍 개념 한 줄 요약

연속된 구간(부분 배열/부분 문자열)을 효율적으로 탐색하기 위한 알고리즘 기법

    •	고정 또는 가변 크기의 “윈도우”를 이동시키며 답을 갱신한다.
    •	중복 계산을 줄여 시간 복잡도를 획기적으로 개선한다.

⸻

❓ 왜 필요한가?

연속 부분 구간 문제를 단순 반복문으로 풀면:

모든 시작점 × 모든 끝점 → O(N²)

하지만 슬라이딩 윈도우를 사용하면:

한 번 들어온 값은 한 번만 나간다 → O(N)

⸻

🧠 기본 구조

📍 투 포인터 기반
• left : 윈도우의 시작
• right : 윈도우의 끝

let left = 0;
for (let right = 0; right < N; right++) {
// right 확장

while (조건 위반) {
// left 축소
left++;
}

// 정답 갱신
}

⸻

🔀 슬라이딩 윈도우 유형

1️⃣ 고정 크기 윈도우
• 윈도우 크기가 항상 동일
• 주로 구간 합 / 평균 문제

예시
길이가 K인 구간 중 최대 합

let sum = 0;
for (let i = 0; i < K; i++) sum += arr[i];

let maxSum = sum;

for (let i = K; i < N; i++) {
sum += arr[i];
sum -= arr[i - K];
maxSum = Math.max(maxSum, sum);
}

⸻

2️⃣ 가변 크기 윈도우 ⭐⭐⭐
• 조건을 만족할 때까지 확장 / 축소

대표 문제 유형
• 중복 원소 제한
• 조건을 만족하는 최장/최단 부분 수열

let left = 0;
for (let right = 0; right < N; right++) {
add(arr[right]);

while (조건 위반) {
remove(arr[left]);
left++;
}

answer = Math.max(answer, right - left + 1);
}

⸻

🧩 핵심 포인트 정리

✅ 언제 while을 쓰는가?
• 조건이 여러 번 위반될 수 있을 때
• 조건을 만족할 때까지 left를 계속 이동해야 함

👉 if ❌, while ⭕

⸻

✅ 왜 시간 복잡도가 O(N)인가?
• right는 끝까지 한 번만 이동
• left도 끝까지 한 번만 이동

각 포인터 최대 N번 이동 → O(2N) = O(N)
