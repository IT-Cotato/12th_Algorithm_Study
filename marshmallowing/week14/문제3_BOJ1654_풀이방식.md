## BOJ 1654 

### 문제 요약
- 길이가 서로 다른 랜선 `K`개가 주어진다.
- 이 랜선들을 잘라서 **같은 길이의 랜선 `N`개 이상**을 만들고 싶다.
- 만들 수 있는 랜선 길이 중 **최대 길이**를 구하는 문제이다.

---

### 핵심 아이디어 - 이분 탐색(Binary Search)
랜선의 길이를 기준으로 **가능한지 / 불가능한지**를 판별하면서  
최대 길이를 찾아간다.


- 답은 **1부터 가장 긴 랜선의 길이(`max`) 사이**에 존재한다.
- 특정 길이 `mid`로 랜선을 잘랐을 때:
    - `N`개 이상 만들 수 있으면 → 길이를 더 늘릴 수 있음
    - `N`개 미만이면 → 길이를 줄여야 함

---

### 이분 탐색 진행 방식
- `first = 1` - 최소 가능한 길이
- `last  = 가장 긴 랜선 길이`
```java
while (first <= last):
    mid = (first + last) / 2

    cnt = mid 길이로 만들 수 있는 랜선 개수

    if cnt >= N:
        result = mid        // 일단 가능한 값 저장
        first = mid + 1     // 더 큰 길이 탐색
    else:
        last = mid - 1      // 길이 줄이기
```

### 자료형 주의
- mid, first, last, result는 long 사용
    - (first + last) / 2 계산 시 오버플로우 방지
