# 백준 11726

## 문제 요약
2×n 크기의 직사각형을
- 1×2 타일
- 2×1 타일  
로 채우는 경우의 수를 구하는 문제이다.
결과는 **10007로 나눈 나머지**를 출력한다.

---

## 풀이 접근 방식

이 문제의 핵심은 **마지막 열을 어떻게 채웠는지**에 따라 경우를 나누는 것이다.

### 1. 상태 정의
- `dp[n]` : 2×n 직사각형을 채우는 방법의 수

### 2. 점화식 도출
2×n을 채우는 마지막 방법은 두 가지다.

1. 마지막에 **세로 타일(2×1)**을 하나 놓은 경우  
   → 앞은 2×(n-1)  
   → 경우의 수: `dp[n-1]`

2. 마지막에 **가로 타일(1×2)** 두 개를 쌓아 놓은 경우  
   → 앞은 2×(n-2)  
   → 경우의 수: `dp[n-2]`

> 따라서 점화식은 다음과 같다.
dp[n] = dp[n-1] + dp[n-2]

---
### 초기값
- `dp[1] = 1`
- `dp[2] = 2`

## 구현 시 주의할 점
- 수가 커지므로 **매 연산마다 10007로 나눈다**
- n ≤ 1000 → 반복문으로 충분히 해결 가능

---

## Java 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());

        int[] dp = new int[n + 1];

        dp[1] = 1;
        if (n >= 2) {
            dp[2] = 2;
        }

        for (int i = 3; i <= n; i++) {
            dp[i] = (dp[i - 1] + dp[i - 2]) % 10007;
        }

        System.out.println(dp[n]);
    }
}
```

- 시간·공간 복잡도 
  - 시간 복잡도: O(n)
  - 공간 복잡도: O(n)
