## BOJ 1541 문제 요약

- 0~9, +, - 로만 이루어진 수식이 한 줄로 주어진다.
- 이 수식에 괄호를 적절히 넣어서 만들 수 있는 값 중 최솟값을 구하는 문제
- 단, 수식의 순서는 바꿀 수 없고 괄호만 추가할 수 있다.

---

## 아이디어

- 최소를 만들려면, 처음으로 -가 등장한 이후의 값들을 가능한 한 크게 만들어서 한 번에 빼면 된다.
- 즉, 수식을 - 기준으로 나눈 뒤
    - 첫 번째 덩어리는 그대로 더하고
    - 두 번째 덩어리부터는 각 덩어리 내부의 +들을 모두 더한 값을 전부 빼면 최소가 된다.
- 이유
    - 뒤에 있는 +들은 괄호로 묶으면 (a+b+c) 형태로 한 번에 빼는 것이 가능하고,
    - 이렇게 하면 빼는 값이 최대가 되어 전체 결과가 최소가 된다.

---

## 알고리즘 단계

1. 입력 문자열을 - 기준으로 split 한다. (tokens 배열)
2. sum을 0으로 둔다.
3. tokens를 왼쪽부터 순회하면서 각 토큰 덩어리를 계산한다.
    - 각 tokens[i]는 +로 연결된 숫자 덩어리이므로
        - 다시 + 기준으로 split 해서 숫자들을 모두 더해 temp를 만든다.
4. i가 0이면 sum에 temp를 더한다.
5. i가 1 이상이면 sum에서 temp를 뺀다.
6. 최종 sum을 출력한다.

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] tokens = br.readLine().split("-");
        int max = 0;
        int sum = 0;
        for (int i = 0; i < tokens.length; i++) {
            max = 0;
            String[] s = tokens[i].split("\\+");
            for (int j = 0; j < s.length; j++) {
                max += Integer.parseInt(s[j]);
            }
            if(i == 0) {
                sum += max;
            } else {
                sum -= max;
            }
        }
        System.out.println(sum);
    }
}
```
