## BOJ 1058 문제 요약

- 사람 수 N이 주어진다.
- N개의 줄로 친구 관계가 주어지며, graph[i][j]는 다음 중 하나이다.
    - 'Y' : i와 j는 직접 친구
    - 'N' : i와 j는 직접 친구 아님
- 어떤 사람 i의 2-친구는 다음 중 하나를 만족하는 사람이다.
    - i와 직접 친구(Y)
    - i와 직접 친구는 아니지만, 공통 친구 k가 존재해서 i-k, k-j가 모두 친구(Y)인 경우(친구의 친구)
- 각 사람마다 2-친구 수를 구하고, 그중 최댓값을 출력하는 문제

---

## 아이디어

- 목표는 각 i에 대해 "직접 친구 + 친구의 친구"를 세는 것.
- i와 j가 직접 친구가 아니더라도, 어떤 k에 대해 i-k가 Y이고 k-j가 Y면 j는 i의 2-친구가 된다.
- 코드에서는 원래의 graph를 그대로 쓰면서,
    - 직접 친구는 'Y' 그대로 유지
    - 2-친구로 판정되는 관계는 '2'로 표시해서 나중에 카운트할 때 'N'만 제외하고 모두 세도록 한다.
- 자기 자신(i == j)은 제외해야 한다.

---

## 알고리즘 단계

1. N을 입력받고, N×N 문자 배열 graph에 친구 관계('Y'/'N')를 저장한다.
2. 모든 쌍 (i, j)에 대해 검사한다.
    - graph[i][j]가 'N'이고 i != j인 경우만 possible(i, j)를 호출한다.
3. possible(i, j) 동작
    - 모든 k를 순회하며
        - graph[i][k] == 'Y' 이고 graph[k][j] == 'Y' 이면
            - j는 i의 친구의 친구이므로 graph[i][j]를 '2'로 표시
            - 관계는 대칭이므로 graph[j][i]도 '2'로 표시
            - 찾았으면 더 볼 필요 없으니 return
4. 모든 possible 처리가 끝난 뒤, 각 i에 대해 2-친구 수를 센다.
    - j를 0..N-1까지 보면서 graph[i][j]가 'N'이 아니면 count++
    - 이렇게 하면 'Y'(직접 친구)와 '2'(친구의 친구) 모두 포함된다.
5. i별 count 중 최댓값 max를 출력한다.

---

## 코드

```java
import java.io.*;

public class Main {
    static int N;
    static Character[][] graph;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        N = Integer.parseInt(br.readLine());
        graph = new Character[N][N];
        for (int i = 0; i < N; i++) {
            String s = br.readLine();
            for (int j = 0; j < s.length(); j++) {
                graph[i][j] = s.charAt(j);
            }
        }
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                if(graph[i][j] == 'N' && i!=j) {
                    possible(i,j);
                }
            }
        }
        int max = 0;
        for (int i = 0; i < N; i++) {
            int count = 0;
            for (int j = 0; j < N; j++) {
                if(graph[i][j] != 'N')
                    count++;
            }
            max = Math.max(max, count);
        }
        bw.write(max+"\n");
        bw.flush();
        bw.close();
    }

    public static void possible(int i, int j) {
        for (int k = 0; k < N; k++) {
            if(graph[i][k] == 'Y' && graph[k][j] == 'Y') {
                graph[i][j] = '2';
                graph[j][i] = '2';
                return;
            }
        }
    }
}
```
