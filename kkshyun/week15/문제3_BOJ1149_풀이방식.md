## BOJ 1149 문제 요약

- N개의 집이 일렬로 있다.
- 각 집은 빨강, 초록, 파랑 중 하나로 칠해야 한다.
- i번째 집을 각 색으로 칠하는 비용이 주어진다.
- 조건: 인접한 두 집은 같은 색으로 칠할 수 없다.
- 모든 집을 칠하는 총 비용의 최솟값을 출력하는 문제

---

## 아이디어

- dp[i][c]를 i번째 집을 색 c로 칠했을 때, 1~i번째 집까지 칠하는 최소 비용이라고 둔다.
    - c는 0=R, 1=G, 2=B
- i번째 집을 c로 칠했다면, i-1번째 집은 c가 아닌 다른 두 색 중 하나여야 한다.
- 그래서 점화식은 다음과 같다.
    - dp[i][0] = min(dp[i-1][1], dp[i-1][2]) + cost[i][0]
    - dp[i][1] = min(dp[i-1][0], dp[i-1][2]) + cost[i][1]
    - dp[i][2] = min(dp[i-1][0], dp[i-1][1]) + cost[i][2]
- 마지막 집까지 계산한 뒤 dp[N][0..2] 중 최소가 정답이다.

---

## 알고리즘 단계

1. N을 입력받는다.
2. 각 집의 비용을 arr[i][0..2]에 저장한다.
3. dp 배열을 준비한다. dp[i][c]는 i번째 집을 c색으로 칠했을 때의 최소 누적 비용.
4. i를 1부터 N까지 순회하며 dp를 채운다.
    - dp[i][0] = min(dp[i-1][1], dp[i-1][2]) + arr[i][0]
    - dp[i][1] = min(dp[i-1][0], dp[i-1][2]) + arr[i][1]
    - dp[i][2] = min(dp[i-1][0], dp[i-1][1]) + arr[i][2]
5. dp[N][0], dp[N][1], dp[N][2] 중 최솟값을 출력한다.

---

## 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int[][] dp = new int[N+1][3];
        int[][] arr = new int[N+1][3];
        for (int i = 1; i < N+1; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < 3; j++) {
                arr[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        for (int i = 1; i < N+1; i++) {
            dp[i][0] = Math.min(dp[i-1][1],dp[i-1][2]) + arr[i][0];
            dp[i][1] = Math.min(dp[i-1][0],dp[i-1][2]) + arr[i][1];
            dp[i][2] = Math.min(dp[i-1][0],dp[i-1][1]) + arr[i][2];
        }

        int min = Integer.MAX_VALUE;
        for (int i = 0; i < 3; i++) {
            min = Math.min(min, dp[N][i]);
        }
        System.out.println(min);
    }
}
```
