# 문제
주어진 식에서 계산 순서를 바꿔(괄호를 이용) 만들 수 있는 최소값 출력

입력: 최대 5자리 정수, +, -만 입력받는다. 식은 50개를 넘지 않는다.

## 풀이
-안에 숫자가 클 수록 숫자가 작아지므로 -기준으로 인덱싱을 수행한다.

### 1. - 기준으로 인덱싱 수행
```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

String calc = br.readLine();

String[] calcIdx = calc.split("-");
```
- calcIdx 안에는 -기준으로 값들이 분리되어 있다.
- 각 분리된 값들은 그냥 +연산을 수행하면 된다.
### 2. 남은 값들을 더하기
```java
int[] nums = new int[51];

boolean flag = false;
for(int i = 0; i < calcIdx.length; i++){
    if(i == 0 && calcIdx[i].isEmpty())
        flag = true;
    try{
        nums[i] = Integer.parseInt(calcIdx[i]);
    }
    catch (Exception e){
        String[] temp = calcIdx[i].split("\\+");
        int sum = 0;
        for(int j = 0; j < temp.length; j++){
            sum += Integer.parseInt(temp[j]);
        }
        nums[i] = sum;
    }
}
```
- 문제에서 50개이상의 식은 주어지지 않으므로 50개의 숫자를 담을 수 있는 배열 할당
- 첫 자리 숫자가 음수인 경우 빈 문자열을 반환하는데 이를 처리하기 위해서 `flag` 변수 이용
- 첫 자리수가 음수인 경우(isEmpty()) flag를 true로 만들기
- 남은 값들은 숫자만 있다면 바로 `nums배열`에 저장
- + 기호도 포함되어 있다면 + 연산을 수행하고 `nums배열`에 저장 
### 3. 결과에서 합치기
```java
int sum = 0;
for(int i = 0; i < nums.length; i++){
    if(i == 0){
        if(flag == true){
            sum -= nums[i];
        }
        else{
            sum += nums[i];
        }
    }
    else{
        sum -= nums[i];
    }
}
```
- flag가 true인 경우 첫자리 숫자가 음수이므로 -로 sum 변수에 합치기
- 아닌경우 양수이므로 양수로 합치기
- 나머지 nums에 저장된 값들은 모두 음수이므로 -로 합치기

### 전체 코드
```java
package kingmingyu.week14;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class 문제1_BOJ1541_풀이 {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String calc = br.readLine();

        String[] calcIdx = calc.split("-");

        int[] nums = new int[51];

        boolean flag = false;
        for(int i = 0; i < calcIdx.length; i++){
            if(i == 0 && calcIdx[i].isEmpty())
                flag = true;
            try{
                nums[i] = Integer.parseInt(calcIdx[i]);
            }
            catch (Exception e){
                String[] temp = calcIdx[i].split("\\+");
                int sum = 0;
                for(int j = 0; j < temp.length; j++){
                    sum += Integer.parseInt(temp[j]);
                }
                nums[i] = sum;
            }
        }

        int sum = 0;
        for(int i = 0; i < nums.length; i++){
            if(i == 0){
                if(flag == true){
                    sum -= nums[i];
                }
                else{
                    sum += nums[i];
                }
            }
            else{
                sum -= nums[i];
            }
        }

        System.out.println(sum);
    }
}

```
