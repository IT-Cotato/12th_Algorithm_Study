# 📉 BOJ 1541 — 잃어버린 괄호

## 🔍 문제 요약

양수와 `+`, `-`로 이루어진 수식이 주어진다.  
원래 식에는 괄호가 있었지만 모두 제거되었고,  
괄호를 적절히 다시 쳐서 **식의 값을 최소로 만드는 것**이 목표이다.

---

## 🧠 핵심 아이디어 (Greedy)

`-` 연산 이후에 등장하는 값들을 **최대한 크게 만들어 한 번에 빼면**
전체 결과를 최소로 만들 수 있다.

### 예시

A - B + C + D

위 식에서 괄호를 다음과 같이 치면:

A - (B + C + D)

괄호 안의 합이 한 번에 빠지므로 결과는 더 작아진다.

---

## ✅ 핵심 규칙

- **첫 번째 `-` 이전**의 값들은 그대로 더한다.
- **첫 번째 `-` 이후**의 값들은 전부 괄호로 묶어 더한 뒤 한 번에 뺀다.

즉,

1. 수식을 `-` 기준으로 분리한다.
2. 첫 번째 덩어리는 더한다.
3. 이후 덩어리들은 각각 내부의 `+` 연산을 모두 더한 뒤 전부 뺀다.

---

## 🧩 풀이 절차

1. 입력 문자열을 `-` 기준으로 분리한다.
2. 각 덩어리를 다시 `+` 기준으로 분리한다.
3. 각 덩어리의 숫자 합을 계산한다.
4. 첫 덩어리는 더하고, 나머지는 모두 뺀다.

---

## ✨ 예제 설명

### 입력

55-50+40

### 처리 과정

- `-` 기준 분리 → `["55", "50+40"]`
- 첫 덩어리 합 → `55`
- 두 번째 덩어리 합 → `50 + 40 = 90`
- 결과 → `55 - 90 = -35`

---

## 🧪 추가 예제

| 입력          | 출력  |
| ------------- | ----- |
| `10+20+30+40` | `100` |
| `00009-00009` | `0`   |

---

## ⏱️ 시간 복잡도

- 문자열 길이 최대 50
- 모든 연산은 한 번씩만 처리

👉 **O(N)**

---

## 📌 한 줄 요약

> **첫 `-` 이후의 모든 수를 한 번에 빼면 최솟값이 된다.**
