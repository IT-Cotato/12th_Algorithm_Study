## BOJ 1966 문제 요약

- 문서마다 우선순위가 있고, 프린터는 가장 높은 우선순위 문서부터 인쇄
- 큐의 맨 앞 문서를 확인했을 때 더 높은 우선순위 문서가 뒤에 있으면 맨 뒤로 보냄
- 특정 문서 M번 문서가 몇 번째로 인쇄되는지 구해야함
- 입력은 여러 테스트케이스로 주어짐

---

## 아이디어

두 개의 큐를 함께 사용

1. 입력값을 저장하기 위한 일반 큐 (Queue<int[]>)
    - 문서의 원래 인덱스와 우선순위를 함께 저장 : new int[]{index, priority}
    - 실제 프린터 동작(앞에서 꺼내 뒤로 붙이기 / 인쇄)
2. 가장 큰 우선순위를 알기 위한 최대 힙 (PriorityQueue<Integer>)
    - 현재 대기열에서 가장 큰 우선순위를 확인하기 위해 사용
    - 일반 큐의 맨 앞 문서와 최대 우선순위를 비교하여 인쇄 여부를 결정

---

## 알고리즘 단계

1. 입력으로 문서 수 N, 타겟 문서 인덱스 M, 우선순위 배열을 받음
2. queue에는 (index, priority)를 순서대로 넣고, priorityQueue에는 우선순위만 넣음
3. count = 0부터 시작:
    - queue.peek()의 우선순위를 priorityQueue.peek()(현재 최대)와 비교
    - 만약 현재 최대가 더 크면 → queue.poll()을 맨 뒤로 add (인쇄 X)
    - 같거나 작으면 → 실제 인쇄
        - queue.poll()로 문서를 꺼내고, priorityQueue.poll()로 최대값 제거
        - count++
        - 방금 인쇄한 문서의 index == M이면 반복 종료, count가 답이 됨
4. count 출력

## 코드

```java
package cotato;

import java.io.*;
import java.util.LinkedList;
import java.util.PriorityQueue;
import java.util.Queue;

public class BJ_1966_0918 {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        int Test = Integer.parseInt(br.readLine());

        // 최대 우선순위를 빠르게 알기 위한 최대 힙
        Queue<Integer> priorityQueue = new PriorityQueue<>((o1, o2) -> Integer.compare(o2, o1));
        
        Queue<int[]> queue = new LinkedList<>();

        for (int t = 0; t < Test; t++) {
		        // 테스트케이스마다 초기화 작업
            priorityQueue.clear();
            queue.clear();

            String[] s = br.readLine().split(" ");
            int N = Integer.parseInt(s[0]);
            int M = Integer.parseInt(s[1]);

            s = br.readLine().split(" ");
            for (int i = 0; i < N; i++) {
                int p = Integer.parseInt(s[i]);
                queue.add(new int[]{i, p});
                priorityQueue.add(p);
            }

            int count = 0;
            while (!queue.isEmpty() && !priorityQueue.isEmpty()) {
                int frontPriority = queue.peek()[1];
                int maxPriority = priorityQueue.peek();

                // 더 큰 우선순위가 뒤에 있으면 맨 뒤로 이동
                if (maxPriority > frontPriority) {
                    queue.add(queue.poll());
                    continue;
                }

                // 그렇지 않으면 인쇄
                int index = queue.poll()[0];
                priorityQueue.poll();
                count++;

                if (index == M) break;
            }

            bw.write(count + "\n");
        }
        bw.flush();
        bw.close();
    }
}
```

## 시간 복잡도

- PriorityQueue의 삽입/삭제는 O(log N), 비교는 O(1)
- 메모리: 16480 KB, 시간: 140 ms
