## BOJ 2805 문제 요약

- N개의 나무 높이가 주어진다.
- 절단기 높이 H를 정해서 나무를 자른다.
    - 높이가 H보다 큰 나무는 (나무높이 - H) 만큼 잘려서 가져갈 수 있다.
    - 높이가 H 이하인 나무는 잘리지 않는다.
- 잘라낸 나무 길이의 합이 최소 M 이상이 되도록 하는 H의 최댓값을 구한다.

---

## 아이디어

- H가 커질수록 잘리는 나무 길이 합(sum)은 줄어든다.
- 즉, H에 대해 sum은 단조 감소하므로 이분 탐색으로 최적의 H를 찾을 수 있다.
- 탐색 범위
    - start = 0
    - end = 나무 높이 중 최댓값
- mid 높이로 잘랐을 때 잘리는 길이 합(sum)을 계산해서,
    - sum이 M보다 크면(필요량보다 많이 잘림) H를 더 올려도 되므로 오른쪽 탐색
    - sum이 M보다 작으면(필요량 부족) H를 내려야 하므로 왼쪽 탐색
    - sum이 M이면 정답 후보이므로 mid 반환
- 코드에서는 sum > M 인 경우 mid+1 쪽으로 이동하며, 최종적으로 조건을 만족하는 최대 H를 start-1로 반환한다.

---

## 알고리즘 단계

1. N, M을 입력받는다.
2. N개의 나무 높이를 배열 trees에 저장하고, 동시에 최대 높이 max를 구한다.
3. binarySearch(0, max)를 호출해 절단기 높이의 최댓값을 찾는다.
4. binarySearch(start, end) 동작:
    1. start >= end이면 start-1을 반환한다. (조건을 만족하는 마지막 높이)
    2. mid = (start + end) / 2 로 절단기 높이를 정한다.
    3. 모든 나무에 대해 max(trees[i] - mid, 0)을 더해 sum을 구한다.
    4. sum 비교
        - sum > M이면: 더 덜 잘라도 되므로(절단기 높이를 올려도 됨) binarySearch(mid+1, end)
        - sum < M이면: 더 많이 잘라야 하므로 binarySearch(start, mid)
        - sum == M이면: mid 반환
5. 반환된 값을 출력한다.

---

## 코드

```java
import java.io.*;

public class Main {
    static int[] trees;
    static int M;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        M = Integer.parseInt(s[1]);
        s = br.readLine().split(" ");
        int max = 0;
        trees = new int[N];
        for (int i = 0; i < N; i++) {
            trees[i] = Integer.parseInt(s[i]);
            max = Math.max(max, trees[i]);
        }
        // 이분탐색(나무 최대길이에서 반씩 줄이면서 M이 되는지 확인)
        bw.write(binarySearch(0, max)+"\n");
        bw.flush();
        bw.close();
    }

    static long binarySearch(int start, int end) {
        if(start >= end)
            return start-1;
        int mid = (start + end) / 2;
        long sum = 0;
        for (int i = 0; i < trees.length; i++) {
            sum += Math.max(trees[i] - mid,0);
        }
        if(sum > M) // 나무를 많이 자르는거니까 더 길이를 보존해도 됨
            return binarySearch(mid+1, end);
        else if(sum < M)
            return binarySearch(start, mid);
        else
            return mid;
    }
}
```
