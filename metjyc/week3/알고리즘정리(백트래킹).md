# 📘 오늘 푼 알고리즘 문제 정리

## 1. 스도쿠 (BOJ 2239)

### 🔍 핵심 개념

- **백트래킹(Backtracking)** 을 이용해 빈 칸을 하나씩 채워 나가는 방식.
- 9x9 스도쿠 판에서 각 행, 열, 3x3 박스에 1~9가 중복 없이 한 번씩 등장해야 한다.
- 입력 값 중 0으로 표시된 칸을 모두 채우는 것이 목표.

### ✅ 풀이 방식 요약

1. **입력 처리**: 2차원 배열로 스도쿠 보드를 읽고, 값이 0인 칸의 좌표를 `blanks` 배열에 저장한다.
2. **백트래킹 함수 dfs(index)**:

   - index는 blanks에서 현재 채워야 할 칸의 인덱스를 의미한다.
   - 가능한 숫자(1~9)를 차례로 시도한다.
   - 가로, 세로, 3x3 박스 조건을 만족하는지 검사한다.
   - 유효하면 숫자를 넣고 다음 칸으로 진행하고, 실패 시 값을 되돌린다.

3. **종료 조건**: 모든 빈 칸을 채우면 스도쿠 완성 → 결과 출력 후 종료한다.

### 💡 주요 구현 포인트

- `isValid(x, y, num)`: 해당 칸에 num이 들어갈 수 있는지 확인하는 함수
- `Math.floor(x / 3) * 3`: x가 속한 3x3 박스의 시작 좌표 계산
- `process.exit()`: 첫 정답을 출력한 뒤 프로그램 종료

## 2. 부분수열의 합 (BOJ 1182)

### 🔍 핵심 개념

- **완전탐색(Brute-force)** + **백트래킹(DFS)** 으로 구현
- 주어진 수열에서 원소 일부를 선택하여 합이 S가 되는 모든 경우의 수를 계산한다.
- 단, 선택한 부분수열의 크기는 1 이상이어야 하며, 빈 부분수열은 제외된다.

### ✅ 풀이 방식 요약

1. `dfs(index, currentSum, pickedCount)` 함수를 재귀적으로 호출

   - index: 현재 수열에서 탐색 중인 위치
   - currentSum: 현재까지 선택한 숫자들의 합
   - pickedCount: 선택한 원소의 개수 (0이면 제외)

2. 각 수에 대해 "선택 or 비선택" 두 갈래로 분기
3. 종료 조건: index === N일 때, currentSum이 S이고 pickedCount > 0이면 count 증가
4. 총 2^N개의 조합을 모두 탐색하여 정답 도출

### 💡 주요 구현 포인트

- 부분수열은 원소 일부를 순서를 유지하며 선택한 조합
- 빈 부분수열은 유효하지 않으므로 pickedCount > 0 조건이 필요
- N ≤ 20 이므로 시간 복잡도 O(2^N)도 충분히 감당 가능

## ✅ 공통 개념 요약

| 항목        | 스도쿠 (BOJ 2239)             | 부분수열의 합 (BOJ 1182)                      |
| ----------- | ----------------------------- | --------------------------------------------- |
| 핵심 기법   | 백트래킹                      | 백트래킹 + 완전탐색                           |
| 탐색 대상   | 스도쿠 보드의 빈 칸들         | 수열에서 가능한 모든 부분수열 조합            |
| 조건 체크   | 행, 열, 박스의 중복 여부 확인 | 합이 S인지 여부 + 부분수열 크기 ≥ 1 여부 확인 |
| 종료 조건   | 모든 칸을 채운 경우 결과 출력 | 모든 원소를 탐색한 후 조건 만족 시 count 증가 |
| 시간 복잡도 | 최악의 경우 약 O(9^빈칸 수)   | O(2^N) (N ≤ 20)                               |

## 🔁 백트래킹(Backtracking) 이란?

- **백트래킹**은 가능한 모든 경우를 탐색하되, 중간에 조건을 만족하지 않으면 더 깊은 탐색을 하지 않고 돌아가는 기법이다.
- 모든 경우를 시도하는 완전탐색과 유사하지만, **가지치기(pruning)** 를 통해 불필요한 탐색을 줄인다.

### ✅ 주요 특징

- 재귀 함수로 상태를 확장하며 탐색
- 적합하지 않은 경로는 조기에 차단 (조건에 맞지 않으면 return)
- 탐색 후에는 상태를 이전으로 되돌리는 **원상복구(backtracking)** 를 수행

### 📌 활용 예시

- 스도쿠: 숫자를 하나씩 채워가며 유효성 검사, 실패 시 숫자 제거
- 부분수열의 합: 원소를 선택하거나 선택하지 않으며 합을 누적, 조건 불만족 시 백트랙

### 💬 요약

> 백트래킹은 **모든 가능한 해를 탐색하되**, 조건을 만족하지 않으면 가지를 잘라내며 효율적으로 정답을 찾는 전략이다.
