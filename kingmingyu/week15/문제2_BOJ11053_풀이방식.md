# 문제
수열 A가 주어졌을 때, 가장 긴 증가하는 부분 수열의 길이를 출력하는 프로그램

### 1. 문제 입력받기
```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

int n = Integer.parseInt(br.readLine());

int[] arr = new int[n];
StringTokenizer st = new StringTokenizer(br.readLine());
for(int i = 0; i < n; i++){
    arr[i] = Integer.parseInt(st.nextToken());
}
```
### 2. dp 이용
```java
int[] dp = new int[n];
int max = 0;
for(int i = 0; i < n; i++){
    dp[i] = 1;
    for(int j = 0; j < i; j++){
        // 이전 원소가 현재 원소보다 작고 이전 dp + 1이 현재 dp보다 크다면 갱신
        if(arr[j] < arr[i] && dp[i] < dp[j] + 1){
            dp[i] = dp[j] + 1;
        }
    }
    // dp에 저장된 값 중 가장 큰 값
    max = Math.max(max, dp[i]);
}
```
1. dp 배열에 자기 자신인 경우(`dp[n]`) 길이가 1이므로 1을 저장
2. 이전에 저장된 dp 배열을 탐색하면서 현재 자기 자신 arr값보다 크고, dp의 값이 큰 경우(배열의 길이가 더 긴 경우) dp배열 갱신
3. 그 중에서 가장 큰 값을 max에 계속 갱신

### 3. 출력
```java
System.out.println(max);
```

### 전체 코드
```java
package kingmingyu.week15;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;

public class 문제2_BOJ11053_풀이 {
    public static void main(String args[]) throws IOException {

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] arr = new int[n];
        StringTokenizer st = new StringTokenizer(br.readLine());
        for(int i = 0; i < n; i++){
            arr[i] = Integer.parseInt(st.nextToken());
        }

        int[] dp = new int[n];
        int max = 0;
        for(int i = 0; i < n; i++){
            dp[i] = 1;
            for(int j = 0; j < i; j++){
                // 이전 원소가 현재 원소보다 작고 이전 dp + 1이 현재 dp보다 크다면 갱신
                if(arr[j] < arr[i] && dp[i] < dp[j] + 1){
                    dp[i] = dp[j] + 1;
                }
            }
            // dp에 저장된 값 중 가장 큰 값
            max = Math.max(max, dp[i]);
        }

        System.out.println(max);
    }
}
```
