## BOJ 2110 문제 요약

- 일직선 상에 N개의 집 좌표가 주어짐
- C개의 공유기를 설치하려고 할 때,
- 두 공유기 사이의 최소 거리를 최대한 크게 만들고 싶다
- 만들 수 있는 최소 거리의 최댓값을 출력하는 문제

---

## 아이디어

1. 거리 기준 이분 탐색 (Parametric Search)
    - 목표는 공유기 사이의 최소 거리의 최댓값을 구하는 것
    - 어떤 거리 D에 대해
        - 그 거리 이상을 유지하면서 공유기를 C개 이상 설치할 수 있으면 → D는 가능
        - 설치할 수 없으면 → D는 불가능
    - 가능/불가능이 거리 D에 대해 단조롭게 변하므로, 이분 탐색으로 최댓값을 찾을 수 있음
2. 주어진 거리 D에서 설치 가능한 공유기 수 계산 (greedy)
    - 집 좌표를 오름차순 정렬
    - 첫 집에 공유기 1개 설치
    - 이후 집들을 앞에서부터 보며
        - 마지막으로 설치한 집과의 거리가 D 이상일 때만 새로 설치
    - 이렇게 세어본 공유기 개수가 C 이상이면, 거리 D로 설치 가능하다고 판단
3. Upper Bound 방식 이분 탐색
    - 탐색 범위를 `low = 0`, `high = 최대 좌표 + 1`로 잡음
        - `high = 최대 좌표 + 1` 로 잡은 이유는 탐색 구간이 [low, high)로 반열린 구간이어서 high는 항상 실패라고 보장되는 값 이상이어야 함 → 따라서 high를 정답보다 무조건 큰 값인 최대좌표 + 1 로 잡음
    - mid를 후보 거리로 두고,
        - `count(mid) < C` 이면 거리가 너무 커서 설치 불가능 → `high = mid`
        - `count(mid) >= C` 이면 설치 가능하므로 더 큰 거리도 시도 → `low = mid + 1`
    - 반복이 끝난 뒤 `low`는 조건을 만족하지 못하는 첫 거리이므로,
        - 우리가 원하는 답은 `low - 1`이 됨

---

## 알고리즘 단계

1. 입력 받기
    - `N`(집 개수), `C`(공유기 개수)
    - N개의 집 좌표를 배열 `location[]`에 저장
    - `location`을 오름차순 정렬
2. 이분 탐색으로 최대 최소 거리 찾기 – `possible()`
    - `low = 0`, `high = maxLoc + 1`로 설정
    - while (`low < high`):
        - `mid = (low + high) / 2`
        - `count = count(location, mid)` 로 거리 `mid`로 설치 가능한 공유기 개수 계산
        - `count < C` → 더 좁게 설치해야 하므로 `high = mid`
        - `count >= C` → 가능하니 거리를 늘려보기 위해 `low = mid + 1`
    - 반복이 끝나면 `low`는 더 이상 설치 불가능해지는 최소 거리

      → 정답은 `low - 1`

3. 거리 D에서 설치 가능한 공유기 수 세기 – `count()`
    - 첫 집에 공유기 설치: `houseCount = 1`, `beforeHouse = 0`
    - 두 번째 집부터 끝까지 순회:
        - `loc[i] >= loc[beforeHouse] + length` 이면
            - 이 집에 공유기 설치 (`houseCount++`)
            - `beforeHouse = i`로 갱신
    - 최종 `houseCount`를 반환
4. 정답 출력
    - `possible(location, location[location.length - 1], C)`의 결과를 출력

## 코드

```java
import java.io.*;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) throws IOException {
        // 최대거리를 이분탐색으로 구하기
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int N = Integer.parseInt(s[0]);
        int C = Integer.parseInt(s[1]);
        int[] location = new int[N];
        for (int i = 0; i < N; i++) {
            int loc = Integer.parseInt(br.readLine());
            location[i] = loc;
        }
        Arrays.sort(location);

        // upperbound 로 구해 가능한 최대 길이는 -1을 해야함
        bw.write(possible(location, location[location.length-1], C)+"\n");
        bw.flush();
        bw.close();

    }
    public static int possible(int[] loc, int maxLoc, int c) {
        int low = 0, high = maxLoc+1;
        while(low < high) {
            int mid = low + (high - low) / 2;
            int count = count(loc, mid);
            if (count < c) high = mid;
            else low = mid + 1;
        }
        return low -1;
    }

    public static int count(int[] loc, int length) {
        int houseCount = 1;
        int beforeHouse = 0;
        for (int i = 1; i < loc.length; i++) {
            if(loc[i] >= loc[beforeHouse]+length) {
                houseCount++;
                beforeHouse = i;
            }
        }
        return houseCount;
    }
}
```
