## BOJ 12847 문제 요약

- n일 동안 하루 벌이가 pay[i]로 주어진다.
- 연속된 m일 동안 벌 수 있는 총 금액 중 최댓값을 구한다.
- 즉, 길이가 m인 연속 부분 구간 합의 최댓값을 출력하는 문제이다.

---

## 아이디어

- 연속 구간 합을 매번 처음부터 다시 계산하면 O(nm)이라서 시간 초과가 날 수 있다. → 슬라이딩 윈도우 사용해 전체를 O(n)에 처리한다.
- 길이가 m인 구간 합을 한 번 구해두고, 구간을 한 칸씩 오른쪽으로 이동시키며 업데이트한다.
- 구간 이동 시 변화는 다음만 반영하면 된다.
    - 새로 들어오는 값 pay[i]를 더한다.
    - 구간에서 빠지는 값 pay[i-m]를 뺀다.

---

## 알고리즘 단계

1. n, m을 입력받는다.
2. pay 배열에 n일치 벌이를 저장한다.
3. 첫 m일(0 ~ m-1)의 합을 sum에 계산한다.
4. max를 sum으로 초기화한다.
5. i를 m부터 n-1까지 순회하며 윈도우를 한 칸씩 이동한다.
    - sum = sum + pay[i] - pay[i-m]
    - max = max(sum, max)
6. 최종 max를 출력한다.

---

## 코드

```java
import java.io.*;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        int n = Integer.parseInt(s[0]);
        int m = Integer.parseInt(s[1]);
        long sum = 0;

        int[] pay = new int[n];
        s = br.readLine().split(" ");
        for (int i = 0; i < n; i++) {
            pay[i] = Integer.parseInt(s[i]);
        }

        for (int i = 0; i < m; i++) {
            sum += pay[i];
        }

        long max = sum;
        // 슬라이딩윈도우
        for (int i = m; i < n; i++) {
            sum += pay[i] - pay[i-m];
            max = Math.max(sum, max);
        }

        bw.write(max + "\n");
        bw.flush();
        bw.close();
    }
}
```
