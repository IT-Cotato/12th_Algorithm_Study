## BOJ 10828 문제 요약

- 정수를 저장하는 스택을 직접 구현하는 문제
- 명령어:
    - push X : 정수 X를 스택에 넣음
    - pop : 가장 위의 정수를 빼고 출력 (없으면 -1)
    - size : 스택에 들어있는 정수 개수 출력
    - empty : 스택이 비어있으면 1, 아니면 0 출력
    - top : 스택의 가장 위 정수 출력 (없으면 -1)

---

## 아이디어

- 자바의 Stack 클래스를 사용하지 않고, 직접 배열로 스택을 구현
- 배열과 top 인덱스를 이용
    - push: stack[++top] = X;
    - pop: stack[top--]; (단, 비어있으면 -1)
    - size: 현재 top 값
    - empty: top == 0인지 확인
    - top: stack[top] (단, 비어있으면 -1

---

## 구현 포인트

- 전역 변수 사용

  stack[]과 top을 전역으로 선언 → 함수 호출 시 매번 전달하지 않아도 됨

- 인덱스 관리 방식
    - top을 0으로 시작 → ++top으로 push할 때 증가
    - 따라서 stack[0]은 항상 비워둠(실제 데이터는 1 ~ top)
    - 비어있는지 확인은 top == 0으로 판별
- 명령어별 처리 방식
    - push 명령은 출력이 없으므로 바로 continue
    - 나머지 명령은 결과값을 bw에 출력

---

## 코드

```java
import java.io.*;

public class Main {
    public static int[] stack;
    public static int top = 0;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        int N = Integer.parseInt(br.readLine());
        String[] s;
        int commandResult;

        stack = new int[N + 1]; // 최대 N개 push 가능 → N+1 크기로 생성

        for (int i = 0; i < N; i++) {
            s = br.readLine().split(" ");
            commandResult = stack(s);
            if (s[0].equals("push"))
                continue; // push는 출력 없음
            bw.write(commandResult + "\n");
        }
        bw.flush();
        bw.close();
    }

    public static int stack(String[] str) {
        int stackResult = 0;
        switch (str[0]) {
            case "push":
                stack[++top] = Integer.parseInt(str[1]);
                break;
            case "pop":
                if (top == 0) return -1;
                stackResult = stack[top--];
                break;
            case "size":
                stackResult = top;
                break;
            case "empty":
                stackResult = (top == 0 ? 1 : 0);
                break;
            case "top":
                if (top == 0) return -1;
                stackResult = stack[top];
                break;
        }
        return stackResult;
    }
}
```
