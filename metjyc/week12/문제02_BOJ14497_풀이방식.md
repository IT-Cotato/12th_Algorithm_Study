🧠 BOJ 14497 - 주난의 난(難)

📌 문제 요약

주난이는 한 번 점프할 때마다 파동을 발생시킨다.
이 파동은 상·하·좌·우 4방향으로만 퍼지며,
친구(1)를 만나면 그 지점에서 멈춘다.
• 0 : 빈 공간 (파동 통과 가능)
• 1 : 친구 (한 번의 점프를 사용해 쓰러뜨려야 통과 가능)
• \* : 주난이 시작 위치
• # : 범인 위치

목표는 범인(#)에게 도달하기 위한 최소 점프 횟수를 구하는 것이다.

⸻

🔍 핵심 관찰 (문제 해석)

✔ 파동의 실제 의미
• 한 번의 점프 = 현재 열려 있는 공간에서 바깥으로 한 겹 확장
• 친구(1)는 즉시 통과 불가
• 한 번 점프 → 쓰러짐
• 다음 점프부터 통과 가능

✔ 문제의 본질

이 문제는 단순 이동 문제가 아니라 다음 문제로 변환할 수 있다.

시작점에서 범인까지 이동하면서
‘친구(1)’를 최소 몇 명 쓰러뜨려야 하는가

⸻

🧩 문제 변환 (그래프 관점)

각 칸을 정점으로 보고, 인접한 칸으로 이동한다고 생각한다.

이동 비용 정의

다음 칸 의미 비용
0, \*, # 바로 이동 가능 0
1 친구를 쓰러뜨려야 이동 가능 1

즉,
• 간선 가중치가 0 또는 1인 그래프 최단경로 문제

⸻

🚀 해결 전략: 0-1 BFS

왜 일반 BFS가 아닌가?
• 일반 BFS는 모든 간선 비용이 동일할 때만 최단거리 보장
• 이 문제는 비용이 0 또는 1 → 일반 BFS ❌

왜 0-1 BFS인가?
• 가중치가 0 또는 1일 때
• 덱(Deque)을 이용해 다익스트라를 빠르게 구현 가능

0-1 BFS 규칙
• 비용이 0인 이동 → 덱의 앞(front) 에 넣기
• 비용이 1인 이동 → 덱의 뒤(back) 에 넣기

⸻

🗂 dist 배열의 의미

dist[x][y] = (x, y)에 도달하기까지 쓰러뜨린 친구(1)의 최소 개수

    •	처음에는 모든 값을 INF로 초기화
    •	시작 위치 *는 비용 0

이 배열을 통해 항상 더 적은 점프로 갈 수 있는 경로만 유지한다.

⸻

🧠 왜 정답에 +1을 하는가?

dist[x][y]는 쓰러뜨린 친구의 수일 뿐이다.

하지만 문제에서 말하는 점프는:
• 파동을 발생시키는 행위
• 설령 친구를 하나도 쓰러뜨리지 않아도,
최소 1번의 점프는 반드시 필요

예시

#00
0\*0
000

    •	친구를 하나도 안 밟음 → dist = 0
    •	하지만 점프는 최소 1번 필요 → 정답 = 1

👉 따라서 최종 답은:

dist[tx][ty] + 1

⸻

✨ 전체 풀이 흐름 요약 1. 입력 파싱 및 좌표를 0-index로 변환 2. dist 배열 생성 (최소 비용 기록) 3. 0-1 BFS를 위한 덱 구현 4. BFS 수행
• 상/하/좌/우 탐색
• 비용 계산 (1이면 +1)
• 더 적은 비용이면 갱신 5. dist[범인 위치] + 1 출력

⸻

🧠 핵심 한 줄 요약

이 문제는
**“상하좌우로 퍼지는 파동을,
친구를 쓰러뜨리는 비용(0/1)으로 모델링한
0-1 BFS 최단경로 문제”**이다.
