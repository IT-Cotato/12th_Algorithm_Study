# Dynamic Programming (동적 계획법) 정리 README

> 동적 계획법(DP)은 **큰 문제를 작은 문제로 쪼개서**,  
> 작은 문제의 답을 **재사용(저장)** 하며 전체 문제를 푸는 기법이다.  
> 핵심은 **중복 계산 제거** → 시간복잡도 폭발을 `O(n)`, `O(nm)` 같은 형태로 줄이는 것.

---

## 1. DP가 성립하는 조건 (2가지)

### ✅ 1) 최적 부분 구조 (Optimal Substructure)

큰 문제의 최적해(또는 정답)가 **부분 문제의 정답**으로부터 만들어질 수 있어야 한다.

예: `dp[n] = dp[n-1] + dp[n-2]`

### ✅ 2) 중복 부분 문제 (Overlapping Subproblems)

부분 문제가 **반복해서 등장**해야 한다.

예: 피보나치 재귀는 계산이 여러 번 반복됨.

---

## 2. DP를 푸는 2가지 방식

### 1. Top-down (재귀 + 메모이제이션)

- 재귀로 탐색하며, 이미 계산한 값은 저장해두고 재사용
- 장점: 필요한 부분만 계산(“게으른 계산”)
- 단점: 재귀 깊이/스택 주의, JS에서는 특히 recursion limit 문제 가능

### 2. Bottom-up (반복문 + 테이블)

- 작은 상태부터 차근차근 채우는 방식(“테이블 채우기”)
- 장점: 구현이 안정적, 스택 문제 없음
- 단점: 때로는 모든 상태를 다 계산(필요 없는 것도 계산할 수 있음)

---

## 3. DP 문제 풀이 사고 흐름 (필수 체크리스트)

1. **상태(State) 정의**: `dp[i]`가 의미하는 게 무엇인가?
2. **점화식(Transition) 세우기**: `dp[i]`를 이전 어떤 상태로부터 만들지?
3. **초기값(Base Case)**: 가장 작은 입력의 정답은?
4. **계산 순서(Order)**: 작은 것 → 큰 것(또는 필요한 방향)으로 채우기
5. **모듈러/범위 처리**: `mod`, 음수/overflow, 큰 수 처리
6. (선택) **공간 최적화**: 이전 몇 칸만 필요하면 배열을 줄일 수 있다.

---

## 4. DP가 특히 자주 나오는 유형

- **최솟값/최댓값**: 최소 비용, 최대 이익, 최단/최장
- **경우의 수**: 몇 가지 방법인지 (보통 mod 함께 나옴)
- **선택/비선택**: i번째를 고른다/안 고른다
- **누적 최적화**: “지금까지 중 최선”을 쌓아감
- **부분수열/부분문자열**: LIS, LCS

---

## 5. 작은 예시 : 피보나치

### 점화식

- `dp[n] = dp[n-1] + dp[n-2]`

### Bottom-up

```js
const n = 10;
const dp = Array(n + 1).fill(0);
dp[1] = 1;
dp[2] = 1;

for (let i = 3; i <= n; i++) {
  dp[i] = dp[i - 1] + dp[i - 2];
}
console.log(dp[n]);
```

### 공간 최적화(이전 2개만 필요)

```js
let a = 1,
  b = 1; // dp[1], dp[2]
for (let i = 3; i <= n; i++) {
  const c = a + b;
  a = b;
  b = c;
}
console.log(n === 1 ? 1 : b);
```
