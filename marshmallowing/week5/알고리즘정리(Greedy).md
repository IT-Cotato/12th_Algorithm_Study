## 그리디 알고리즘 (Greedy Algorithm) 

그리디 알고리즘은 **각 단계에서 가장 최적인 선택**을 하여 최종적으로 전체 문제의 최적 해답을 얻으려는 알고리즘 설계 기법이다. 

-----

## 1\. 기본 작동 원리

| 단계 | 설명                                                  |
| :--- |:----------------------------------------------------|
| **선택 (Selection)** | 현재 상태에서 **가장 이득이 되는 최적의 해답**을 선택한다. 이후의 선택은 고려하지 않음 |
| **적절성 검토 (Feasibility)** | 선택된 해답이 문제의 **제약 조건**을 만족하는지 확인                     |
| **해답 (Solution)** | 이 선택 과정을 **반복**하여 최종적인 문제 해결에 도달                    |

-----

## 2\. 그리디 알고리즘의 전제 조건

1.  **탐욕적 선택 속성 (Greedy Choice Property):** 각 단계의 최적 선택이 **이후의 선택에 영향을 미치지 않으며**, 최종 해답의 최적 선택으로 이어져야 한다
2.  **최적 부분 구조 (Optimal Substructure):** 문제의 최적 해답이 그 **부분 문제들의 최적 해답**으로 구성될 수 있어야 한다

-----

## 3\. 장점 및 단점

| 구분 | 설명                                                                                   |
| :--- |:-------------------------------------------------------------------------------------|
| **장점** | **매우 빠르다** (**효율적**). 모든 경우의 수를 저장하거나 복잡한 점화식을 세울 필요가 없기 때문에 실행 시간이 짧다.              |
| **단점** | **최적해를 보장하지 않는다.** 각 단계의 최적 선택이 전체 최적해로 이어지지 않는 경우가 많으므로, 적용 전에 문제의 성질을 반드시 확인해야 한다. |

-----

## 4\. 대표적인 활용 문제

| 문제 | 그리디 선택 기준 | 알고리즘 |
| :--- | :--- | :--- |
| **거스름돈** | 현재 남은 돈을 거슬러줄 수 있는 **가장 큰 화폐 단위**를 선택 | 단순 그리디 |
| **활동 선택** | 가장 **빨리 끝나는** 활동을 선택 | 단순 그리디 |
| **최소 신장 트리 (MST)** | 현재 집합에서 연결할 수 있는 **가장 가중치가 낮은** 간선을 선택 | 프림 알고리즘 (Prim's Algorithm) |
| **최단 경로** | 현재까지 발견된 경로 중 **가장 거리가 짧은** 노드를 선택 | 다익스트라 알고리즘 (Dijkstra's Algorithm) |
| **데이터 압축** | 현재 가장 **빈도가 낮은 두 문자**를 묶어 코드를 생성 | 허프만 코딩 (Huffman Coding) |
