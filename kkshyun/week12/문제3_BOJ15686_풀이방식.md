## BOJ 15686 문제 요약

- N×N 도시가 주어지고 각 칸은 다음 중 하나
    - 0 빈 칸
    - 1 집
    - 2 치킨집
- 치킨집 중 최대 M개만 남기고 나머지는 폐업시킨다.
- 각 집의 치킨 거리(집 ↔ 가장 가까운 치킨집의 맨해튼 거리)를 구해 모두 더한 값을 도시의 치킨 거리라고 한다.
- 도시의 치킨 거리가 최소가 되도록 치킨집을 고르고, 그 최소값을 출력하는 문제

---

## 아이디어

- 치킨집 후보가 여러 개이므로, 그중 M개를 고르는 모든 조합을 탐색한다. (백트래킹/DFS)
- 특정 조합이 정해지면:
    - 각 집(1)에 대해 선택된 치킨집들 중 가장 가까운 거리의 최솟값을 구하고
    - 그 값을 누적해서 도시의 치킨 거리를 계산한다.
- 조합 탐색에는 visited[](선택된 치킨집 표시)를 사용한다.

---

## 알고리즘 단계

1. 입력으로 N, M을 읽는다.
2. 도시를 순회하면서
    - 집(1) 좌표는 onePoints에 저장
    - 치킨집(2) 좌표는 twoPoints에 저장
3. visited = new boolean[twoPoints.size()] 준비
4. choiceChicken(start, n, r)로 치킨집 M개 조합을 탐색한다.
5. choiceChicken 동작
    - r == 0이면 M개를 다 뽑은 상태 → calChickenStreet() 호출 후 종료
    - i = start ~ n-1까지 순회하며
        - visited[i] = true로 i번째 치킨집 선택
        - choiceChicken(i+1, n, r-1) 재귀 호출
        - 재귀 종료 후 visited[i] = false로 원상복구
6. calChickenStreet 동작
    - 모든 집에 대해:
        - 선택된 치킨집(visited[j] == true)들 중 최소 거리 min 계산
        - sum += min
    - result = min(result, sum)으로 최소값 갱신
7. 모든 조합 탐색이 끝나면 result 출력

---

## 코드

```java
import java.io.*;
import java.util.ArrayList;

public class Main {
    static class Point {
        int col;
        int row;
        public Point(int col, int row) {
            this.col = col;
            this.row = row;
        }
    }
    static ArrayList<Point> onePoints = new ArrayList<>();
    static ArrayList<Point> twoPoints = new ArrayList<>();
    static boolean[] visited;
    static int N, M;
    static int result = Integer.MAX_VALUE;
    public static void main(String[] args) throws IOException {
        // 치킨집 중 M개를 고르고(조합) 여기에서 각 집의 치킨거리의 합
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        N = Integer.parseInt(s[0]);
        M = Integer.parseInt(s[1]);

        // 입력받기(0 : 빈칸, 1 : 집, 2 : 치킨집)
        for (int i = 0; i < N; i++) {
            s = br.readLine().split(" ");
            for (int j = 0; j < N; j++) {
                int num = Integer.parseInt(s[j]);
                if(num == 1)
                    onePoints.add(new Point(i,j));
                else if(num == 2)
                    twoPoints.add(new Point(i,j));
            }
        }

        visited = new boolean[twoPoints.size()];

        // 치킨집 선정
        choiceChicken(0, twoPoints.size(), M);
        bw.write(result+"\n");
        bw.flush();
        bw.close();
    }
    static void choiceChicken(int start, int n, int r) {
        if(r == 0) {
            // 치킨거리 계산
            calChickenStreet();
            return;
        }
        for(int i = start; i < n; i++) {
            visited[i] = true;
            choiceChicken(i+1, n, r-1);
            visited[i] = false;
        }
    }
    static void calChickenStreet() {
        int sum = 0;
        int min;
        for (int i = 0; i < onePoints.size(); i++) {
            min = Integer.MAX_VALUE;
            for (int j = 0; j < visited.length; j++) {
                if(visited[j])
                    min = Math.min(Math.abs(onePoints.get(i).col-twoPoints.get(j).col) + Math.abs(onePoints.get(i).row-twoPoints.get(j).row), min);
            }
            sum += min;
        }
        result = Math.min(result, sum);
    }
}
```
