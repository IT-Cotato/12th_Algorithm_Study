# BOJ 15686 - 치킨 배달

## 문제 요약
N×N 도시에서
- 0: 빈 칸
- 1: 집
- 2: 치킨집

치킨집 중 **M개만 남기고 폐업**할 때,
도시의 치킨 거리(각 집에서 가장 가까운 치킨집 거리의 합)를 최소화하라

## 핵심 아이디어:
> "치킨집 선택" = 조합

치킨집 개수를 K라 하면
- 가능한 선택 경우의 수는 C(K, M)
- K는 최대 13(문제 특성상) 수준이라 완전탐색이 가능하다.

## 구현 전략
1) 입력을 2차원 배열로 다 들고 있을 필요 없다
    - 집 좌표 리스트(houses)
    - 치킨집 좌표 리스트(chickens)
      만 따로 모아둔다.

2) 조합 생성 (재귀)
- pick[]에 선택한 치킨집 인덱스를 넣고
- M개가 채워지면 도시 치킨 거리 계산

3) 도시 치킨 거리 계산
   각 집 h에 대해:
- 선택된 치킨집들 중 거리 최소값 best를 찾고
- sum += best
  모든 집을 합하면 해당 조합의 도시 치킨 거리

## 시간 복잡도
- 조합 수: C(K, M) (K<=13)
- 각 조합마다: 집 개수 H(최대 2N) * M
  대략 O(C(13, M) * H * M) 정도로 충분히 통과 가능.
