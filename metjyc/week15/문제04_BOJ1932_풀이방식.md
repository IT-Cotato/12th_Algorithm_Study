# 정수 삼각형 (BOJ 1932)

## 📌 문제 요약

맨 위에서 시작하여 삼각형의 아래쪽으로 내려오면서 숫자를 하나씩 선택한다.  
아래층으로 내려갈 때는 **대각선 왼쪽 또는 대각선 오른쪽**으로만 이동할 수 있다.

이때 선택된 숫자의 **합이 최대가 되는 경로의 합**을 구하는 문제이다.

---

## 🧠 문제 접근 방식

삼각형의 각 칸으로 도달하는 경로는 매우 많기 때문에  
모든 경로를 직접 탐색하면 경우의 수가 **지수적으로 증가**하여 시간 초과가 발생한다.

이 문제는 **동적 계획법(DP)** 을 사용하여 해결할 수 있다.

---

## 📐 DP 상태 정의

`dp[i][j]`  
→ i번째 줄의 j번째 칸까지 내려왔을 때 만들 수 있는 **최대 합**

- i는 0부터 n-1까지
- j는 0부터 i까지 유효

---

## 🚀 초기값

삼각형의 맨 꼭대기는 시작점이므로:

```text
dp[0][0] = 삼각형의 첫 번째 값


⸻

🔁 점화식

현재 칸 (i, j)로 올 수 있는 경우는 최대 2가지이다.

1️⃣ 왼쪽 위에서 오는 경우
	•	(i-1, j-1)

2️⃣ 오른쪽 위에서 오는 경우
	•	(i-1, j)

이를 이용한 점화식은 다음과 같다:
	•	맨 왼쪽 (j = 0)

dp[i][j] = dp[i-1][j] + value[i][j]


	•	맨 오른쪽 (j = i)

dp[i][j] = dp[i-1][j-1] + value[i][j]


	•	중간 위치 (0 < j < i)

dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + value[i][j]



⸻

✅ 최종 정답

삼각형의 마지막 줄에 있는 값들 중 가장 큰 값이 정답이다.

max(dp[n-1][0], dp[n-1][1], ..., dp[n-1][n-1])


⸻

⏱ 시간 복잡도
	•	각 칸을 한 번씩 계산
	•	O(n²)

💾 공간 복잡도
	•	2차원 DP 배열 사용
	•	O(n²)

```
