# 🧩 쿼드 트리 (Quad Tree) 압축 – BOJ 1992

## 1. 문제 개요

흑백 영상(0과 1로만 이루어진 N×N 배열)을  
**쿼드 트리(Quad Tree)** 구조를 이용해 문자열로 압축하는 문제이다.

- N은 항상 **2의 제곱수**
- 같은 값(0 또는 1)으로만 이루어진 영역은 **한 글자**로 표현
- 섞여 있으면 **4분할 후 재귀적으로 압축**
- 결과는 **문자열**로 출력

---

## 2. 핵심 아이디어

이 문제는 **탐색 문제**이며  
정답 문자열은 **재귀 DFS 탐색 순서 그대로 이어 붙인 결과**이다.

👉 값을 계산하거나 정렬하지 않는다  
👉 탐색 순서가 곧 출력 순서이다

---

## 3. 쿼드 트리 압축 규칙

### (1) 영역이 전부 같은 값일 경우

- 전부 `0` → `"0"`
- 전부 `1` → `"1"`

👉 **괄호 없음 (리프 노드)**

---

### (2) 0과 1이 섞여 있을 경우

- 해당 영역을 **4등분**
- 각 영역을 다시 압축
- 결과를 **괄호로 묶어서 표현**

형식:

(왼쪽위 오른쪽위 왼쪽아래 오른쪽아래)

👉 **괄호 있음 (내부 노드)**

---

## 4. 탐색 순서 (매우 중요 ⭐)

쿼드 트리는 **항상 이 순서로 탐색한다**

1️⃣ 왼쪽 위 (LU)
2️⃣ 오른쪽 위 (RU)
3️⃣ 왼쪽 아래 (LD)
4️⃣ 오른쪽 아래 (RD)

이 순서는 **절대 바뀌지 않는다**

---

## 5. 괄호의 기준 정리

괄호는 아래 조건일 때만 등장한다.

| 조건                | 출력             |
| ------------------- | ---------------- |
| 영역이 전부 같은 값 | `"0"` 또는 `"1"` |
| 0과 1이 섞여 있음   | `"(....)"`       |

---

## 6. 예제 문자열 해석

결과 예시:

(0(0011)(0(0111)01)1)

의미:

- 전체 영역이 섞여 있음 → 괄호
- 왼쪽 위 → `0`
- 오른쪽 위 → `(0011)`
- 왼쪽 아래 → `(0(0111)01)`
- 오른쪽 아래 → `1`

👉 **DFS 재귀 호출 순서 그대로 쌓인 문자열**

---

## 7. 알고리즘 흐름

1. 현재 영역이 전부 같은 값인지 확인
2. 같으면 `"0"` 또는 `"1"` 반환
3. 다르면 4등분
4. 각 영역을 재귀 호출
5. 결과를 `(LU + RU + LD + RD)` 형태로 반환

---

## 8. 시간 복잡도

- 최악의 경우 모든 칸을 한 번씩 검사
- **O(N²)**  
  (N ≤ 64 이므로 충분히 빠름)

---

## 9. 구현 코드 (Node.js)

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split("\n");

const N = Number(input[0]);
const arr = input.slice(1);

function isSame(x, y, size) {
  const first = arr[x][y];
  for (let i = x; i < x + size; i++) {
    for (let j = y; j < y + size; j++) {
      if (arr[i][j] !== first) return false;
    }
  }
  return true;
}

function compress(x, y, size) {
  if (isSame(x, y, size)) return arr[x][y];

  const half = size / 2;
  const lu = compress(x, y, half);
  const ru = compress(x, y + half, half);
  const ld = compress(x + half, y, half);
  const rd = compress(x + half, y + half, half);

  return "(" + lu + ru + ld + rd + ")";
}

console.log(compress(0, 0, N));
```
