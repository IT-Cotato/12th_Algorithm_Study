## BOJ 14497 문제 요약

        - N×M 격자 지도가 주어진다.
        - 시작 위치 (x1, y1)에서 목표 위치 (x2, y2)까지 이동한다.
        - 지도에는 이동 가능한 칸과, 지나가려면 “뚫어야 하는” 칸(문자 '1')이 섞여 있다.
        - 상하좌우 4방향으로 이동할 수 있을 때,
        - '1' 칸으로 들어가면 비용(카운트)이 1 증가
        - '1'이 아닌 칸으로 들어가면 비용 증가 없이 이동
        - 목표 위치에 도달하기 위한 최소 비용(최소로 '1'을 밟는/뚫는 횟수 기준)을 구하는 문제

        ---

        ## 아이디어

        - 일반 BFS로는 “'1'을 지날 때만 비용이 증가”하는 가중치가 반영이 안 된다.
        - 따라서 0 또는 1의 가중치가 있는 최단경로 문제로 보고
        - PriorityQueue를 이용한 다익스트라(0-1 BFS 느낌)를 사용한다.
        - 큐에는 (x, y, cost)를 넣고 cost가 작은 것부터 먼저 꺼내서 확정해 나간다.
        - 다음 칸이 '1'이면 cost+1로, 아니면 cost 그대로 큐에 넣는다.
        - visited로 한 번 방문한 칸은 다시 처리하지 않는다.

        ---

        ## 알고리즘 단계

        1. N, M을 입력받는다.
        2. (x1, y1), (x2, y2)를 입력받고 0-index로 변환한다.
        3. N줄을 입력받아 graph[N][M]에 문자 단위로 저장한다.
        4. bfs(x1, y1)를 수행한다.
        5. bfs 동작
        1. PriorityQueue에 (x1, y1, 1)을 넣고 시작점을 방문 처리한다.
        2. 큐에서 cost가 가장 작은 상태를 꺼낸다.
        3. 꺼낸 좌표가 (x2, y2)이면 그 cost를 정답으로 반환한다.
        4. 상하좌우 4방향으로 이동 가능한 칸을 확인한다.
        - 범위 안이고, 아직 방문하지 않았다면 진행
        - 다음 칸이 "1"이면 (nx, ny, cost+1)을 큐에 넣는다
        - 다음 칸이 "1"이 아니면 (nx, ny, cost)을 큐에 넣는다
        - 방문 처리(visited[nx][ny] = true)
        - graph[nx][ny]를 "0"으로 바꿔 재방문 의미를 없앤다 (네 코드 방식)
        6. 큐가 빌 때까지 도착하지 못하면 -1을 반환한다.

        ---

        ## 코드

        ```java
import java.io.*;
import java.util.LinkedList;
import java.util.PriorityQueue;
import java.util.Queue;

public class Main {
    static int[] dx = {-1,1,0,0};
    static int[] dy = {0,0,-1,1};
    static int N, M, x2, y2;
    static boolean[][] visited;
    static String[][] graph;
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        String[] s = br.readLine().split(" ");
        N = Integer.parseInt(s[0]);
        M = Integer.parseInt(s[1]);
        s = br.readLine().split(" ");
        int x1 =  Integer.parseInt(s[0]) -1;
        int y1 = Integer.parseInt(s[1]) -1;
        x2 =  Integer.parseInt(s[2]) -1;
        y2 = Integer.parseInt(s[3]) -1;

        graph = new String[N][M];
        visited = new boolean[N][M];
        for (int i = 0; i < N; i++) {
            s = br.readLine().split("");
            for (int j = 0; j < M; j++) {
                graph[i][j] = s[j];
            }
        }
        int result = bfs(x1, y1);
        bw.write(result+"\n");
        bw.flush();
        bw.close();
    }

    static int bfs(int x, int y) {
        Queue<int[]> queue = new PriorityQueue<>((o1,o2)->Integer.compare(o1[2],o2[2]));
        visited[x][y] = true;
        graph[x][y] = "0";
        queue.add(new int[]{x, y, 1});
        while(!queue.isEmpty()) {
            int[] cur = queue.poll();
            if(cur[0] == x2 && cur[1] == y2)
                return cur[2];
            for (int i = 0; i < dx.length; i++) {
                int moveX = cur[0] + dx[i];
                int moveY = cur[1] + dy[i];
                if(moveX >= 0 && moveY >= 0 && moveX < N && moveY < M && !visited[moveX][moveY]) {
                    if(graph[moveX][moveY].equals("1")) // 1 한번 만나면 끝
                        queue.add(new int[]{moveX, moveY, cur[2]+1});
                    else // 아니면 1 만날때까지 퍼짐
                        queue.add(new int[]{moveX, moveY, cur[2]});
                    visited[moveX][moveY] = true;
                    graph[moveX][moveY] = "0";
                }
            }
        }
        return -1;
    }
}
```
