## 백준 2630

### 해결 방법

이 문제는 **분할정복(Divide and Conquer)** 방식으로 해결할 수 있다.

### 핵심 아이디어
- 현재 정사각형 영역이 한 색인지 확인한다.
- 한 색이면 더 이상 나누지 않고 해당 색을 카운트한다.
- 한 색이 아니라면 영역을 4개의 정사각형으로 나눈다.
- 나눈 각 영역에 대해 같은 작업을 반복한다.

---

### 알고리즘 상세

1. 전체 색종이를 하나의 정사각형 영역으로 시작한다.
2. 해당 영역이 한 색인지 확인한다.
3. 모두 같은 색이면:
    - 흰색이면 흰색 개수 증가
    - 파란색이면 파란색 개수 증가
4. 색이 섞여 있다면:
    - 현재 영역을 크기가 절반인 4개의 정사각형으로 나눈다.
    - 각 영역에 대해 재귀적으로 동일한 과정을 수행한다.
5. 모든 영역에 대한 검사가 끝나면 결과를 출력한다.

---

### 영역 분할 방식

현재 정사각형의 한 변 길이를 `size`라 할 때,  
절반 크기(`size / 2`)의 정사각형 4개로 나눈다.

- 왼쪽 위
- 오른쪽 위
- 왼쪽 아래
- 오른쪽 아래

각 영역은 독립적으로 처리된다.

---

### 구현 코드

```java
import java.io.*;
import java.util.StringTokenizer;

public class Main {

    // 흰색(0), 파란색(1) 색종이 개수
    static int white = 0;
    static int blue = 0;
    static int[][] matrix;

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int n = Integer.parseInt(br.readLine());
        matrix = new int[n][n];

        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 0; j < n; j++) {
                matrix[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 전체 종이를 하나의 영역으로 시작
        solve(0, 0, n);

        // 결과 출력
        bw.write(white + "\n" + blue);
        bw.flush();
        bw.close();
    }

    // (x, y)를 왼쪽 위로 하는 size × size 영역 처리
    static void solve(int x, int y, int size) {
        if (isSameColor(x, y, size)) {
            if (matrix[x][y] == 0) white++;
            else blue++;
            return;
        }

        int half = size / 2;
        solve(x, y, half);
        solve(x, y + half, half);
        solve(x + half, y, half);
        solve(x + half, y + half, half);
    }

    // 영역이 전부 같은 색인지 확인
    static boolean isSameColor(int x, int y, int size) {
        int color = matrix[x][y];
        for (int i = x; i < x + size; i++) {
            for (int j = y; j < y + size; j++) {
                if (matrix[i][j] != color) return false;
            }
        }
        return true;
    }
}
