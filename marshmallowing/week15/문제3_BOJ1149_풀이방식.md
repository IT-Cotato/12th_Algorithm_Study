# BOJ 1149

#### 문제 핵심
- 집이 N개 있고, 각 집은 빨강(R), 초록(G), 파랑(B) 중 하나로 칠해야 한다.
- 연속된 두 집은 같은 색을 사용할 수 없다.
- 모든 집을 칠하는 데 드는 최소 비용을 구하는 문제.

---

#### DP 아이디어
- 이전 집의 색만 알면 현재 집의 선택이 결정된다.
- 따라서 현재 집을 어떤 색으로 칠했을 때의 최소 비용만 관리하면 된다.

---

#### DP 정의
- dp[0] : 현재 집을 빨강(R)으로 칠했을 때의 최소 비용
- dp[1] : 현재 집을 초록(G)으로 칠했을 때의 최소 비용
- dp[2] : 현재 집을 파랑(B)으로 칠했을 때의 최소 비용

---

#### 초기값 (첫 번째 집)
```java
dp[0] = cost[0][0];
dp[1] = cost[0][1];
dp[2] = cost[0][2];
```

---

#### 점화식 (두 번째 집부터)
- 같은 색은 연속해서 사용할 수 없으므로
- 현재 색을 제외한 이전 두 색 중 최소값을 선택한다

```java
int prevR = dp[0];
int prevG = dp[1];
int prevB = dp[2];

dp[0] = cost[i][0] + Math.min(prevG, prevB);
dp[1] = cost[i][1] + Math.min(prevR, prevB);
dp[2] = cost[i][2] + Math.min(prevR, prevG);
```

---

#### 시간 / 공간 복잡도
- 시간 복잡도: O(N)
- 공간 복잡도: O(1)

---

#### 핵심 요약
- 현재 집 색 ≠ 이전 집 색
- 이전 상태만 필요 → 1차원 DP로 해결 가능
