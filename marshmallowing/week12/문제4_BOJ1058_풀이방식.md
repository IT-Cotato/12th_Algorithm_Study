# BOJ 1058 - 친구 (2-친구)

## 문제 요약
사람 N명(<=50)이 있고,
- 친구면 'Y'
- 아니면 'N'

A의 2-친구란:
1) A와 직접 친구이거나
2) A의 친구 C가 존재해서 C와 B가 친구인 경우
   즉, 거리(친구 관계 간선 수)가 1 또는 2인 사람들이다.


>  각 i에 대해 직접/간접만 체크

사람 i에 대해:
- 직접 친구 j는 2-친구
- i의 친구 k를 거쳐서 갈 수 있는 j도 2-친구

boolean 배열 two[]로 중복 없이 표시하면 된다.

### 절차
1) two[j] = true if g[i][j]=='Y'
2) 모든 k에 대해 (g[i][k]=='Y')이면
    - 모든 j에 대해 (g[k][j]=='Y')이면 two[j]=true
3) two[i]=false
4) true 개수 세기

## 시간 복잡도
- i 루프 N
- k, j 루프 N^2
  => O(N^3) 이지만 N=50이라 충분히 빠름(125000 정도 수준)
