# 💥 BOJ 2812 - 크게 만들기 (Make It Bigger)

---

## 📖 문제 설명

N자리 숫자가 주어졌을 때, 이 숫자에서 **K개의 숫자를 지워서** 만들 수 있는 **가장 큰 수**를 구하는 문제다.

- 한 번에 한 자리 숫자를 제거할 수 있다.
- 제거 후 남은 숫자의 순서는 바꾸면 안 된다.

---

## 🧩 입력 형식

```
N K
숫자
```

- 1 ≤ K < N ≤ 500,000
- 숫자는 0으로 시작하지 않는다.

---

## 🧾 출력 형식

```
K개의 숫자를 지워서 얻을 수 있는 가장 큰 수
```

---

## 💡 문제 접근 (사고 흐름)

이 문제는 **그리디(Greedy)** + **스택(Stack)** 을 이용해 풀 수 있다.

핵심 아이디어는 다음과 같다 👇

> 앞자리 숫자가 클수록 전체 수가 크다.  
> 따라서 **현재 숫자가 앞자리보다 크면, 앞자리 작은 숫자를 지워버리는 것이 유리하다.**

이를 위해 숫자를 **왼쪽부터 하나씩** 보면서,  
“앞자리(top)가 나보다 작으면 pop” 하는 과정을 반복한다.

---

## ⚙️ 알고리즘 설계

1. 문자열을 왼쪽에서 한 자리씩 순회한다.
2. 스택의 맨 위(top) 값이 현재 숫자보다 작고, 아직 K번 덜 지웠다면 → pop
3. pop이 끝나면 현재 숫자를 push한다.
4. 모든 순회가 끝나고도 남은 삭제 횟수가 있다면, 뒤에서 자른다.

---

## 🧠 핵심 조건 정리

| 조건                              | 의미                                              |
| --------------------------------- | ------------------------------------------------- |
| `removeCount > 0`                 | 아직 지울 수 있는 횟수가 남아있다                 |
| `stack.length > 0`                | 비교할 스택 요소가 존재한다                       |
| `stack[stack.length - 1] < digit` | 앞자리 숫자가 현재 숫자보다 작다 → 지우는 게 이득 |

---

## 💻 코드 (JavaScript)

```js
const fs = require("fs");

const input = fs
  .readFileSync(process.platform === "linux" ? "/dev/stdin" : "input.txt")
  .toString()
  .trim()
  .split("\n");

const [N, K] = input[0].split(" ").map(Number);
const number = input[1].trim();

const stack = [];
let removeCount = K;

for (const digit of number) {
  while (
    removeCount > 0 &&
    stack.length > 0 &&
    stack[stack.length - 1] < digit
  ) {
    stack.pop();
    removeCount -= 1;
  }

  stack.push(digit);
}

// 남은 삭제 횟수만큼 뒤에서 제거
if (removeCount > 0) {
  stack.splice(stack.length - removeCount, removeCount);
}

console.log(stack.join(""));
```

## 🧩 동작 과정 예시 (시각화)

| 단계     | 읽은 숫자 | 스택 상태 변화 | 남은 삭제 횟수 | 동작 설명                        |
| -------- | --------- | -------------- | -------------- | -------------------------------- |
| 1        | 4         | [4]            | 4              | 첫 숫자 push                     |
| 2        | 1         | [4,1]          | 4              | 작으니 push                      |
| 3        | 7         | [7]            | 2              | 4,1 둘 다 작아 pop 두 번 후 push |
| 4        | 7         | [7,7]          | 2              | 같으니 push                      |
| 5        | 2         | [7,7,2]        | 2              | 작으니 push                      |
| 6        | 5         | [7,7,5]        | 1              | 2 < 5 → pop 후 push              |
| 7        | 2         | [7,7,5,2]      | 1              | push                             |
| 8        | 8         | [7,7,8]        | 0              | 5,2 작아 pop 두 번 후 push       |
| 9        | 4         | [7,7,8,4]      | 0              | push                             |
| 10       | 1         | [7,7,8,4,1]    | 0              | push                             |
| **결과** |           | **775841**     |                |                                  |

## ⏱️ 시간 복잡도

| 과정      | 복잡도             |
| --------- | ------------------ |
| 스택 순회 | O(N)               |
| pop/push  | 각 요소당 최대 1회 |
| **총합**  | **O(N)**           |

> N ≤ 500,000 이므로 충분히 빠르다.
